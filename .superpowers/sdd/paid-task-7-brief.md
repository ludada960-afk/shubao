# Paid Workflow Task 7 Brief

Canvas AI actions must use a server-authoritative quote, hold funds before work,
settle only after a stable result, and release when no result was delivered.
Successful action results are persisted by owner and action id so retries do not
rerun an expensive provider operation. The UI exposes actual AI-point prices and
routes structured 402 responses to the resumable paywall without clearing nodes.

Deterministic canvas tools remain free. Reverse prompt costs 0.2 AI points,
background removal costs 0.5, 2K AI edits cost 1, and 4K output costs 2. PSD export
remains disabled until real pixel layers and a valid PSD artifact exist.
