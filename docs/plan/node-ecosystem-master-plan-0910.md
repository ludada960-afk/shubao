## 2. 三条深度调研的关键结论（均带证据）

### 2.1 生成后的路径：工作台 vs 画布（报告：docs/reports/post-generation-flow-competitor-research-20260910.md）
- **10 家竞品 0 家有独立整页「第二步设计方案」确认页**——它不是行业标准；「先方案后执行」在竞品里由 Agent 意图规划 / 画布内节点即方案 / 生成前方案+扣费透明 三种轻形态承担。
- 画布派（即梦/知渔/Canva/稿定/可灵）生成后**留在画布就地编辑，画布即工作台**；时间线派（Runway）进内置时间线；合流方向 = **同一份项目数据两个投影（画布管策划/编排，时间线管镜头级成片/交付）**。
- 即梦完整路由 12 条**没有独立编辑器路由**——它的「视频工作台」就是无限画布本身（时间线是画布内元素）。
- **结论**：① 第二步设计方案**保留能力、废弃独立整页**，收敛为「共享方案对象 + 两种挂载（wizard 步骤 / 画布节点内嵌）」；② 视频工作台**该做且已建**，但入口收进画布（砍掉第三入口 DirectorWorkbench）；③ 三层 IA：**L1 首页=入口/灵感层（功能区卡片=预配置发射器，不再拥有独立结果出口）→ L2 画布=唯一编辑/编排/导出表面 → L3 作品·素材·主体=持久层**。

### 2.2 即梦视频生态四层（报告：docs/research/jimeng-video-ecosystem.md）
1. **模型层**：Seedance 2.5 独占 6 输入模式（全能参考/文/首帧/尾帧/超长 30–180s/自然语言视频编辑）+ 全能参考 50 素材（图30+视频10+音频10）+ 第三方模型超市。
2. **资产层**：主体库（含音色生成）/ 素材库 / **技能广场 186 技能·12 分类·用户可发布·使用量+点赞+添加三计数·二创溯源**。
3. **画布层**：无限画布五元素 文/图/视/音/**时间线** + 卡片连线 + **框选编号链式改写** + 多轨时间轴 + 一键导出成片。
4. **分发层**：作品公开 + 查看创作过程（只读画布）+ **一键复制项目**。
- **我方最大断点：TTS 是 mock**（占位音频、不收费）——它阻塞口播带货/成片/对口型三条线。
- 我方反超点：计费正确性（幂等 + 失败自动释放）、任务可靠性、分镜+成本护栏+精确重放、商品事实/合规/尺寸锁。

### 2.3 供应商与模型选型（报告见对话；证据文件 .tmp-research/ip233_*.json、quantv_models.json）
- **IP233 模型密度最高、可观测性最好**：我方密钥实测 `/v1/models` 可调用 **124 个模型**（视频 30/图片 24/音频 1…），80 个有公开价（`/api/pricing` 公开 JSON），**渠道健康公开**（视频 24/30 在线）。

- **Change2Pro**：渠道倍率登录墙；我方 nano 记账 **¥0.06/张**，比 IP233 公开 nano 价便宜 40–60% → **保留**。

## 3. 下一程路线图（P4→P9，每期门禁不变）

### P4 模板返工（先把体验做对）
- 模板节点**直接用画布真实的上传节点/生成节点**（`createUploadedImageNodes/VideoNodes` 同款形状），不再自造「槽位」样式；
- **预置占位素材**（真实商品图/模特图/服装图/视频素材各一张，像真实上传物），标题就叫「模特图」「服装图」「视频素材」；
- **选中即现「替换」按钮**（工具条 + 右键菜单；换图 = 重新上传/从素材库选），后续你自己替换、自己真跑；
- **模板三件套**（图 + 便签教程 + 一键同款）对齐知渔；文案全部市场化；**删除**「待 P3」「把商品图拖进来」等自造词（门控改为运行时提示，不印在节点上）。
- 门禁：模板节点与真实上传节点**同款契约**（同 class/同交互）；无自造样式；Playwright 视觉冒烟。

### P5 模型即选项（你要的「把供应商模型接进来」）
- 生成框加 **「选择模型」下拉**（对标 quantv/即梦形态），数据源 = **后端 catalog 唯一真源**（含供应商路由 + 报价），首页/画布/视频模块共用同一份清单；
- **SKU 四维分档**：模型 × 分辨率 × 时长 × 有无输入视频（即梦同款）；
- 落地上面的换/加/留（fast 档换 65535 需先小流量灰度）；
- 门禁：模型清单唯一真源契约 + 「换模型 → 报价随之变化」契约 + 不确认不扣费。

### P6 音视频能力（TTS 先行，补最大断点）
- **TTS 接真上游 + 计费**（ec_tts_voice；供应商报价确认后开；本轮先保持诚实门控）；
- **对口型 / 数字人节点**（独立 kind，报价确认后开放；未确认前 UI 不提供扣费入口）；
- 音乐 BGM（可选，优先级低于 TTS）。

### P7 三层 IA 迁移（把「首页为画布服务」落成结构）
- 首页四域**发射器化**（卡片=预配置 + 发射，不再拥有独立结果出口）；
- **方案对象统一**（DesignDirection 一套组件两种挂载），独立整页 wizard 物理消失、能力保留；
- 出口收口：一切生成结果落画布项目；作品/素材/主体归一为持久层。

### P8 资产与运营层
- 主体资产库（商品/人物/音色，跨项目复用）；技能市场（使用+点赞+添加三计数 + 署名 + 二创溯源；同时清掉 publicTemplates 的占位假计数——诚信红线）；复制项目 / 查看创作过程。

### P9 画布视频视图 + 时间线闭环
- VideoStudio 并入画布做「视频视图」（不新增第三套画布）；时间线落画布底部成片条（graph.timeline 已预留字段）；成片 renderer 接通（拼接免费=引流）。

## 4. 我要立的「把关」机制（防歪掉/冲突/变形）
1. **设计令牌与 UI 基线清单**：间距/圆角（≤14px）/字号/色板/按钮高度（32px）/面板宽度，所有新面必须复用，不得自造；
2. **契约测试三件套**：新增面必须有 ① 几何契约（bounded geometry / 响应式两档）② 文案契约（禁 demo 腔与自造词）③ 单一真源契约（价格/模型/图结构）；
3. **Playwright 视觉冒烟**：每个交付面在 1440/390 两档截图 + 关键几何断言（本轮已建好 `?qa=ec-canvas` 免登录画布通道 + 无代理 Playwright 用法，可持续复用）；
4. **总统筹自检清单**：每个改动过一遍 影响面（首页/画布/视频/作品）× 断点（输入/生成/编排/导出）× 三条不变式（不确认不扣费 / 老文档只读 / 价格唯一真源）。
