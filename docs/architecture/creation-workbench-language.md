# 创作工作台统一视觉与交互语言

## 不变的骨架

首页四个入口共用同一套暖白工作台：顶部是倾斜叠放的能力卡片，中段是能力说明和素材入口，主体是大输入区，底部是一行稳定的参数工具栏。圆角、边框、紫色动作色、素材缩略图和第二步方案确认都属于同一套产品语言。

默认电商生图必须保持“产品图 × 参考图”的原始框架。它的产品素材、参考图、文字描述和六个配置面板已经形成可交付习惯，任何新增能力都以扩展层接入，不能重排或替换默认流程。

## 能力配方层

电商工作台的能力选择器只负责选择配方，不改变默认编辑器。商品套图使用原来的产品/参考双栏；万物上身使用商品与穿搭、模特参考、场景参考三个语义槽位，并复用原有输入区、提示词区和第二步方案确认。

每个配方必须声明：

- 输入角色：用户上传的商品、模特、场景、视频或音频分别是什么；
- 保留事实：颜色、材质、纹理、结构、人物身份和品牌信息哪些必须保留；
- 结果价值：最终输出解决什么商业问题；
- 适用场景：用户什么时候应该选择它；
- 计划字段：比例、清晰度、张数、风格和一致性开关；
- 预览素材：一张输入到输出的原创示例，不能直接使用竞品素材。

万物上身的上方示例采用“商品组合 + 模特成片”的视觉叙事：左侧表达输入，右侧表达上身结果，中间用动作箭头建立因果。主体仍使用本站的暖白、紫色和卡片叠放语言，而不是复制竞品页面的整体布局。

## 第二步方案确认

需要分析的不是一个假弹窗，而是可解释的服务端计划：

- 识别每个素材的角色、质量和可用事实；
- 解析模特的姿态、取景和场景光线；
- 说明商品哪些特征会被保留，哪些只作为风格参考；
- 生成镜头/画面计划、输出规格和预计积分；
- 允许用户返回调整，再以相同计划幂等提交。

视频工作台也遵循这一点：智能成片、首尾帧、爆款重构是三种不同输入契约。爆款重构的参考视频负责节奏和镜头结构，用户素材负责替换对象，不能复用智能成片的上传语义。图片、视频、音频必须作为可见重点入口，底部工具栏只放模型、规格、声音和生成设置，不再添加与上方重复的“加号上传”。

## Skill 示例契约

自由创作的四个 Skill 卡片共用相同结构：

1. 原创输入示例；
2. 对应的输出结果；
3. 保留什么；
4. 生成什么；
5. 最适合什么场景。

卡片点击只切换配方和预览，不偷偷修改其他模式的素材。用户确认后再进入统一的参考素材区、提示词区和底部参数栏。未来增加海报、品牌 KV、社媒封面或其他 Skill 时，只需新增配方、预览资产、输入角色和参数 schema，不需要复制一套页面。

## 画布与恢复

第二步确认后的计划、素材角色和生成规格都必须可写入任务快照，结果进入现有 Canvas 节点和作品归档。画布再次编辑时只能修改计划允许的字段；刷新、断线和重新打开都恢复同一个任务，不重复上传、分析或扣费。
