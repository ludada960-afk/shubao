# 附录：无限画布 × 导演 Skill 实战拆解（2026-08-24 深度解析）

> 来源：《第一集：无限画布制作口哨舞女装带货视频》（小红书 @知渔AI，10min33s 全片逐段视觉拆解）＋ Seedance 2.5 导演 Skill 实战（B站 BV1zfg36ZEXi 细粒度重解析）。

## 一、无限画布带货视频完整工作流（民间最佳实践）

阶段 A — 模特资产两种生成法：
1. 模板直出：IMAGE2 模型从模板生成模特图；
2. 参考照反推：上传真人参考照 → 反推提示词 → 符号引用复用，保证跨镜头同款。

阶段 B — 场景一致性链：导入参考照 → 从图片提取元素 → 场景风格/色调/色彩设定节点 → 生成头像+全身像 → 结果回流画布成为可复用节点。注释原话："从图片里提取出来的元素，后面生成的AI图片更真实自然"。

阶段 C — 服装组合：上传服装组件图（白裙/粉上衣）→ 与姿势、背景组合成穿搭提示 → 批量产出同款服装跨姿势/跨背景的模特图（1:1、image2 模型）供挑选。

阶段 D — 动作驱动成片：上传动作参考视频（口哨舞）→ "全能语言模型"把动作+镜头拆解为极详细的结构化指令 → 结构化提示词模板分区：【全局基础提示词 | 镜头角度 | 镜头动作 | 情绪表情 | 时间节点与动作拆解】→ 图生视频逐镜生成。

阶段 E — 迭代交付：720p/480p、9:16 参数 → 逐节点运行 → "替换图片 / 替换动作参考视频"做资产级迭代 → 合成导出。

**产品启示**：用户心智里的"带货视频工作流"= 资产节点(模特/服装/场景/动作) + 提示词组装 + 批量候选挑选 + 资产替换迭代。这正是薯包导演台左栏一致性库 + 中央分镜板 + 候选体系的用户语言版。

## 二、Seedance 2.5 导演 Skill 补充实证

- 单项目可引用 **最多 30 个资产**参与生成（角色/场景/服装一致性的官方机制）。
- Agent 入口在右下角；上传"专属导演 Skill.zip"后由 Agent 驱动：一条条拆分镜 → 逐条改提示词 → 大场面单独试跑评估质量。
- UI 为暗色主题；角色设计环节出现九宫格服装选择网格与早期版 vs 改进版对比卡（候选对比是一等公民）。
- 分屏提示词（split-screen prompts）用于多主体场景。

## 三、对 R1-R6 的修订输入

1. 左栏一致性库的资产引用上限应支持两位数（≥30），与 Seedance 对齐；
2. 候选对比卡（前后版本并排+差异标注）列为 R3 编辑器必选项；
3. 结构化提示词分区采用无限画布实证的五分区（全局基础/镜头角度/镜头动作/情绪表情/时间节点拆解），并与 H3 六列表合并：六列表的"每秒指令"列内部按五分区组织；
4. "替换资产→下游失效→一键重跑"是画布类产品的核心迭代回路，R2 锁定状态机必须原生支持（v2 蓝图 R2 已含，此处确认为最高优先）；
5. 快捷预设模板（智能成片等）在导演台内的形态 = 预填好的 SkillRun 模板 + 示例画布，而非独立表单页。
