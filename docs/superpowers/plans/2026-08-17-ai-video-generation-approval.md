# AI 视频生成计划确认门禁

## 目标

把只读预检升级为可追溯的项目级确认快照。确认只保存当前计划哈希、目录报价和项目修订，不上传素材、不创建供应商任务、不冻结积分；后续真实生成必须携带同一哈希并重新校验当前项目仍未变化。

## 约束

- 服务端必须从当前工作台重算计划，不能信任客户端传入的报价、分镜或素材状态。
- 仅 `ready` 计划允许确认；阻断项、过期哈希、项目变化均返回可解释的 409/400。
- 每个项目只保留最新确认；任何工作台变更都会令旧确认失效。
- 生产仍需通过 `scripts/deploy-production.ps1`，不绕过受控 SSH 门禁。

## 实现切片

1. 为预检计划增加稳定哈希（排除生成时间），并持久化 owner/project scoped approval。
2. 增加 GET 最新确认与 POST 确认接口，服务端重算并比较哈希。
3. 客户端在计划面板提供“确认计划”，展示确认状态与哈希短码；计划变化后清除确认状态。
4. 用 store、route、client、UI 测试覆盖 ready/blocked/stale/越权/重复确认。

## 验证与后续

先完成本地测试、全量回归、构建和账本记录；实际生成路由接入后，必须要求未过期 approval 才能进入上传、报价和扣费阶段。
