# 流影式电商画布与图片性能重构实施计划

规格：`docs/superpowers/specs/2026-07-31-liuying-canvas-image-performance-rebuild.md`

## Task 1：状态与导航契约

1. 为 SKU 空配置、案例来源恢复和单进度面新增失败测试。
2. 由有效配置差异推导首页参数高亮。
3. 为案例弹层增加来源快照，不覆盖电商工作台状态。
4. 移除重复右下角分析面板，验证任务中心仍可恢复任务。

## Task 2：分析生命周期与新网关

1. 为客户端截止时间、服务端截止时间、心跳失效和可重试错误新增失败测试。
2. 将分析调用接入统一 AbortSignal 与分类错误。
3. 更新运行时网关契约和安全验证，使用新识图端点。
4. 执行不打印凭据的真实图像输入探测。

## Task 3：响应式图片管线

1. 为候选宽度、`srcset/sizes`、原图回退、预解码和缓存头新增失败测试。
2. 扩展服务器派生图接口和稳定版本 URL。
3. 重写共享图片组件，按容器与 DPR 选择候选并支持高清预取。
4. 接入案例、详情、作品和画布，不降低视觉清晰度。

## Task 4：画布交互内核

1. 将高频拖动位置与持久化草稿解耦，连接线与节点共享世界层。
2. 为拖动中端点、结束保存、选择/悬停/淡化和端口动作增加模型测试。
3. 重构空画布、顶栏、左栏、底部工具、缩放和快捷键。
4. 实现图片节点单击拖动、双击预览、右键菜单、上下文工具栏和节点下方编辑器。

## Task 5：电商信息架构

1. 只保留图片、文本、电商套图派生动作。
2. 按白底、主图、详情、SKU、素材横向泳道布局。
3. 保留商品原图、用途、比例和像素尺寸；清除默认线标签。
4. 统一重新生成、反推提示词和局部编辑的上下文面板。

## Task 6：视觉与可访问性验收

1. 为首页参数布局和 AI 按钮补齐统一样式状态。
2. 在 1440x900、1920x1080 和 390x844 下检查文本、工具栏和节点无重叠。
3. 检查键盘焦点、按钮语义、加载/错误/空状态。
4. 采集桌面与移动截图、canvas 像素非空检查、控制台和失败请求证据。

## Task 7：完整发布

1. 运行聚焦测试、全量测试、构建、`npm run check`、协作检查和 diff 检查。
2. 显式暂存本任务文件并提交，不包含运行时文件和无关删除。
3. 使用唯一生产部署脚本更新网关与代码。
4. 验证健康、账务、真实分析/生成、作品、画布和图片请求。
5. 观察窗口通过后更新进度账本并关闭目标。
