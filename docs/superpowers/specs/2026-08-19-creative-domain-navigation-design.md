# 薯包创作域导航设计

## 背景与目标

薯包目前已经形成电商视觉、视频创作、小红书图文和自由视觉四个创作域，同时拥有画布和作品两个跨域工作台。现有左侧四图标导航只能表达“有几个入口”，不能让首次用户理解产品范围，也无法从入口直接发现各域内部技能。

本次目标是增加一套面向创作意图的主导航，让用户在首页和浏览案例时都能快速回答三个问题：我可以做什么、每个方向有哪些入口、点击后会从哪里开始创作。

## 产品身份与信息架构

薯包定位为“从素材出发、按创作意图组织视觉内容的 AI 创作工作台”。导航不按内部页面或模型分类，而按用户要完成的工作分类。

一级导航固定为：

1. 电商视觉
2. 视频创作
3. 内容发布
4. 自由视觉
5. 工作台

视频创作暂时只显示为一个完整创作域。智能成片、首尾帧、参考视频重构属于视频工作台内部能力，本次不在导航面板中拆分，避免提前固化仍在演进的分类。

工作台不是创作域，包含画布和作品；画布继续使用现有 `OPEN_CANVAS`，作品继续使用现有 `OPEN_CANVAS({ tab: 'works' })`。

## 桌面端交互

- 首页和非画布页面使用新的顶部主导航；画布页面保留画布自身的专用 Chrome，不叠加全局导航。
- 顶部导航使用半透明暖白材料、细边框和轻微背景模糊，形成独立的功能层；内容区保持现有暖白、彩色案例视觉。
- 默认状态是 72px 左右的浮动条；页面向下滚动超过 32px 后压缩为 60px，并降低透明度变化，保证案例浏览时仍能辨认入口。
- 鼠标进入一级入口约 80ms 后打开面板；鼠标离开导航和面板整体约 180ms 后关闭，避免跨越间隙时闪烁。
- 一级入口点击直接进入该创作域默认工作台；有子菜单时点击箭头区域或再次点击可打开菜单，悬停只负责发现，不阻断直达。
- 面板使用两列：左侧显示创作域身份、说明和主操作，右侧显示该域的可用入口。内容域的条目最多一层，不出现三级嵌套。
- 面板不依赖图片才能完成导航；案例缩略图若出现，只作为视觉提示，加载失败不影响入口。
- 右侧保留积分/登录/管理后台；不重复显示旧 Navbar 的隐藏导航。

## 导航内容

### 电商视觉

- 商品套图：进入首页电商工作台
- 万物上身：进入首页电商工作台并选择上身能力
- 电商画布：进入画布

### 视频创作

- 视频创作：进入 `video-studio`

### 内容发布

- 小红书图文：进入首页并切换内容模式
- Plog 生活记录：进入首页内容模式，选择 Plog

### 自由视觉

- 自由创作：进入首页并切换自由视觉模式
- 海报设计、社媒封面、品牌主视觉：进入自由视觉工作台并选择对应 Skill

### 工作台

- 无限画布：进入 `ec-canvas`
- 我的作品：进入 `ec-canvas` 的作品页签

## 移动端与无障碍

- 640px 以下隐藏桌面 Mega menu，使用全高右侧抽屉；创作域按手风琴展开，一次只展开一个域。
- 抽屉底部固定“开始创作”主按钮，避免用户在长菜单中失去行动入口。
- 一级项和所有入口都是真实按钮或链接，触控目标不小于 44px。
- 支持 Tab、Enter/Space、Escape 和上下方向键；普通鼠标 hover 不强制抢焦点。
- 使用 `aria-expanded`、`aria-controls`、`aria-current` 和清晰的 `aria-label` 表达状态。
- `prefers-reduced-motion: reduce` 时关闭位移、弹簧和模糊过渡，只保留可辨认的显隐与焦点状态。

## 稳定性边界

- 导航只调用已有 `NAVIGATE`、`SET_MODE`、`OPEN_CANVAS` 和登录意图动作。
- 未登录用户进入需要登录的页面时沿用现有登录弹窗，不在导航层复制鉴权逻辑。
- 不新增网络请求；菜单内容由静态配置生成。
- 菜单打开/关闭不触发生成、计费、作品读取或路由重构。

## 验收标准

- 桌面端可从五个一级域直达现有创作入口；视频导航只显示一个视频创作入口。
- 首页首屏不再出现左侧四个重复的主入口；画布页面不被全局导航遮挡。
- 滚动前后导航尺寸、层级和 active 状态稳定，无横向溢出。
- 鼠标、键盘和触控均可打开并关闭菜单；Escape 能返回触发项。
- 移动端抽屉可完整访问所有入口，底部主操作不被内容遮挡。
- `npm test`、`npm run check`、`npm run build` 通过，且浏览器桌面/390px 移动端无控制台错误。
