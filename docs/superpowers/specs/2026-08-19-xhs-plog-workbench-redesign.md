# 小红书图文与 Plog 工作台重做设计

## 目标

重做首页小红书图文工作台，使种草图文和 Plog 生活碎片共用电商生图工作台的布局、上传卡片、按钮、面板、间距、状态和响应式规则；保留厦门 3 天 2 夜真实 9 张案例及完整发布内容，Plog 案例暂时使用明确空状态。

## 范围

- 修改首页 `Home` 的小红书图文与 Plog 创作入口。
- 保留现有小红书图文、Plog 的生成接口、素材上传角色、作品保存、额度逻辑和发布预览弹窗。
- 重做能力切换卡、案例区、素材上传区、输入区、配置按钮条和向上展开面板的视觉与布局。
- 不修改独立 `/plog` 页面。
- 不引入电商专属的生产验收、生产红苹果或电商质量检查。
- 不在验收过程中调用生产生图供应商、扣除积分或创建真实生成任务。

## 设计

### 1. 能力切换

在小红书工作台最上方放置两个与电商能力选择器同构的卡片：

- `种草图文`：使用厦门真实案例中的若干缩略图组成扇形展开预览，选中态使用小红书红色强调边框/底部色带和清晰勾选状态。
- `Plog 生活碎片`：保持同样尺寸、位置和交互，案例未入库时展示稳定的“案例暂未入库”空状态，不使用虚构图片。

切换卡片只改变创作模式和对应的输入配置；真实案例区在种草模式展示厦门案例，在 Plog 模式展示同尺寸的“案例暂未入库”空状态。

### 2. 真实案例区

厦门 3 天 2 夜案例是唯一保留的真实案例。案例区使用完整 9 张发布图的九宫格/拼图预览，右侧呈现完整标题、正文、标签和“查看完整发布预览”入口。删除案例区内部重复的种草/Plog切换按钮，避免能力选择出现两次。

发布预览仍由现有 `NoteModal` 和 `buildXhsPublishPages` 数据链路负责，点击缩略图支持打开对应图片，不改变现有键盘和关闭行为。

### 3. 创作工作台

案例区下方为一个连续的白色工作台容器，内部结构参照电商生图：

1. 素材上传卡片：种草模式显示“我的素材”和“风格参考”，Plog 显示“生活素材”和“风格参考”；复用 `SupplementAssetDeck` 的卡片尺寸、标签行、缩略图、添加入口、删除入口、提示文案和空状态。
2. 一句话输入区：保持现有文本状态和插入素材提及能力，改为电商工作台同样的边界、留白和占位文案层级。
3. 底部配置条：按钮使用电商工作台的触发器、摘要、打开态和间距；配置面板定位在按钮条上方，箭头朝上，面板向上展开。

### 4. 本地化配置

种草图文配置项：

- 发布结构：固定 1 张封面 + 8 张内容图，并交付标题、正文和标签。
- 热门主题：提供现有 `QUICK_HINTS` 作为可选起点，选择后回填输入框。
- 视觉参考：解释“我的素材”与“风格参考”的职责，不改变生成请求。

Plog 配置项：

- 发布结构：固定 9 张生活碎片，并交付标题、正文和标签。
- 内容风格：沿用现有 Plog 风格选项。
- 图片节奏：沿用现有 Plog 排版选项。

所有面板关闭时只显示本地化摘要；打开时有稳定的向上箭头和明确的选中态，不能使用电商专属文案或验收控件。

## 代码边界

- `src/pages/Home/XhsContentMode.jsx`：组合新的小红书能力选择器、案例展示和统一工作台结构，保留现有生成/上传/保存状态逻辑。
- `src/pages/Home/CreationShowcase.jsx` 与对应 CSS：将厦门案例和 Plog 空状态适配为能力切换后的展示内容，删除案例内部的重复模式切换。
- `src/pages/Home/ec/components/SupplementAssetDeck.jsx`：仅在确有小红书需求时增加通用视觉参数，不改变电商默认行为。
- `src/pages/Home/Home.css`：新增小红书工作台的结构化 class、桌面/390px 断点和向上面板层级；不通过继续堆叠内联样式解决布局。
- `test/`：增加针对 DOM 结构、模式切换、空状态、面板方向和无生产调用的本地回归覆盖；沿用项目现有测试工具和命名。

## 验收

- `npm test` 或仓库当前等价的全量回归通过。
- `npm run build` 和 `npm run check` 通过。
- 桌面截图确认：能力卡在顶部、种草卡扇形展开、Plog 空位稳定、案例内容完整、上传区和按钮条采用电商同款骨架、面板向上展开且箭头朝上。
- 390px 截图确认：无横向溢出，能力卡可滚动/适配，上传卡片和输入区不重叠，按钮摘要和面板文字不溢出。
- 测试或浏览器验收不得调用生产生图接口、扣除积分、创建真实任务或依赖生产环境状态。
