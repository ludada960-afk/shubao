# 流影式电商画布与图片性能重构规格

日期：2026-07-31

## 1. 目标

在不改写薯包既有电商生成、作品、账务和项目版本契约的前提下，重构无限画布的表现层与交互内核，修复首页配置、案例返回、分析任务和图片交付链路中的用户可见缺陷。最终产品面向电商商家、美工设计师和小红书创作者，不使用面向开发者的解释性文案。

## 2. 研究结论

### 2.1 竞品交互

- 流影 AI 使用低干扰画布外壳：细顶栏、左侧节点入口、底部全局工具、左下缩放、中央空状态。
- 节点默认保持安静；悬停时强化当前节点及关系，选中时显示边框、控制点、上下文工具栏和紧邻节点的生成面板。
- 节点端口的 `+` 菜单只呈现可从当前素材派生的动作；生成状态直接落在目标节点，不另开脱离画布的流程页。
- BigBong 的图片节点具备单击选中、直接拖动、双击大图、右键紧凑菜单和顶部上下文工具栏。

### 2.2 性能根因

- 线条延迟不是画布框架能力限制，而是拖动期间把高频位置写入广域 React 状态、连接层与节点层不同步，以及持久化工作混入每帧更新。
- 图片模糊来自固定 `thumb` 派生图被拉伸到大容器；图片慢来自没有按容器/DPR 选择尺寸、详情打开前没有预取解码、远端原图与代理变体缺少稳定版本关系。
- 案例关闭跳首页来自结果弹层直接覆盖全局 `result/genState`，没有保存来源工作台和步骤。
- SKU 空数组仍高亮来自历史 `smartOverrides` 标志，而不是当前有效配置差异。
- 分析卡死来自客户端和服务端缺少统一截止时间、心跳失效状态和可恢复错误分类。

## 3. 产品与视觉规格

### 3.1 画布外壳

- 顶栏：返回、项目名、自动保存状态；右侧为筛选、导出和保存等明确命令。
- 左侧：添加图片、从作品导入、电商套图、文本四类入口；不显示视频、音频或工作流。
- 底部中间：选择、抓手、图片、文本；熟悉图标优先，文字只用于明确命令。
- 左下：缩放百分比、缩小、放大、适配画布。
- 空画布：中央提供“双击添加商品素材”，下方提供“上传商品图”“从作品导入”“生成电商套图”。

### 3.2 节点状态

- 默认：中性细边框、轻阴影、完整图片比例。
- 悬停：当前节点轻微抬升，直接关系保持清晰，无关节点降至 45% 不透明度。
- 选中：品牌蓝描边与稳定尺寸控制点；顶部显示上下文工具栏；右侧端口显示 `+`。
- 生成中：目标节点内部显示可感知进度光带和状态文字，布局尺寸不变化。
- 单击图片主体可选中并拖动；双击打开高清预览；右键显示复制、下载、加入引用、删除等紧凑菜单。

### 3.3 连接与布局

- 节点位置和连接线位于同一变换世界层。
- 拖动时通过本地指针状态和 `requestAnimationFrame` 更新，连接端点同帧跟随；只在拖动结束时保存草稿。
- 默认连接线不显示“素材关系”等冗余标签；仅在有业务分支含义且用户选中时显示。
- 商品原图作为左侧源节点；输出按白底图、主图、详情图、SKU、素材分为横向泳道。
- 节点尺寸按真实比例计算，显示用途、比例和像素尺寸；不得裁掉图片主体。

### 3.4 节点派生面板

- 选中图片后在节点下方显示紧邻的提示词编辑器，包含引用素材、模型、比例、数量和生成命令。
- `+` 端口只提供文本生成、图片编辑、电商套图三类薯包能力。
- 反推提示词、重新生成、局部编辑等动作使用同一上下文面板，不使用固定右下角弹窗。

## 4. 首页与工作流修复

- SKU 高亮由当前非空 SKU 配置推导；删除最后一个 SKU 后立即恢复智能默认态。
- “恢复智能方案”位于参数工具第二行，不挤压主操作；“下一步”始终留在主操作行右侧。
- “重新分析四个方向”和“AI 润色补充说明”具备明确边框、图标、悬停、按下、键盘焦点和忙碌态。
- 打开案例前记录页面、模式、电商步骤和当前草稿；关闭案例精确恢复，不能跳首页或清空第二步。
- 全局生成任务只保留左侧任务中心；移除重复的右下角电商分析指示器。
- 分析任务有明确阶段、心跳、客户端截止时间、服务端截止时间、可重试错误和取消能力；不能无限停留在“正在分析商品”。

## 5. 图片交付与加载

- 原图是单一事实源，派生图只做展示缓存，不替换作品原图。
- 服务器提供稳定的 320、640、960、1600 宽度 WebP/AVIF 候选，并保留完整原图回退。
- 客户端通过 `srcset`、`sizes`、容器尺寸和 DPR 选择候选；首屏关键图可提高优先级，其他图片惰性加载。
- 列表占位固定宽高以防布局跳动；高清候选完成 `decode()` 后再原位替换。
- 悬停案例时预取详情所需尺寸；点击后优先使用已解码资源，同时后台加载原图。
- 任何缩略图不得被放大超过对应 DPR 所需分辨率。

## 6. 网关与安全

- 生产只保留两套逻辑凭据：65535 GPT-Image-2 生图和 `hgapi.dieqiyun.top` 识图/设计方向。
- 新识图 Key 仅通过运行时环境注入，不写入 Git、日志、测试快照或错误消息。
- 切换前执行一次模型/图像输入探测；只重试 429 和 5xx，永久错误立即失败。
- 配置更新必须原子写入并保留受保护备份；部署失败恢复代码和运行时配置。

## 7. 验收标准

- SKU 新增后删除最后一项，按钮不高亮且摘要恢复默认。
- 从第二步打开并关闭任一案例，仍停留第二步且编辑内容不丢失。
- 分析超时后 90 秒内出现可重试错误，不存在无限加载。
- 首页仅有一个电商任务进度入口。
- 案例列表在桌面和移动端显示清晰，详情打开有预解码证据，不卡白屏。
- 画布节点可直接拖动，拖动过程每一帧连接端点保持贴合；单击、双击、右键、端口派生均通过真实浏览器验收。
- 白底、主图、详情、SKU、素材按横向泳道排布并显示正确比例/尺寸。
- 全量测试、生产构建、协作检查、桌面/移动截图、控制台和失败请求检查全部通过。
- 通过 `scripts/deploy-production.ps1` 部署；生产健康、网关探测、生成任务、作品、画布恢复与图片加载验收通过。
