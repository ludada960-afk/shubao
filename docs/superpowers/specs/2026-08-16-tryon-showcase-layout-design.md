# 万物上身展示成片与预览居中设计

## 目标

让“万物上身”首屏成片复刻参考图的视觉关系：左侧展示完整服饰套装，右侧展示四张完整模特角度图，内容填充 16:9 展示框且不发生裁切；点击任意成片后，预览弹窗在视口中水平、垂直居中。

## 设计

- 合成脚本的多角度成片使用完整的 `editorial-flatlay-v3.webp` 作为左侧商品素材，不再使用两侧已被裁切的 `product-flatlay.png`。
- 左侧商品面板采用接近 3:4 的完整卡片，放大到与参考图相当的视觉权重；素材使用 `contain`，保证帽子、手袋、鞋履和服装边缘全部保留。
- 右侧沿用正式生产的四张角度图，保持完整全身比例，以轻微左右旋转和重叠形成浅扇形；四张图之间保留单一弧形箭头，表达商品到上身结果的关系。
- 合成画布仍为 1600x900，展示组件仍以 16:9 `contain` 显示并可点击放大；不改变案例 ID、任务来源或 CDN 版本参数。
- 预览遮罩使用 grid 居中对齐，预览内容最大高度受视口约束；内容超过视口时由弹窗内部滚动，关闭、左右切换和键盘操作保持现状。

## 验收

- 左侧服饰素材在成片中完整可见，左右边缘不裁切，卡片宽度与参考图的视觉比例接近。
- 右侧四张模特图完整可见，四张图均保留头部、衣摆和鞋履，扇形展开不超出 16:9 画布。
- 桌面和移动端展示框无横向溢出，成片点击后预览内容在视口中心显示。
- 相关合成、案例目录和 UI 契约测试通过；完整测试、构建和生产部署验证通过。
