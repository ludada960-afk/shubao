## 2 · 初步判断（总监视角）

1. **产品力可，但商业化"最后一公里"未通。** 技术债基本清完（1450+ 测试、生产 27/27 审计、月度 6+ 次发布），但商业化只有 2 个内测账号，**真正考验付费/复购/退款的真用户流尚未跑通**。总监 P0 是"让真用户买一次视频"。
2. **定价终案的最大风险是"标准档 ¥11.9"**——毛利 54.4% 唯一破主力门禁，且依赖 IP233 价不变；上游涨 1 毛即变负毛利。**要么 A/B 验证后上调到 ¥12.9，要么先把 IP233 廉价通道接进来当 failover**，二选一，30 天内必须落地一个。
3. **H3-2K 是利润王炸 + 长期对冲**——成本 ¥0.76、毛利 91.9%、可吸收 7.25 倍涨价，但首账单未校准、长条 token 单耗未测，**对外宣传前必须做完一次真实生成对账**。
4. **视频画布 P2 缺口是"完成度"而不是"创新度"**：决策卡队列、改稿对话、trim 手柄、ffmpeg 导出——全是工程活，3–5 周可拿下，对标 PixVerse 形态做差异化（一致性锁+审批门）的护城河。
5. **"对标 liblib ¥5/条"是伪命题**：liblib 靠包月积分池+31 天清零摊薄，照抄必亏；薯包应学其**会员制结构 + 每日签到送积分**（TapNow 每周 40 点 / 小云雀每日 60–100 积分先例），不学其单价。
6. **月卡 ¥39/¥59 是现金流 + 客户教育的最佳起步**：预付 150–225 积分锁住首批付费用户，赠分限图=强制把用户带到"电商生图"主力 SKU，是比一次性付费更稳的留存钩子。
7. **小红书/抖音/微信视频号还没开张**——薯包目前只做"工具"，还没做"内容"。XHS/Plog 提示词已落库是天然素材源；下一步是把"薯包出品"做成可投放的种草内容，反哺工具流量。
8. **GLM 不能碰核心代码**——所有上述判断落到代码必须由 Codex 走 RTK.md §2 隔离规则；本简报不动代码，只给"决策点 + 等待授权"。

## 4 · TapNow 整合建议（用 P0/P1/P2 路线图消化）

TapNow 形态（Agentic 创意无限画布 + 多模型聚合 + 决策卡）已在 2026-08-25 蓝图被裁定为"借鉴 + 超越"，薯包不是复制而是按 Flova/TapNow 骨架做差异化。**不引入第二套基础设施**。

整合路径（按 2026-08-26 审计 P2 裁定）：
1. **跨域投递桥**（已完成契约，缺 UI）：EcCanvas 节点菜单 + Works 作品卡加"发往视频项目"按钮，零新 API。**W3 D11 落地。**
2. **TTS→音轨→字幕初稿**：唯一需新供应商接入的项，单独过计费与合规评审，MiniMax TTS 优先（已有合作）。**W4 D12 落地。**
3. **画布音频节点**：在节点三类（素材/镜头/候选）外加 audio card，复用 asset 引用语义；框选音频+镜头=配乐/口播绑定。**W4 D12 顺带。**
4. **导出渲染 MVP**：ffmpeg worker 混音+字幕烧录，验收锚点=全程画布内完成。**W4 D13 落地。**
5. **不做**：成片自动回流素材库（RTK 已裁定手动入库）、视频候选回贴 EcCanvas（P3 后再看）、模板社区与 Marketing Hub 引导流（待内容运营就绪）。
