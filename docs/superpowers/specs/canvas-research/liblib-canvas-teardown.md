## §0 速览 / TL;DR

Liblib 的画布（也叫"灵感画布 / 创作工作台"）和 TapNow 路线不同：
- **画布是"无限网格 + 节点图"**
- 节点类型偏**模型 / LoRA / ControlNet 优先**（社区基因）
- 内置**大量国内模型**（哩布自研 + 通义 / 智谱 / 混元 + 国外 Flux / SDXL）
- **画廊 / 作品流是画布外的核心**（社区首页）→ 画布是"深度创作"模式
- **提示词模板广场**比 TapNow 更细（标签 + 风格 + 反向词）
- 视频节点（文生视频/图生视频/补帧）已实装
- 协作：偏弱（无强实时 CRDT，但有"作品-克隆"机制）

> **真机实拍前都是基于产品公开资料/官方教程/作品集整理**

## §1 [PUB] 画布骨架（A 类）

### 1.1 无限画布 + 网格底
- 和 TapNow 类似，无限画布
- **底色：深色为主**（#0E0E10 风格，社区基因）
- **有非常淡的网格底**（每隔 50px 一个像素点）
- 网格是装饰性，可关闭

### 1.2 缩放
- 范围：10% ~ 800%（比 TapNow 上限更高，适合检查像素）
- 快捷键：Ctrl + `+` / `-` / `0`
- 鼠标：Ctrl + 滚轮
- 右下角缩放比例器：可点击预设（25/50/100/200/适应屏幕）

### 1.3 平移
- 空格 + 拖拽
- 鼠标中键
- 触控板两指

### 1.4 选区
- 单击 / 框选 / Shift 多选（同 TapNow）
- 双击节点进入"焦点模式"（节点占满画布）
- Alt + 拖拽复制节点

### 1.5 minimap
- 右下角 minimap（可隐藏）
- minimap 比例固定（不可调）
- minimap 中节点用色块表示（不同类型不同颜色）

### 1.6 标尺
- 顶部有**水平标尺**（px 单位）
- 左侧有**垂直标尺**（px 单位）
- 标尺样式：灰底 + 黑刻度 + 数字
- 鼠标在画布上时，标尺会显示当前位置（红色高亮线）

## §2 [PUB] 节点库 + 加号菜单（B 类）

### 2.1 节点类型（与 TapNow 差异）

| 节点类型 | Liblib 独有性 | 说明 |
|----------|---------------|------|
| **模型节点** | ✅ Liblib 强项 | 直接选具体 checkpoint（不只是风格预设） |
| **LoRA 节点** | ✅ Liblib 强项 | 社区 LoRA 库（哩布自营 + 第三方） |
| **VAE 节点** | ✅ Liblib 强项 | 单独 VAE 选择（vae-ft-mse 等） |
| **采样器节点** | ✅ Liblib 强项 | 显式采样器节点（不藏在参数里） |
| **CLIP Skip 节点** | ✅ Liblib 强项 | 高级用户最爱 |
| **提示词模板节点** | ✅ 社区基因 | 公开模板广场 |

### 2.2 加号子项（点击 +）

```
[+] 媒体
   ├─ 上传图片
   ├─ 上传视频
   └─ 从素材库
[+] AI 模型
   ├─ 文生图（模型选择器）
   ├─ 图生图
   ├─ 局部重绘
   ├─ 扩图
   ├─ ControlNet
   └─ 高级（采样器/VAE/CLIP 节点）
[+] 风格
   ├─ LoRA 选择器
   ├─ 参考图风格迁移
   └─ 反向提示词模板
[+] 文本
   ├─ 纯文本
   └─ 提示词片段（snippet）
[+] 数据
   ├─ 公共提示词模板
   └─ 我的收藏
[+] 工作流
   ├─ 从模板新建
   └─ 从历史新建
[+] 注释
   ├─ 便签
   └─ 框选
```

### 2.3 拖动行为
- 同 TapNow（拖文件 → 自动创建节点）
- 拖动**模型卡**到画布 → 创建模型节点（可拖到 AI 节点的模型输入端口 = 切换模型）
- 拖动**LoRA 卡**到画布 → 创建 LoRA 节点

### 2.4 搜索 / 收藏
- 加号菜单顶部搜索（按节点名 / 关键词）
- 节点右键"收藏"
- 收藏的节点出现在加号菜单顶部"我的收藏"

## §3 [PUB] 多模态资产（C 类）

### 3.1 图片节点
- 支持：jpg/png/webp/avif
- 缩略图：自动 512px（比 TapNow 大，方便看细节）
- 双击查看大图 / 全屏
- 节点属性：位置 / 尺寸 / 旋转 / 不透明度 / 混合模式 / 锁定
- **额外属性**：采样信息（用了哪个模型/LoRA/采样器）— 这是 Liblib 特色，
  因为社区用户很在意"这张图是怎么生成的"

### 3.2 视频节点
- 支持：mp4/mov
- 抽帧缩略图（1s 间隔）
- 节点属性：位置 / 尺寸 / 播放头 / 静音 / 自动播放 / 循环 / **参数记录**

### 3.3 文本节点
- 两种：纯文本 / 提示词片段（snippet）
- snippet 节点是 Liblib 特色：可包含 `{占位符}`，被其他节点引用时自动填入
- 例：`{主体}在{场景}里，{风格}` = 参数化模板

### 3.4 蒙版
- 与 TapNow 类似（不是独立节点，是图节点属性）
- 笔刷大小 / 硬度可调
- 蒙版可"反转"

### 3.5 参考图（IP-Adapter）
- 图片节点右键"设为参考图"
- 强度可调（0~1）
- 可同时挂多张（多参考图混合）

### 3.6 ControlNet
- 多种类型：深度 / Canny / 姿态 / 线稿 / 颜色 / **Tile**
- Tile 是 Liblib 强项（高清修复常用）
- ControlNet 是独立节点（不是图节点属性）

## §4 [PUB] AI 能力（D 类）

### 4.1 文生图（T2I）
- **模型选择是核心**：
  - 哩布自研（多个）
  - SDXL / SDXL-Turbo
  - Flux.1 Dev / Schnell / Pro
  - Stable Diffusion 3
  - 通义万相
  - 智谱 CogView
  - 字节豆包
  - 混元
- **采样器选择是独立面板**（不藏在参数里）：
  - Euler / Euler a
  - DPM++ 2M Karras / SDE Karras
  - UniPC / DPM++ SDE
  - LCM（实时）
  - DDIM
- 参数面板：
  - 步数（1~150）
  - CFG Scale（1~30）
  - **CLIP Skip（1~4）** ← 高级用户
  - Seed（可锁定）
  - 分辨率（presets + 自定义）
  - 批次（1~8）
  - **图片数量**（一次多张）

### 4.2 图生图（I2I）
- 强度（denoise）：0~1
- 修复模式：整图 / 仅蒙版
- 提示词 / 负提示词

### 4.3 局部重绘
- 必填：原图 + 蒙版
- 选填：参考图、ControlNet
- **采样器**、**模型**、**LoRA** 都可独立选

### 4.4 扩图
- 4 方向 / 比例
- 输出可设分辨率上限（避免超出）

### 4.5 高清修复（Hires.fix / Upscale）
- 多种算法：ESRGAN / 4x-UltraSharp / RealESRGAN / NMKD
- 1.5x / 2x / 4x
- **这是 Liblib 强项**（社区用户很在意）

### 4.6 ControlNet
- 多种类型 + 可叠加（多 ControlNet）
- 控制强度独立可调

### 4.7 LoRA
- 社区 LoRA 库（公开）
- 权重：-2 ~ 2（Liblib 允许负权重，独有）
- 多 LoRA 叠加（不同模型可不同 LoRA）

### 4.8 视频生成
- 文生视频（多种模型）
- 图生视频
- 视频补帧（2x/4x/8x）
- 视频抠像

### 4.9 AI 工具节点 UX
- 三栏：左输入 / 中参数 / 右输出
- 底部状态条
- 失败就近显示
- 完成后可"自动插入"或"手动放置"

## §5 [PUB] 协作 / 版本 / 撤销 / 多创串联（E 类）

### 5.1 撤销 / 重做
- 节点级 + 画布级
- 撤销栈深度通常 100 步（比 TapNow 深）

### 5.2 历史版本
- 顶栏"历史"→ 时间轴侧栏
- 自动保存间隔：3 分钟（比 TapNow 频繁）
- 快照可"恢复" / "另存为新画布" / "导出为 JSON"

### 5.3 协作
- **不强实时 CRDT**（弱于 TapNow）
- 主要协作模式：**作品-克隆**（发布画布为作品 → 他人克隆为副本 → 各自修改）
- 评论：节点级评论，可公开 / 私有

### 5.4 多创串联

**5.4.1 模板广场**
- 公开模板：按热度 / 最新 / 关注 排序
- 模板卡片：封面 + 标题 + 作者 + **完整参数**（可一键复刻）
- 使用模板 = 克隆到我的画布

**5.4.2 作品流（社区首页）**
- 不是画布内功能，但和画布深度联动：
  - 作品页有"在画布中打开"按钮
  - 作品页有"复刻参数"按钮（一键创建相同参数的画布）
- 这是 Liblib 的核心社区闭环：
  创作 → 发布作品 → 别人看到 → 复刻参数 → 自己创作 → 发布

**5.4.3 当前画布 → 复制 → 编辑**
- 节点右键"复制"= 复制节点
- 节点右键"复制为模板"
- 整画布"复制画布"

**5.4.4 多创串联路径**
1. 模板广场选模板
2. 在画布里修改
3. 保存为作品
4. 他人看到后复刻
5. 他人再修改
6. 循环

## §6 [PUB] 提交流（F 类）

### 6.1 数据流连线
- 同 TapNow：右侧输出 / 左侧输入 / 端口类型匹配
- **特殊**：模型节点可以"插拔"（拖到 AI 节点的模型端口 = 切换模型）

### 6.2 节点"发送到"
- 完成后输出区有"发送到"：
  - 发送到：图生图 / 局部重绘 / 扩图 / 抠图 / 视频 / ControlNet

### 6.3 导出
- 单节点：PNG / JPG / WebP / **JSON**（含完整参数）
- 多节点：合并导出
- 整画布：按 minimap 比例
- 视频：MP4（多种 fps）
- **参数导出**：导出为 JSON → 别人可一键导入复刻

### 6.4 共享
- 画布"分享"= 公开/私有链接
- **发布为作品**：进入社区流（带完整参数）

### 6.5 历史任务
- 节点"历史"标签
- 切换查看历史
- 恢复历史

### 6.6 失败重试
- 失败状态条
- 重试按钮
- 错误信息可展开

## §8 [PUB] 关键发现 / 启发

1. **模型 / LoRA / 采样器是一等公民**
   Liblib 把 SD 时代的"高级参数"全拆成了独立节点 → 极度友好的硬核用户
2. **采样信息存进图片节点**
   每个生成的图节点都带完整参数 → 复刻社区的核心机制
3. **JSON 导出 + 一键导入**
   比 TapNow 更进一步：把"画布"变成可复刻的纯文本 → 跨用户复刻
4. **作品流（社区）→ 画布 → 作品流**
   三方闭环是 Liblib 的最大护城河，画布只占 1/3
5. **提示词片段（snippet）参数化**
   `{主体}在{场景}` → 让模板更可复用
6. **高清修复是常规操作**
   不藏在高级菜单 → 鼓励用户提质
7. **多 ControlNet 叠加**
   比 TapNow 强：同一 AI 节点可挂多个 ControlNet
