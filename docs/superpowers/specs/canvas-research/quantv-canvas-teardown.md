## §0 速览 / TL;DR

老鱼 quantv 的画布和 TapNow/Liblib 路线都不同：
- **画布核心是"视频 + 时间线"**，不是"无限节点图"
- 节点画布是辅助视图（用于策划/分镜），主视图是**时间线编辑器**
- 内置**镜头语言 / 运镜 / 转场**等视频专有概念
- AI 视频模型：可灵 / 通义万相 / Vidu / Sora / 字节豆包
- **故事板（Storyboard）模式**：把视频拆成一帧帧的图像节点
- 协作：偏弱（个人创作为主）
- 多创串联：弱（视频很难"模板化"，但有"剧本分镜"模板）

> **真机实拍前都是基于产品公开资料/官方教程整理**

## §1 [PUB] 画布骨架（A 类）

### 1.1 双视图：节点画布 + 时间线
- 顶部有切换：
  - **节点视图**（default）：无限画布，节点图
  - **时间线视图**（timeline）：横轴时间，纵轴轨道（视频/音频/字幕/特效）
- 两个视图是**同一份数据**的不同投影
- 切换时无缝（无需重新加载）

### 1.2 节点视图（同 TapNow）
- 无限画布
- 缩放 10%~400%
- 鹰眼（minimap）
- 选区工具

### 1.3 时间线视图（独门）
- 横轴：时间（秒 / 帧）
- 纵轴：轨道
  - V1 / V2 / V3 ...：视频轨道（可叠加）
  - A1 / A2 ...：音频轨道
  - T1：字幕轨道
  - FX1：特效轨道
- 帧单位：默认 24fps，可切 30/60
- 标尺：顶部时间标尺（红色播放头）
- 缩放：可调时间标尺比例（看 1 秒 / 看 1 帧）

### 1.4 故事板模式
- 在时间线视图上，每个视频片段**可折叠为一张图**
- 整条时间线 = 故事板
- 故事板是"画布"的另一种呈现

### 1.5 网格 / 标尺
- 节点视图：深色底，淡网格
- 时间线视图：固定时间网格

## §2 [PUB] 节点库 + 加号菜单（B 类）

### 2.1 节点类型（视频导向）

| 节点类型 | 说明 |
|----------|------|
| 视频节点 | 核心节点 |
| 图像节点 | 视频拆帧 / 关键帧 |
| 文本节点 | 字幕 / 标题 |
| 音频节点 | 配乐 / 配音 |
| **分镜节点** | 老鱼独有：1 镜头 = 1 节点 |
| **运镜节点** | 镜头运动参数（推/拉/摇/移） |
| AI 工具 | 文生视频 / 图生视频 / 视频补帧 / 视频抠像 |
| 特效节点 | 转场 / 滤镜 / 调色 |
| 数据 | 剧本节点 / 模板 |

### 2.2 加号子项（点击 +）

```
[+] 媒体
   ├─ 上传视频
   ├─ 上传图片（作为分镜）
   ├─ 上传音频
   └─ 从素材库
[+] AI 视频
   ├─ 文生视频
   ├─ 图生视频
   ├─ 视频补帧
   ├─ 视频抠像
   └─ 视频风格迁移
[+] AI 图像
   ├─ 文生图（用于分镜）
   └─ 图生图
[+] 文本
   ├─ 字幕节点
   ├─ 标题节点
   └─ 剧本节点
[+] 音频
   ├─ 配乐
   ├─ 配音（AI 语音）
   └─ 音效
[+] 视频特效
   ├─ 转场
   ├─ 滤镜
   ├─ 调色
   └─ 运镜
[+] 工作流
   ├─ 从模板新建（剧本分镜）
   └─ 从历史新建
[+] 注释
   └─ 便签
```

### 2.3 拖动行为
- 文件拖入 = 自动创建对应节点
- **视频节点可拖到时间线轨道** = 直接成片
- 音频拖到视频节点 = 配乐
- 字幕拖到视频 = 自动对齐时间

### 2.4 搜索 / 收藏
- 加号菜单顶部搜索
- 节点右键"收藏"

## §3 [PUB] 多模态资产（C 类）

### 3.1 视频节点（核心）
- 支持：mp4 / mov / webm（部分）
- 缩略图：抽 5 帧（首/25%/50%/75%/末）
- 双击：全屏播放
- 节点属性：
  - 位置 / 尺寸 / 旋转 / 不透明度 / 混合模式
  - **入点 / 出点**（裁切）
  - **播放速度**（0.5x / 1x / 2x）
  - **静音 / 音量**
  - **运镜参数**（独有）：推/拉/摇/移/跟

### 3.2 图像节点
- 同 TapNow：jpg/png/webp
- 缩略图：256px
- 双击查看大图
- 节点属性：位置 / 尺寸 / 旋转 / 不透明度 / 混合模式

### 3.3 文本节点
- 字幕节点（带时间码）
- 标题节点（卡片样式）
- **剧本节点**（独有）：长文本，可拆分为多段字幕

### 3.4 音频节点
- 配乐（背景音乐）
- 配音（AI 语音）
- 波形可视化

### 3.5 蒙版
- 视频节点支持**关键帧蒙版**（运动蒙版）
- 静态蒙版（图节点）

### 3.6 参考图
- 视频节点的"风格参考"
- 强度可调

## §4 [PUB] AI 能力（D 类）

### 4.1 文生视频（T2V）
- 模型：
  - 可灵 1.6（多种）
  - 通义万相视频
  - Vidu
  - 字节豆包
  - Sora（部分）
- 参数：
  - 提示词（必填）
  - 负提示词
  - 时长（4s / 8s / 12s）
  - 分辨率（720p / 1080p）
  - 帧率（24 / 30）
  - 镜头语言（推/拉/摇/移）
  - 风格（写实/动漫/水墨）
  - 运动强度（0~1）

### 4.2 图生视频（I2V）
- 必填：原图 + 提示词
- 其余参数同 T2V

### 4.3 视频补帧
- 2x / 4x / 8x
- 算法：RIFE / FILM / 自研

### 4.4 视频抠像
- 人物 / 主体
- 输出：透明背景视频 / 蒙版通道

### 4.5 视频风格迁移
- 参考视频 → 目标视频
- 强度可调

### 4.6 镜头语言（独门）
- 运镜参数：推/拉/摇/移/跟/固定
- AI 视频生成时显式选择
- 后期编辑可改

### 4.7 AI 工具节点 UX
- 三栏：左输入 / 中参数 / 右输出预览
- 视频输出：自动播放（带静音）
- 失败就近显示
- 完成后自动插入到时间线

## §5 [PUB] 协作 / 版本 / 撤销 / 多创串联（E 类）

### 5.1 撤销 / 重做
- 节点级 + 视频级
- 时间线操作的撤销很关键（误删轨道）

### 5.2 历史版本
- 顶栏"历史"→ 时间轴
- 视频类操作撤销栈更深（每个剪辑动作）

### 5.3 协作
- 弱（个人创作导向）
- 主要：项目分享链接（只读）
- 评论：节点级 / 时间线 marker

### 5.4 多创串联（弱）
- 视频很难"模板化"，但老鱼尝试了：
  - **剧本分镜模板**：10 个分镜的剧本 → 自动生成视频
  - **风格模板**：某种运镜 + 某种调色 → 应用到现有视频
  - **AI 配音模板**：某种音色 → 应用到字幕

### 5.5 多创路径
1. 从剧本模板开始（10 分镜）
2. 每个分镜 AI 生成视频
3. 时间线拼接
4. 调色 / 配乐 / 字幕
5. 导出

## §6 [PUB] 提交流（F 类）

### 6.1 数据流连线
- 视频节点的输出 = 时间线上的视频片段
- 文本节点 → 字幕节点（自动转时间码）
- 音频节点 → 配乐轨道

### 6.2 节点"发送到"
- 完成后"发送到"：
  - 发送到：补帧 / 抠像 / 风格迁移 / 时间线

### 6.3 导出
- 单视频：MP4（24/30/60fps / 720p/1080p/4K）
- 多视频：合并导出
- 时间线导出：完整成片
- **可导出项目文件**（.quantv）= 完整画布+时间线+参数

### 6.4 共享
- 画布"分享"= 链接（可设权限）
- "以作品发布"= 公开到平台

### 6.5 历史任务
- 视频节点"历史"
- 时间线版本

### 6.6 失败重试
- 视频生成失败：状态条 + 重试
- 自动重试：网络错误可自动重试 1 次

## §8 [PUB] 关键发现 / 启发

1. **双视图是核心创新**
   节点视图（策划）+ 时间线视图（剪辑）= 同一份数据两个投影
2. **镜头语言是一等公民**
   运镜参数（推/拉/摇/移）显式建模 = 视频创作的"专业感"
3. **故事板是画布的另一种呈现**
   时间线折叠 = 故事板 = "用画布思路做视频"
4. **AI 视频模型多**
   可灵 + 通义 + Vidu + Sora + 豆包 = 平台型产品
5. **多创串联偏弱**
   视频难模板化，但有"剧本分镜模板"作为切入点
6. **关键帧蒙版**
   运动蒙版 = 视频版的局部重绘
7. **项目文件 .quantv 导出**
   可移植的工程文件 = 让用户能备份 / 迁移
