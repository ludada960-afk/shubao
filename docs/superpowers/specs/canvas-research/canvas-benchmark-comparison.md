## §3 关键差异点深挖

### 3.1 TapNow 的"节点是画布一等公民"
- 一切皆节点 = 心智统一
- 节点内部是"迷你工作区"（输入/参数/输出）= 自包含
- 适合：复杂流程编排

### 3.2 liblib 的"模型参数是画布一等公民"
- 高级参数（采样器/VAE/CLIP）= 独立节点
- 采样信息存进图片节点 = 复刻社区核心
- JSON 导出 = 跨用户复刻
- 适合：硬核用户 + 社区闭环

### 3.3 quantv 的"镜头语言是画布一等公民"
- 运镜参数显式建模
- 双视图（节点+时间线）= 数据多投影
- 故事板 = 时间线的另一种呈现
- 适合：视频创作

## §4 薯包 v2 路线图（融合建议）

### 4.1 战略原则
1. **核心心智 = 节点 = 一等公民**（抄 TapNow）
2. **次级心智 = 采样信息 = 内置元数据**（抄 liblib）
3. **视频专享 = 镜头语言 = 一等公民**（抄 quantv）
4. **AI 能力分层 = 不让用户淹没在 100 个参数**
5. **多创串联 = 模板 + 节点复制 + 参数复刻**

### 4.2 薯包 v2 节点类型（最终建议）

```
[+] 媒体（基础）
   ├─ 图片节点
   ├─ 视频节点
   └─ 音频节点
[+] 文本（基础）
   ├─ 纯文本节点
   ├─ 富文本节点
   └─ 提示词片段节点（抄 liblib）
[+] AI 图像（核心）
   ├─ 文生图节点
   ├─ 图生图节点
   ├─ 局部重绘节点
   ├─ 扩图节点
   ├─ 抠图节点
   └─ 高清修复节点（V1.5）
[+] AI 视频（核心）
   ├─ 文生视频节点
   ├─ 图生视频节点
   ├─ 视频补帧节点
   ├─ 视频抠像节点
   ├─ **运镜节点**（抄 quantv，独门）
   └─ 视频风格迁移节点
[+] AI 风格（V1.5）
   ├─ ControlNet 节点
   ├─ 参考图风格迁移节点
   └─ LoRA 节点（V2.1）
[+] 数据
   ├─ 提示词模板
   ├─ 风格预设
   └─ 模型卡（V2.1）
[+] 工作流
   ├─ 模板
   ├─ 我的收藏
   └─ 历史
[+] 注释
   ├─ 便签
   └─ 框选
```

### 4.3 薯包 v2 视图（最终建议）

- **默认视图 = 节点画布**（无限画布 + 缩放 + 鹰眼 + 标尺）
- **视频模块 = 双视图**（节点画布 + 时间线切换）
- **故事板模式**（视频模块专属）
- **焦点模式**（双击节点）

### 4.4 薯包 v2 元数据（最终建议）

每个生成的图节点 / 视频节点都带：
- 生成时间
- 用了哪个模型 / LoRA / 采样器
- 完整参数 JSON
- 消耗积分
- 生成任务 ID（用于失败重试）
- **这是 liblib 采样信息的薯包版**

### 4.5 薯包 v2 提交流（最终建议）

- 数据流连线：节点右侧输出 / 左侧输入 / 端口类型匹配
- 节点"发送到"：
  - 通用：图生图 / 局部重绘 / 扩图 / 抠图
  - 视频：补帧 / 抠像 / 风格迁移 / 时间线
- 导出：
  - 单节点：PNG/JPG/WebP/MP4/JSON（含完整参数）
  - 多节点：合并导出
  - 整画布：按 minimap
  - **JSON 导出 = 跟 liblib 复刻机制**

### 4.6 薯包 v2 多创串联（最终建议）

1. **从模板开始**（V1.5 模板市场）
2. **节点复制**（V1）
3. **画布变模板**（V1.5）
4. **JSON 导入复刻**（V2，抄 liblib）
5. **作品流**（V3，抄 liblib 社区闭环）

### 4.7 薯包 v2 不做（明确取舍）

- ❌ 实时 CRDT 协作（V3 再考虑）
- ❌ 模型/VAE 独立节点（V2.1 之前不暴露给非硬核用户）
- ❌ 移动端深度适配（V1 只做响应式，不做 PWA 完整功能）
- ❌ 100+ 高级参数（V1 只暴露 8 个核心参数）

## §5 融合建议分阶段

### V1（立刻做）
- 节点画布 + 加号菜单（30+ 节点）
- 无限画布 / 缩放 / 鹰眼 / 标尺
- 6 大类资产（图/视频/音频/文本/提示词片段/数据）
- 6 大 AI 能力（图生图/局部重绘/扩图/抠图/文生视频/图生视频）
- 节点复制 / 画布复制 / 撤销重做 / 历史版本
- 失败就近显示 + deliberate retry
- JSON 导出（带完整参数）

### V1.5（1 个月后）
- 模板市场（官方 + 用户）
- ControlNet / 高清修复 / 视频补帧
- 评论 / 共享链接
- 作品发布（私有 → 公开）

### V2（3 个月后）
- 双视图（节点 + 时间线）
- 故事板模式
- 运镜节点（独门）
- AI 配音
- JSON 导入复刻
- LoRA 节点（实验）

### V2.1（4 个月后）
- 模型节点 / VAE 节点 / 采样器节点（高级用户面板）
- 移动端深度适配

### V3（6 个月后）
- 实时协作（CRDT）
- 作品流（社区闭环，抄 liblib）
- 公开模板市场（带审核）

## §6 风险与对策

| 风险 | 对策 |
|------|------|
| 节点太多用户淹没 | 分层：基础/核心/高级，V1 只暴露核心 |
| 模板质量参差 | 官方模板 + 用户模板 + 审核机制 |
| 视频生成成本高 | 默认不自动生成 + 显式扣费 + 失败就近 |
| 协作冲突 | V1 不做实时协作，V3 引入 CRDT |
| 移动端性能 | 移动端只读 + 简单编辑 |
