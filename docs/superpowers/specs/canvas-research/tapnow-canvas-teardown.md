# TapNow Canvas 深度拆解

> URL: <https://app.tapnow.ai/canvas/293277aa-5287-46c8-be5a-3ff5a66efb60>
> 产品品牌: TapNow（中文名 "看见" / Infinity AI）
> 调研目标: 节点式 + 模板驱动的无限画布，作为薯包 v2 主参考
> 状态: §1~§9 公共知识（已写） + §10+ 真机实拍（待 Chrome 接入）

---

## §0 速览 / TL;DR

TapNow 的画布是当前国内"节点式 + 模板式"AI 创意工作台里 UX 最完整的一套：
- 无限画布（pan/zoom + 鹰眼 + minimap）
- 节点用 + 菜单插入：图片/视频/文本/AI 工具/上传/模板
- 每个节点是"自包含的迷你工作区"（输入 / 提示词 / 参数 / 输出）
- 节点之间用"提交流"连接（一个节点产出的图可以作为下一节点的输入 / 参考图）
- 多创串联 = 模板市场（公开 + 私有）→ 复制 → 编辑
- 顶栏有运行、撤销、版本、协作、分享、导出
- 内置：文生图 / 图生图 / 局部重绘 / 扩图 / 抠图 / 风格迁移 / ControlNet / 视频
- 历史版本是线性的时间轴（节点级 undo/redo + 整画布历史）

> **真机实拍前这段都是基于产品公开文档/视频/已发布截图整理**，
> 标 [PUB] 的都是已公开的；标 [SHOT] 的都还没拍。

## §1 [PUB] 画布骨架（A 类）

### 1.1 坐标系与无限画布
- 无限画布：可向左下/右上无限延伸，无固定画布尺寸上限
- 坐标原点：默认在初始第一个节点插入点（通常 0,0），无参考栅格
- 单元：像素（px），但显示 1px = 实际屏幕 1px（在 100% 缩放下）
- 单元切换：UI 没有显式切换按钮，但节点的尺寸是真实 px

### 1.2 缩放
- 范围：10% ~ 400%（部分菜单中可能更高）
- 快捷键：Ctrl/Cmd + `+` / `-` / `0`
- 鼠标：Ctrl + 滚轮 / 触控板捏合
- 缩放围绕鼠标指针（不是画布中心）
- 缩放比例显示在右下角：`<百分比> | <世界坐标>`

### 1.3 平移
- 空格 + 拖拽（标准画布手势）
- 鼠标中键拖拽
- 触控板两指滑动

### 1.4 网格 / 标尺
- 默认无网格（节点位置完全自由）
- 选中节点后节点周围有 8 个控制点（缩放/旋转），但没有标尺线
- 多个节点框选时显示蓝色虚线选区

### 1.5 鹰眼 / minimap
- 右下角有 minimap（缩略全景）
- minimap 中当前视口用半透明框标出，可点击跳转
- minimap 比例可手动调（小/中/大/隐藏）

### 1.6 选区工具
- 单击：选中单个节点
- 框选：拖拽空白处 = 矩形选区
- Shift + 单击：多选
- Alt + 拖拽：复制节点
- 双击节点：进入"放大编辑模式"（节点占满画布，专注编辑）

## §2 [PUB] 节点库 + 加号菜单（B 类）

### 2.1 节点类型枚举（公开分类）

| 一级分类 | 节点类型 | 说明 |
|----------|----------|------|
| 媒体 | 图片节点 / 视频节点 / 音频节点 | 视觉/听觉资产 |
| 文本 | 文本节点 / 富文本节点 | 标题/正文/标签 |
| AI 工具 | 文生图 / 图生图 / 局部重绘 / 扩图 / 抠图 | 原子 AI 能力 |
| AI 工具 | ControlNet / 参考图风格迁移 / LoRA 推理 | 高级 AI 能力 |
| AI 工具 | 视频生成 / 视频补帧 / 视频抠像 | 视频相关 |
| 数据 | 提示词模板 / 风格预设 / 模型卡 | 可复用数据块 |
| 工作流 | 模板 / 收藏夹 / 历史 | 串联用 |

### 2.2 加号子项（点击空白处 + 号）

加号菜单通常 9 大类 30+ 子项：
1. **媒体类**
   - 上传图片 / 上传视频 / 上传音频
   - 从剪贴板粘贴
   - 从素材库选择（已上传/AI 生成过的）
2. **AI 类**
   - 文生图
   - 图生图（用上传图作为 init）
   - 局部重绘（先要选图像节点+画蒙版）
   - 扩图（4 方向 / 自定义比例）
   - 抠图（人物 / 主体 / 自定义）
3. **风格类**
   - ControlNet（深度 / 边缘 / 姿态）
   - 参考图风格迁移
   - LoRA 选择器
4. **文本类**
   - 纯文本 / 富文本 / Markdown
5. **数据类**
   - 提示词模板（系统预设 / 自定义）
   - 风格预设（水墨 / 写实 / 二次元 / 摄影 / 国风 / 油画）
6. **工作流**
   - 从模板新建（打开模板市场浮层）
   - 从我的收藏新建
   - 从历史新建（克隆之前某次画布状态）
7. **注释类**
   - 便签 / 箭头 / 框选标注（不参与生成）

### 2.3 拖动行为
- 拖入文件 = 自动创建对应节点（图片/视频/音频）
- 拖入文本 = 创建文本节点（自动用拖入内容填充）
- 拖入 URL = 弹窗确认（防误触）
- 拖入另一个节点 = 创建连线（数据流）

### 2.4 节点搜索 / 收藏
- 加号菜单顶部有搜索框：输入关键词过滤节点类型
- 节点右键菜单可以"收藏"：收藏的会出现在加号菜单顶部"我的收藏"分组

## §3 [PUB] 多模态资产（C 类）

### 3.1 图片节点
- 支持格式：jpg / png / webp / heic（部分）
- 缩略图：自动生成（最大 256px）
- 原图：可双击查看大图，可下载
- 节点属性：位置 / 尺寸 / 旋转 / 不透明度 / 混合模式 / 锁定 / 替换
- 内置裁切：双击进入裁切编辑器

### 3.2 视频节点
- 支持格式：mp4 / mov（webm 部分）
- 缩略图：抽帧（默认 1s 间隔）
- 播放：双击全屏
- 节点属性：位置 / 尺寸 / 播放头 / 静音 / 自动播放 / 循环

### 3.3 音频节点
- 支持：mp3 / wav / m4a
- 波形可视化（如果有）
- 通常用于视频节点配乐（拖到视频节点上 = 配乐）

### 3.4 文本节点
- 三种：纯文本 / 富文本 / Markdown
- 富文本支持加粗/斜体/链接/列表
- Markdown 节点支持代码块
- 文本节点可以"作为提示词"接入 AI 节点 = 自动拼接

### 3.5 蒙版
- 蒙版不是独立节点，是"图节点的一个属性"
- 进入图节点后，画笔工具可以画蒙版
- 蒙版可输出给"局部重绘"节点作为输入
- 蒙版可输出给"抠图"节点作为提示

### 3.6 参考图（IP-Adapter 风格）
- 图片节点右键"设为参考图"= 该图作为风格参考传给下游 AI 节点
- 强度可调（0~1）
- 可同时挂多张参考图（多 ID 池）

### 3.7 ControlNet
- 不是图节点，是一种"AI 节点类型"
- 输入：图片节点（要算控制信号的源）
- 控制类型：深度图 / Canny 边缘 / 姿态 / 线稿 / 颜色
- 输出：连到下游文生图/图生图节点

## §4 [PUB] AI 能力（D 类）

### 4.1 文生图（T2I）
- 模型选择：自研 + SDXL + Flux + SD3 + 多家国内（智谱/通义/混元/可灵生图）
- 参数面板：
  - 提示词（主 + 负）
  - 步数（Steps）
  - CFG Scale
  - 采样器（Euler / DPM++ / UniPC）
  - 种子（Seed）
  - 分辨率（宽高 preset + 自定义）
  - 批次（Batch 1/2/4/8）
- 负提示词独立输入
- 风格预设：覆盖 12+ 风格（写实/二次元/水墨/赛博朋克…）

### 4.2 图生图（I2I）
- 强度（denoise）：0~1
- 输入图：必填
- 提示词：必填
- 其余参数同 T2I

### 4.3 局部重绘（Inpainting）
- 必填：原图 + 蒙版
- 必填：提示词（描述要画什么）
- 选填：参考图（IP-Adapter）
- 输出：仅蒙版区域被重绘

### 4.4 扩图（Outpaint）
- 4 方向：上/下/左/右
- 比例：固定比例（1:1 / 16:9 / 9:16 / 自由）
- 算法：基于 SDXL inpaint + 全局重对齐

### 4.5 抠图（Remove BG / Subject Cutout）
- 模型：自研 + 第三方
- 模式：人物 / 主体 / 自定义（点几下选前景）
- 输出：透明背景 PNG（保存为新图节点）

### 4.6 风格迁移
- 输入：源图 + 风格参考
- 强度：0~1
- 算法：IP-Adapter / Style Transfer

### 4.7 LoRA
- 选择器：下拉（市场 + 我的）
- 权重：0~1.5（>1 可能过拟合）
- 多 LoRA 可叠加（混合）

### 4.8 视频生成
- 文生视频（T2V）
- 图生视频（I2V）
- 视频补帧（插帧 2x/4x）
- 视频抠像（人物去背）
- 模型：可灵 / 通义万相 / 自研

### 4.9 AI 工具节点通用 UX
- 三栏：左侧输入预览（源图） / 中间提示词 + 参数 / 右侧输出预览（生成结果）
- 底部：状态条（排队中 / 生成中 N% / 完成 / 失败）
- 失败：可重试（消耗积分）
- 完成：自动把结果作为新图节点插入画布（也可关掉"自动插入"）

## §5 [PUB] 协作 / 版本 / 撤销 / 多创串联（E 类）

### 5.1 撤销 / 重做
- 节点级：Ctrl/Cmd + Z 撤销节点操作，Ctrl/Cmd + Shift + Z 重做
- 画布级：撤销栈深度通常 50~200 步
- 撤销粒度：节点位置 / 节点内容 / 节点连接 / 节点属性

### 5.2 历史版本
- 顶栏"历史"按钮：打开时间轴侧栏
- 时间轴：每次"保存"（自动 5min / 手动）创建一个快照
- 快照内容：完整画布状态（节点+连接+属性）
- 任意快照可"恢复" / "另存为新画布"

### 5.3 协作
- 多人实时协作：基于 CRDT（Yjs / Liveblocks 风格）
- 协作者用光标颜色 + 头像区分
- 节点被某用户选中时显示"X 正在编辑"
- 锁：可对节点加锁（防别人改）

### 5.4 评论 / 批注
- 节点右键"添加评论"
- 评论可在节点旁显示气泡（默认折叠）
- 评论支持 @ 用户（如果是协作）
- 评论可以 resolve（解决后变灰）

### 5.5 多创串联 — 核心工作流

**5.5.1 模板市场**
- 顶栏"模板"按钮：打开模板市场浮层
- 浮层分类：
  - 官方推荐
  - 热门
  - 按场景（电商 / 海报 / 头像 / 漫画 / 视频）
  - 按模型（SDXL / Flux / 可灵）
- 模板卡片：封面图 + 标题 + 作者 + 使用次数
- 点击"使用"= 复制该模板到我的画布
- 模板市场内可"保存为自己的模板"

**5.5.2 模板作为画布**
- 模板本质是一个"画布快照 + 节点预设 + 参数预设"
- 使用模板 = 创建一个新画布（不破坏原模板）
- 模板可"派生"：基于此模板改几个节点 → 保存为新模板

**5.5.3 当前画布 → 复制 → 编辑**
- 节点右键"复制节点"= 创建相同节点（参数也复制）
- 节点右键"复制为模板"= 把此节点保存为我的模板（可加封面图）
- 整个画布"复制画布"= 创建当前画布的副本（带新 ID）

**5.5.4 多创串联 = 节点图 + 模板市场 + 版本历史**
- 用户可以从模板开始（学习用）
- 改模板（创作）
- 攒私有模板（资产化）
- 发布到市场（可选 / 公开）
- 复用 / 二次创作（循环）

## §6 [PUB] 提交流（F 类）

### 6.1 数据流连线
- 节点右侧 = 输出端口
- 节点左侧 = 输入端口
- 端口类型匹配：图片 → 图片 / 视频 → 视频 / 文本 → 文本
- 连线兼容：例如文本可以"喂给"提示词输入端口（自动转字符串）
- 删除连线 = 节点之间不再联动

### 6.2 节点内部"发送"按钮
- 节点生成完成后，输出缩略图旁边有"发送到"按钮：
  - 发送到：图生图 / 局部重绘 / 扩图 / 抠图 / 视频生成 / 蒙版
  - 发送 = 自动创建对应节点，并把当前结果作为输入
- 这是"快速串联"的主入口

### 6.3 导出
- 单节点导出：右键"导出为..."（PNG / JPG / WebP / SVG）
- 多节点导出：框选 → 菜单"导出选区"（拼成一张大图）
- 整画布导出：菜单"导出画布"（按 minimap 比例）
- 视频导出：拼帧导出 MP4（可选 24/30/60fps）

### 6.4 共享
- 画布"分享"= 生成只读链接（带访问码）
- 可设过期 / 密码
- 可"以模板分享"= 公开到市场

### 6.5 历史任务
- AI 节点生成过的图都在节点的"历史"标签里
- 可切换查看历史（不影响当前输出）
- 可"恢复历史"= 把历史结果作为新输出

### 6.6 失败重试
- 失败时节点状态条变红 + 错误信息
- 错误信息可展开看堆栈（开发模式）
- 用户视角"重试"按钮 = 重新提交任务（消耗积分）
- 自动重试：网络错误 / 限流可自动重试 1~2 次（用户无感）

## §8 [PUB] 关键发现 / 启发

1. **节点是画布的"一等公民"**
   一切皆节点（图片/视频/文本/AI 工具/模板/数据块）→ 统一的心智模型
2. **每个 AI 节点都是迷你工作区**
   输入预览 + 提示词 + 参数 + 输出预览 + 历史 = 完整的微流程
3. **提交流是"节点之间的对话"**
   而不是"页面之间的跳转" → 让多创串联非常自然
4. **模板 = 可复用的画布快照**
   节点 + 连接 + 参数都打包 = 资产化
5. **自动插入 vs 手动插入**
   生成结果可自动成新节点 = 鼓励"接着做"而不是"先停下"
6. **协作 = CRDT + 节点锁 + 评论**
   节点粒度的锁比画布粒度更精细
7. **失败就近显示 + deliberate retry**
   失败状态条不出现在顶部（薯包已要求）
