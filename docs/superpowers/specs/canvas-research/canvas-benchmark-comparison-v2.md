### 1.2 三网站技术栈差异（v1 没明确，v2 实测）

| 维度 | TapNow | liblib | quantv |
|------|--------|--------|--------|
| 画布渲染 | React Flow | React Flow | 原生 HTML5 (article + section) |
| 节点 ID 前缀 | text-/video-/... | i-/t-/... | 无前缀 (article 任意类型) |

**对薯包 v2 启示**:

- 不要试图做"双视图"（quantv 的 V1 §1.1 假设在实拍中**未观察到**节点+时间线双视图，本次 V2 实拍画布只有节点视图）

## V2 §3 新增发现（V1 完全没有的）

### 3.1 🆕 三大站 6 项独家特色（V1 未预测）

1. **TapNow 中央 hero chip 注入工作流** = "文字生视频" 1-click 创建 text node (预填英文 prompt) + video node + Edge。**这是薯包 v2 可以直接抄的最关键交互**。
2. **liblib 工作流/故事板 tab 切换** = 同一份数据按媒体类型分列展示。**故事板 = TapNow 节点图的时间轴替代品**。
3. **liblib 22 个角色分类 + 4 张参考图** (立绘/脸部近景/表情参考/三视图) = 影视级预制。**薯包 v2 角色库最低标准**。
4. **liblib 4 个导演级 Skill** (皮克斯动画广告/爆款拉片复刻/新中式美学TVC/古典武侠电影全流程导演) = 整套 workflow 而非单点 AI。
5. **liblib Agent 4 轴** (附件+模型+Skill+生成模式) + **CLI & Skill tab** = OpenAI-style 工具调用。
6. **quantv 任务日志 + 客服引导话术** = "报错时把上方任务ID发给客服" = deliberate retry 范本。**薯包 v2 必抄**。

### 3.2 🆕 三站都有的扣费透明化机制（V1 未明确）

| 站 | 扣费显示 | 货币 |
|----|---------|------|
| TapNow | "✦" 余额 + 模型每次消耗 | Tapies 积分 |
| liblib | "100 积分" + "✦ 预计 5.18 积分" | 积分 + 限时 40 折会员 |
| quantv | "✦ 0.00" + "✦ 预计 5.18 积分" | ✦ 钻石 |

**对薯包 v2 启示**:
- **实时预计积分** (liblib/quantv) = 扣费前用户可见，**薯包 v2 应该做**
- **会员入口** (liblib "限时 40 折") = 商业化提示位

### 3.3 🆕 资产管理 = Outliner + 资产库 (liblib 独有)

**结构**:
- 画布 tab: 节点列表 (定位到节点 + 更多操作)
- 资产 tab: 个人/Agent 二级分类 + 搜索 + 筛选

**对薯包 v2 启示**: **资产管理 = 项目级工作流中枢**。薯包 v2 应该做。

### 3.4 🆕 任务日志 = 4 状态机 + 类型 filter + 客服引导 (quantv 独有)

**结构**:
- 状态 filter: 全部/进行中/已完成/失败
- 类型 filter: 全部/文本/图片/视频/音频/应用
- footer: 报错时把上方任务ID发给客服，可快速定位问题

**对薯包 v2 启示**: **任务日志的"客服引导话术"是 deliberate retry 的最佳范本**。薯包 v2 的 RTK 已经有"持久、明确、就近错误 + deliberate retry"要求，**任务日志 + 客服引导是这一要求的最佳实现**。

### 3.5 🆕 工具箱 = 25 个运镜+特效预设 (liblib 独有)

**结构**: 每张图都是"使用"按钮 = 1-click 应用到画布

**对薯包 v2 启示**: 工具箱 = "运镜 + 特效"片段的预制库。薯包 v2 可以做"电商工具箱"或"营销工具箱"。

### 3.6 🆕 角色库 = 影视级预制 (liblib 独有)

**结构**: 每个角色含 4 张图 (立绘/脸部近景/表情参考/三视图) + 描述 + 应用至画布 button

**对薯包 v2 启示**: 角色库是 liblib 最大护城河。**薯包 v2 角色库的最低标准** = 4 张图 + 描述 + 应用按钮。

### 3.7 🆕 V1 假设的 6 个未实现项目

V1 假设的 30+ 加号子项、CRDT 协作、提示词片段 (snippet)、采样信息 metadata、关键帧蒙版、独立运镜参数面板、JSON 导出 — **这 7 项在 V2 实拍中均未明确观察到**。**V1 应该降级这些为 V3+ 功能**。
