> 调研方式：Exa 联网检索 + 用户浏览器 CDP 实访（小红书/B站/抖音）+ GitHub API 取实时 star。
> **未做任何付费调用、未真实生图**，全部为资料查阅。
> 引擎假设：`/api/canvas/regenerate`，模型 image2，文生图 / 图生图（参考图 ≤9），比例 1:1 / 4:3 / 3:4 / 16:9 / 9:16，清晰度 1K/2K/4K。

**可行性口径**
- `ready`：纯提示词 + 1 张商品参考图即可出，当前引擎直接支持。
- `needs_ref`：必须先抠图 / 必须先有白底图 / 需要多张参考图或多轮分镜，需要上游处理。
- `blocked`：当前引擎能力或合规不允许，需外部工具或不做。

## 二、逐条候选

### 1. 爆炸分解广告图
- **效果**：上传商品图 + 写出它的构成层，得到商品在半空中炸开、碎片与成分悬浮定格的电影级广告图。
- **为什么有热度**：
  - 小互·AI 解读站《一条提示词让产品广告炸开花：AI 生成爆炸分解效果图》（2026-03-21，专门拆解该配方四层结构，汉堡/球鞋/护肤三例）https://best.xiaohu.ai/article/exploded-product-ad/
  - GitHub EvoLinkAI/awesome-gpt-image-2-API-and-Prompts **17,199★**，E-commerce Cases 分类收录同类广告案例 https://github.com/EvoLinkAI/awesome-gpt-image-2-API-and-Prompts
- **提示词骨架**：`{{商品名}}动态空中爆炸效果，物体碎裂成多个碎片向各方向飞散，悬浮的残骸与颗粒漂浮，电影慢动作定格，逼真物理，细微{{粉末/液滴/纤维}}散落，戏剧性景深，高速摄影风格，中心主体锐利对焦，体积光照，照片级真实，8k`
- **可行性**：图生图。需 1 张商品参考图 + 构成层文字；不需先抠图。物理感由模型自己推理，属于本清单里最容易出效果的一条。
- **风险**：碎片摆放可能遮住 Logo 或标签，需人工复检商品可辨识性；食品类不可暗示"实际内容物"以免虚假宣传。

### 2. 极地冰封巨型海报
- **效果**：商品被封在巨型冰块或极地冰原中，做成超现实大场面广告海报。
- **为什么有热度**：
  - 尚品云 AI 平台把它列为独立可选项"极地冰封巨型广告海报"（与"电影级高端产品爆炸瞬间海报""蓝白降落伞悬浮产品创意3D渲染广告"并列）https://spyyai99.quantv.com/
  - 同源"巨型/超现实"玩法在 GitHub 17,199★ 仓库 E-commerce Cases 中反复出现（Miniature Diorama、9-Panel TVC 等大场面主视觉）https://github.com/EvoLinkAI/awesome-gpt-image-2-API-and-Prompts
- **提示词骨架**：`{{商品名}}被完整封存在一块巨大的透明冰块中央，置于广袤极地冰原，冷蓝色调，低角度仰拍突出体量感，体积光穿过冰体产生折射与内辉光，冰面裂纹细节，远处暴风雪氛围，电影级广告摄影，超现实商业大片，商品标签与轮廓保持清晰`
- **可行性**：图生图。1 张商品参考图 + 色调即可。冰体折射可能糊掉标签，建议 9:16 或 16:9 大画幅。
- **风险**：冰块遮挡标签会造成"商品与实物不符"；不得叠加未证实的功能宣称（如"保鲜""锁冷"）。

### 3. 产品悬浮电影感主视觉
- **效果**：商品悬浮于半空，单一方向光切过，大面积暗部，做成高级静物广告。
- **为什么有热度**：
  - umaax《怎么用 Nano Banana Pro 做电商设计图，附 13 个玩法教程》玩法 2 产品摄影，给出可直接复制的悬浮/电影感提示词 https://umaax.com/zenmeyongnanobananaprozuodianshangshejitufu13gewanfajiaochen/
  - GitHub 17,199★ 仓库收录 Miniature Diorama Skincare Advertisement 等悬浮类主视觉案例 https://github.com/EvoLinkAI/awesome-gpt-image-2-API-and-Prompts
- **提示词骨架**：`基于产品实拍照片生成高端产品摄影，{{商品名}}悬浮构图，暗色渐变背景，单一方向侧光，强烈明暗对比，几何光影切割，大面积暗部保留，产品为唯一视觉焦点，柔和反射，真实摄影质感，品牌官网主视觉，无杂乱元素`
- **可行性**：图生图。1 张商品图即可，不需抠图。风险最低、复用率最高的一条。
- **风险**：极低。注意不要生成品牌 Logo 之外的虚构标识。

### 4. 商品套图（一图出全套）
- **效果**：上传一张干净白底图，一次产出主图 + 卖点图 + 场景图 + 细节图的整套视觉。
- **为什么有热度**：
  - B站《image2直出一整套主图详情页电商图》**3.3 万播放** https://www.bilibili.com/video/BV1WMEJ65EQe/
  - 小红书《一张产品图｜AI 生成全套电商主图》（实访笔记，作者"是个凳子呀"，说明"洗衣液、运动鞋、家居睡衣、小家电多数实物产品都可适配"）https://www.xiaohongshu.com/explore/6a9a9867000000002b000608
- **提示词骨架**：`基于上传的{{商品名}}白底图生成一整套电商套图共{{张数}}张：第1张白底主图突出整体；第2张卖点图用图标短句标注{{卖点1}}{{卖点2}}{{卖点3}}；第3张场景图把商品放入{{场景}}；第4张细节特写表现{{材质}}。全程保持商品形状、Logo与配色不变，1:1，商业摄影质感`
- **可行性**：**needs_ref**。必须先有白底图/干净原图；建议拆成多次单图调用而非一次要全套（引擎单次出图稳定性更好）。
- **风险**：多张之间商品一致性是主要风险，需逐张与白底图对比验收。

### 5. 详情页分镜套图（3 镜/次）
- **效果**：按封面头图、卖点段、细节段、场景渲染段、规格参数段规划，每次出 3 张竖版分镜。
- **为什么有热度**：
  - 小红书《详细版GPT Image AI电商详情页具体指令》（实访笔记，作者"皮卡皮卡呐"，完整给出三步法与"一次三个分镜"的指令）https://www.xiaohongshu.com/explore/6a9547ac000000000b025042
  - B站《目前B站最全最细的AI电商设计零基础全套教程》**4.8 万播放** https://www.bilibili.com/video/BV159NB6EEef/
- **提示词骨架**：`根据我上传的{{商品图}}和资料，规划3张竖版详情页分镜，每张明确主题、主标题、副标题、画面构图、商品摆放方式与排版方向。资料：产品名称{{名称}}、核心卖点{{卖点}}、材质{{材质}}、规格{{规格}}、适用场景{{场景}}。保持商品外观一致，适合移动端竖屏浏览`
- **可行性**：**needs_ref**。需商品图 + 逐镜文案规划；建议拆 3 次单图调用。
- **风险**：中文长文案渲染易出错，建议只出图后由设计工具压字。

### 6. 九宫格 TVC 分镜

- **为什么有热度**：
  - image-2.net 收录《产品 TVC 九格分镜 - GPT Image 2 提示词》，给出 12 段可拆结构（9 个场景槽位明确列出）https://image-2.net/zh-cn/gpt-image-2-prompts/product-tvc-9-panel-storyboard/

- **可行性**：图生图，1 张参考图即可，**ready**。但格内中文字准确率不稳定，属"效果炸但文字需兜底"的类型。

### 8. 场景/生活方式图

- **为什么有热度**：

### 9. 白底主图（过审向）
- **效果**：纯白背景、主体占比约 85%、无文字无道具的合规主图。
- **为什么有热度**：
  - GitHub YouMind-OpenLab/awesome-nano-banana-pro-prompts **13,429★**，设有独立 E-commerce Main Image 分类 https://github.com/YouMind-OpenLab/awesome-nano-banana-pro-prompts

- **提示词骨架**：`{{商品名}}置于纯白背景（RGB 255,255,255），柔和均匀棚拍光，平视角度，商品居中并占据画面约85%，焦点锐利，颜色真实，轻微柔和阴影，干净的商业电商产品摄影，无文字、无道具、无水印`

- **可行性**：**needs_ref**。高风险商品（透明瓶、反光材质、密集标签）建议先抠图再做合成路线。
- **风险**：模型可能"顺手"改动瓶盖、标签或颜色——上传参考图不等于像素被锁定，必须逐项与原图对比验收。

## 三、明确不做的

- **建筑家装 / 室内设计**：竞品有 10 条独立分类，但这是建筑垂类基本盘，与我们的电商五大品类（美妆护肤/服饰鞋包/3C数码/食品饮料/家居日用）不重叠，投入产出比低。
- **游戏动漫 / 二次元角色**：竞品有 5 条分类，属于内容创作垂类，用户画像与电商卖家不同，且不受电商平台素材规范约束，无法复用我们的商品一致性能力。
- **明星脸 / 可识别真人肖像**：版权与肖像权风险最高，且平台审核直接拒绝，收益远小于法务成本。
- **擦边 / 性感化人体**：平台违规红线，账号与商家双封，绝不做。
- **医疗功效与"使用前后"强对比**：涉及广告法与市监处罚（虚假功效宣称可致永封甚至刑责），美妆护肤类尤其危险，只能做弱化的视觉对比且需法务白名单。
- **未授权品牌 Logo / 地标 / 艺术风格复刻**：训练数据含受保护内容，侵权赔偿风险高，需反向图搜核查。
- **"一键复刻爆款"类**：直接抄袭他人商品图/主图设计，存在著作权与不正当竞争风险，不应作为公开技能上架。
- **纯 AI 模特整身换装（服饰类主图）**：调研中明确有实测结论指出"真人模特穿戴类实拍转化率更高""服装鞋包细节质感与版型 AI 还原度 60%—70%，主图必须实拍"，故不做主图级方案，只做测款/氛围辅助。
