# 节点化创作生态 · 一页纸决策简报

> 详细方案：`docs/research/master-plan-node-ecosystem.md`（42KB）｜调研底稿：Quantv 拆解 816 行、能力地图 725 行、即梦拆解 396 行（同目录）

## 一句话结论

**我们的画布在"数据结构"上早就是节点图（kind + 端口类型校验 + 连线交互都有），缺的是"边会跑数据"。**
补上这一环，教程里那种"上传素材 → 反推提示词 → 生成图 → 换装 → 生成视频 → 换素材再来一遍"的流程就能一键跑。

## 现状判断（有证据）

| 维度 | 结论 |
|---|---|
| 数据模型 | 已经是标准节点图（`nodeWorkflow.js:83-122`），边带端口 |
| 执行 | ❌ 边不传值、要手点、无失效重跑、无图级后端端点（N1-N5） |
| 能力面 | ✅ 20+ 个执行原语已封装好（生图/变换/抠图/分层/OCR/反推/TTS/字幕/套装/视频任务） |
| 计费 | ✅ quote→hold→settle 完整，失败自动退款；本轮补齐 3 处漏收 + 统一价格口径 |
| 假能力 | ⚠️ TTS 配音是 mock、chainService 前两步是 mock、两条悬空路由、模板使用量是模拟值 |
| 结构债 | ⚠️ VideoStudio 是**第二套平行节点画布**（端口不可拖、与后端不通） |

## 五个决策（我的建议已给）

| # | 决策 | 建议 | 代价/风险 |
|---|---|---|---|
| 1 | 画布是否作为唯一主战场 | **是**，VideoStudio 画布并入 | 一次性重构，但不并就会"每加一个能力做两遍" |
| 2 | 第一批模板 | 白底主图 / 模特试穿 / 场景详情 / 换装短视频 / 口播带货（图结构已设计） | 免费，模板不收费，只收节点 |
| 3 | 新 SKU 定价 | TTS 0.5 积分/次；对口型待上游报价；拼接免费（本地 ffmpeg） | 需你确认对口型档位 |
| 4 | 音视频顺序 | TTS → 首尾帧视频 → 对口型 → 拼接 | 依赖 P3 |
| 5 | P0.5 是否开工 | **已开工**（纯前端、零上游成本、不确认不扣费） | 唯一风险点：自动扣费 → 已用"显式点击 + 费用确认"锁死 |

## 三条不变式（任何改动都不许破坏）

1. **不确认不扣费**：挂载/连线/编辑/模板铺开都不触发执行；
2. **老文档只读可用**：历史画布必须能打开并运行；
3. **价格唯一真源**：前端不出现第二套价格表。
