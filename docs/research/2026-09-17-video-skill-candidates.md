# 视频技能候选（调研日期 2026-09-17）

> 目标：为「薯包 AI」视频板块的 **skill（玩法配方）库** 补充候选。
> 引擎口径：服务端 `/api/video/jobs`，上游 Seedance 2.0 级别，支持 **文生视频 / 图生视频 / 首尾帧 / 参考素材（图片+视频+音频）**，单条 5s / 10s，比例 9:16 / 16:9 / 1:1。
> 已有 9 条技能：智能成片、首尾帧、爆款复刻、图生视频、商品动态展示、内容替换、模特动态、运镜控制、延长续写(blocked)、节日营销短片。
> 范围：只做电商基本盘（美妆护肤 / 服饰鞋包 / 3C数码 / 食品饮料 / 家居日用），**不做建筑家装**。

**可行性口径**（沿用 `src/skills/videoSkills.js` 的既有约定）
- `ready`：现有可调用路由（seedance_fast / seedance_standard）即可满足；
- `needs_ref`：需要参考素材能力（图片/视频/音频），现有路由已声明支持但**未实测出片**；
- `blocked`：所需能力当前不可用，**上架前必须先转 ready**。

**取证方式（全部真实访问，零付费、零真实生成调用）**
- GitHub：GitHub REST API `/search/repositories` 实名实星 + `raw.githubusercontent.com` 实读 README / 方法论原文。
- B站：用户浏览器 CDP 实访搜索页与视频页；播放/点赞数**经 `api.bilibili.com/x/web-interface/view` 二次核对**（两处数值一致才采用）。
- 小红书：CDP 实访搜索页 + 带 `xsec_token` 的站内跳转读笔记详情，取真实点赞/收藏/评论。
- 微信公众号：搜狗微信 `weixin.sogou.com` 实读标题 + 公众号名 + 发布日期 + 摘要。
- **未能取得的部分如实标注**，不做估算、不补数字。

### 1. 红绿灯换装（ready）

- **效果**：用户上传 **1 张人物图 + 2~3 套穿搭/配色描述**，得到"红/黄/绿灯依次亮起、每亮一盏就切换一整套穿搭"的竖版转场视频（9:16）。
- **为什么有热度**
  - 来源 1：抖音 ·《红灯停，绿灯行！ #红绿灯穿搭 #变装》· **104.9万赞** · @原来是陶阿狗君（原创）· https://www.douyin.com/search/交通信号灯换装
  - 来源 2：抖音 ·《AI复刻爆款红绿灯穿搭，教程公开》· **902赞** · @千谲AI-cedar · 同上搜索页
  - 来源 3：B站 ·《红绿灯换装视频教程，工作流保姆级教程》· 148 播放 · https://www.bilibili.com/video/BV1s7up6aEqM/
  - 佐证：抖音侧已有 5+ 独立账号在做复刻教程，且泛化到"色卡穿搭转场"（@番茄沙司Tomato 1782赞），是典型可迁移爆款。
- **我们怎么实现**：**图生视频**。prompt 骨架（约 60 字）：
  > 固定机位中景，人物站在纯色背景前保持姿势不变。画面左侧交通灯依次亮起：红灯亮时人物穿【A套】，黄灯亮时切换为【B套】，绿灯亮时切换为【C套】。每次切换为干脆的硬切，无过渡特效。竖版构图，光线稳定。
- **可行性**：**只靠现有引擎可跑通**。单人物、固定机位、主体动作可控，属图生视频范畴；换装节奏由提示词驱动。注意：**"一镜内多次换装"当前需要拆成多条 5s 生成后拼接**，或用一条 10s 承载 2~3 次切换。
- **风险**：低。若使用真人模特图需有肖像授权；纯 AI 人物无版权问题。服饰图案若为知名品牌 logo 有侵权风险，需提示用户避免。

## 三、明确不做的

| 看似热，但不做 | 一句话原因 |
|---|---|
| **建筑家装 / 户型生长 / 3D 空间改造** | 竞品知渔 AI 靠建筑室内 19 条撑量，但那是**垂类生意**（客单价高、销售链条长），我们只做电商基本盘，做它等于开第二条产品线。 |
| **明星脸 / 名人肖像 / 明星声音克隆** | 法律红线。公众号《法治热点：带货视频滥用AI仿名人声音、肖像，商家需担责！》（京尹律师事务所）已点名追责，平台侧也会直接下架封号。 |
| **擦边 / 性感擦边换装** | 平台违规高发区，会连累整个 skill 库的审核评级；且与"电商基本盘"的品牌调性不符。 |
| **AI 仿真实顾客好评 / 假测评（Review-style UGC）** | 属于虚假宣传。《cliprise/awesome-ai-ugc-video-prompts》明确写入 "UGC style is not permission to fake real experience"、《HiAPIAI/awesome-ai-video-workflows》亦列 "no fake testimonials"。 |
| **AI 换脸 / 一键换人（内容替换类）** | 肖像权风险极高，且已被大量滥用。技能库虽已有"内容替换"，但**不应作为主推玩法**，需强授权校验。 |
| **医疗 / 保健 / 药品功效类视频** | 广告法严格监管，AI 生成的功效宣称极易违法，远超出我们可控范围。 |
| **数字人口播（本期不并入）** | 热度最高（B站 147.4万播放、抖音品牌实投 7.1万赞），但**依赖口型驱动能力，当前 blocked**——不因热而虚标可用，单独立项评估。 |
| **AI 短剧 / 漫剧带货** | 制作链路长（剧本→分镜→多角色一致性→配音），单条 5/10 秒档位承载不了，投入产出比不适合作为 skill。 |
| **FPV 航拍 / 城市地标穿越（非店内）** | 玩法本身极热（X 平台 158K 浏览），但**应用场景是文旅/地产**，不是电商；我们只保留其中的"店内货架漫游"变体（候选 13）。 |
