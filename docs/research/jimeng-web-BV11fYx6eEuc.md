## 4. 画布 / 串联专章（架构对标重点）

### 4.1 画布定位

- 字幕："**全新画布 / 全流程创作 一站式完成**"（t≈44s）、"**无限画布 一站管理 / 文字 ｜ 图片 ｜ 视频 ｜ 音频 ｜ 时间线**"（t≈86s）。
- 简介："全新画布一站整合｜文图视音，全流程可控"。
- 即：**对话是入口，画布是工作台，时间轴是成片出口**；画布是承载"文/图/视/音 + 时间线"的唯一容器。

### 4.2 画布上的元素与布局（实取）

- 元素类型：**文字、图片、视频、音频、时间线**（字幕明确五类）。
- 可见具体元素：城堡/场景图卡片；人物形象卡片（含"…Prompt"字样，如"人物形象设定Prompt"）；**音频卡片**（与人物形象相邻）；**视频卡片**（t≈88s 两枚并排，卡面标"视频"）；文本卡片（"1. 某类人 2. 某个地方 3. 某种情况 4. 某些要求"，疑为脚本/结构文本）；时间码 00:45:04 的播放元素。
- **连线**：卡片之间**曲线相连**（modlens 描述 "connected by curved lines"，颜色见 §7 未确认项）→ 表达素材之间的**引用/派生关系**。

### 4.3 画布内的"就地指令"编辑（最有价值的一段）

t≈78–86s 镜头序列（影视级"串联"演示）：

1. 画布上先是"巨大人物手里拿着云"的镜头（提示词"场景的人物变巨大"）。
2. 画布内输入"**把雷云变成章鱼**" → **虚线选框**圈定区域 + 蓝色**编号圆标 1**。
3. 再输入"**把章鱼变成食人花**" → 同样选框 + 编号。
4. 再输入"**把食人花变成骷髅乌鸦**" → 同样选框 + 编号。

要点提炼：

- **链式改写**：每轮以前一轮结果为输入，形成 A→B→C→D 派生链——这正是"串联"的产品语义。
- **局部选中 + 指令**：用**虚线矩形框**圈定要改的区域，而非整图重绘。
- **编号标记**：选框带**编号圆标**（见 "1"）⇒ 支持**多处选择、按编号分别下指令**；⚠️编号 ≥2 未在片中见到，属推断。
- 输入位置：画布底部/卡片附近的文本输入条。
- 输出：改写结果留在画布上，继续参与后续编辑与成片。

### 4.4 素材如何流入画布（实取）

1. **生成流入**：对话/生成结果 → 画布（伴随"编辑画布中"状态）。
2. **素材库流入**：素材缩略图**拖拽连线**到画布主预览区（t≈72s）。
3. **项目/画布维度**：侧边栏可切换多个画布；素材支持**跨项目复用**。

### 4.5 画布 → 时间轴 → 成片（实取）

- 画布含"**时间线**"元素类型；实际操作界面是**多轨时间轴**：视频轨（连续缩略图串）、音频轨（**波形**）、时间刻度（00:25 / 00:30 / 00:35）、播放器时间码（00:08 / 01:25；00:08:04 / 00:25:00）、按钮"**全屏编辑**"。
- 出口："**多轨素材自由编排 一键即可导出成片**"。

### 4.6 画布串联"有 / 没有"清单（对标速查）

| 问题 | 结论 | 证据强度 |
| --- | --- | --- |
| 节点怎么连？ | 素材卡片/节点之间**曲线相连**，表达引用与派生；未见输入/输出端口语义 | 中 |

### 6.2 即梦独有、我们短期做不了

- **Seedance 2.5 / 2.0 Fast 自研视频模型与算力**，以及 **720P 0.2–0.4 元/秒**级成本结构（字节内部成本，第三方接入无法对齐）。
- **"电影教科书级技能"背后的模型微调 + 影视版权素材/导演知识资产**。
- **Dreamina 海外分发 + B站/抖音生态导流**（本片即官方号 + 转发评论送积分的增长打法）。
- **面向影视/广告/自媒体创作者的通用创作场景**：不背商品事实约束，直接照抄会偏离薯包"商品事实校验"护城河。

### 6.3 我们已经有的（不要重复造）

- **画布 + 节点派生 + 就地配置**：节点、就地生成配置器、连线几何一致性、泳道编排、空状态引导（见 canvas-interaction-audit）。
- **资产 / 作品 / 归档 / 回收站 / 稳定交付 URL**：即梦"素材管理"的大部分能力薯包已有。
- **任务恢复 + 幂等计费**：薯包对"轮询断线被误判失败"的处理，比宣传片能证明的即梦能力更硬（RTK.md §11 有实证）。
- **电商事实与合规**：商品事实不猜测、白底图不重绘、SKU 规格差异、平台规格与多语言——通用创作工具没有这套约束。

### 6.4 需要重新评估的一条既有结论

`2026-07-30-canvas-interaction-audit.md` 第 2 条写的是"**通用画布的文生图、视频、音频能力不引入**"。即梦这一版把"文/图/视/音 + 时间线 + 多轨 + 一键导出成片"做成了画布标配，并明确指向电商广告投放（"创意品牌广告""年度爆款短片"）。

建议：

- 维持"不做通用文生视频玩具"，但**把"商品短视频"纳入下一阶段评估**（素材→拼接→字幕/配音→成片），因为投放素材与主图/详情图是同一交付链路的自然延伸；
- 无论是否做视频，**画布数据模型应预留时间线/轨道维度**（素材带时长、可挂音频），否则未来接视频要重构画布。
