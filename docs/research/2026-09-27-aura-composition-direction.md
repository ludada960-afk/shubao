> 本文只答一个问题：**用户说的「他有些篇，一张是从左往右构图、一张是从右往左构图」——成立到什么程度。**
>
> **先纠正上一轮的方法错位**：上一轮做的是「把每张图水平翻转后与同篇其它图比 dHash（8×8 梯度指纹，阈值 d≤8）」，

> 而用户说的是「**两张图各自的构图走向是相反的**」——这是两个不同的问题，dHash 答不了后者。
> 本文换方法重答：**先逐张判「重心在哪一侧 / 视线或动势朝哪边 / 留白在哪一侧 / 是否左右对称」，
> 再看同一篇里是否同时出现左右两种走向**。

## 〇、一句话结论

**用户那条观察「部分成立、但不是他的系统手法」**：

* 严格口径（同一篇里一张有 **左→右** 的视线/动势引导、另一张有 **右→左** 的）：**3/41 篇**（n5、n10、n14）成立，占 7.3%；其中 **n5 是干净的一对**（n5-6 ↔ n5-3，同一窗框场景，手臂一左一右互为正反）。
* 放宽到「主体重心」口径（同一篇里既有一张主体明显偏左、又有一张明显偏右）：**9/41 篇**（n3、n5、n8、n10、n12、n20、n25、n33、n36），占 22.0%；其中 **7 篇是"同一主体/同一场景换到另一侧"**（n5、n8、n10、n12、n25、n33、n36）。
* 但「两张作品是**镜像成对**（同一张构图的镜像版式）」这个强形式：客观配对检验只给出 **4 组弱候选**（增益 ≤0.026，见 §三），而我目视怀疑的 **23 组里 16 组被原图放大复核否定**——所以**它不是靠"镜像成对"编排的**。
* **真正稳定的篇级规律是另外几条**（§四）：**居中式大留白是基本盘（86.1% 的图没有横向引导）**、**镜面对称构图 69 张（17.2%）**、**篇内"同版式族反复用"（74 张 / 18.4% 落在 21 篇的同机位簇里）**、以及**少数篇的"主体占比/景别单调收束"（5 篇）**。
* 对用户「每篇都有策划思路」的回应：**成立，但思路不是"左右方向"**，而是「一个母题 + 一组固定道具 + 3~5 个反复用的版式族 + 逐张换一个实体化动作」。

### 1.3 客观指标（`composition/metrics.mjs`，402 张全量；只作旁证，不当主判）

每张图缩到 360×480 后算 4 组量：

| 指标 | 定义 | 用途 |
|---|---|---|
| `cxSig` | 用「纹理+梯度+饱和度+与边框背景色差」合成显著性 `S`，Otsu 取阈值得前景掩膜，按 6 列求「列掩膜密度」后算横向质心（0=最左，1=最右） | 重心侧的旁证 |
| `spread` | 上述列分布的横向标准差；>0.235 视为"铺满整幅、没有单一主体" | 决定 `cxSig` 是否可信（铺满时不判左右） |
| `flatL/C/R/T/B` | 12×16 块（每块 30×30px）中 **灰度标准差 < 5** 的"平块"占比，按左/中/右三分与上/中/下三分统计 | 留白侧的旁证 |
| `sMask` / `sLum` | 前景掩膜的「掩膜 vs 水平镜像掩膜」IoU；以及整图灰度与其镜像的皮尔逊相关 | 镜面对称判定的旁证 |

配对检验（`composition/pairs.mjs` / `composition/paircheck.mjs`）：把每张图压成 **6×8 的版式签名**（每格=前景掩膜密度），
对同篇每一对 (i, j) 算 `dDirect = |sig_i − sig_j|` 与 `dMirror = |sig_i − mirror(sig_j)|`。
**若两张真是"构图镜像成对"，应当 `dMirror` 明显小于 `dDirect`（增益为正且大）**。

### 1.4 判定标准（逐条写死，表格里就是按这个填的）

| 列 | 判定标准 |
|---|---|
| **画面重心 L/C/R/E** | **主体（人/产品/被拍物，即观者第一眼落在的东西）所占的横向位置**：主体整体落在左 1/3 → 左；右 1/3 → 右；居中或横跨中间 → 中；**没有单一主体、画面被场景/版式铺满**（全景、平铺、宫格拼版）→ 均。以目视为主，`cxSig` 只在"主体是否真在某侧"上做旁证 |
| **视线或动势方向 `>` / `<` / `0` / `-`** | **只记画面内部真实存在的横向引导**：① 人物目光朝向；② 行走/运动方向；③ 手臂/身体从哪一侧入画并向哪一侧伸展（含"手伸进画面取物"）；④ 文字/字符的阅读方向。**左→右 记 `>`，右→左 记 `<`**；人物正对镜头 / 对镜自照 / 对称构图 / 拼版内方向互抵 → `0`（居中）；**画面里没有人、没有动势、没有横向伸展的物件 → `-`（无方向）**。（注意：`-` 不等于"没构图"，只表示"没有横向方向这一项"） |
| **留白 l/r/t/b/tb/n** | 低细节、低对比、接近背景色的区域**主要**落在哪一侧；上下留白为主记 `t`/`b`/`tb`；没有明显单侧留白（铺满）记 `n` |
| **镜面对称 Y/N** | **沿竖轴左右近似对称的构图**（主体居中、左右两侧结构/重量对等）：宫格拼版、居中产品静物、居中大字/色块版式、圆形居中框 → 是；主体偏一侧、或左右内容明显不同 → 否。判定阈值：`sMask ≥ 0.55` 且 `sLum ≥ 0.45` 为客观候选（**一致率 80.6%**，不一致的以目视为准） |
| **置信度 H/M/L** | **高**：250px 与 470px 两遍都看得清、指标同向；**中**：250px 能判但没放大复核，或指标与目视不同向；**低**：人小/模糊/背影/画面太满，看不清（全站只有 5 张） |

### 1.5 局限（明确写出来，别当成结论）

1. **"重心/留白"是目视主观量**：我自己写的像素重心（`cxSig`）与目视的一致率只有 **39.7%（重心）/ 51.6%（横向留白）**，
   典型分歧如 **n4-8**（产品在左中，但右侧粉色圆镜+玻璃杯面积大，`cxSig=0.60` 判右）——**像素重心 ≠ 视觉重心**，
   所以表格里这两列**以目视判定为准**，指标只作旁证。镜面对称的一致率是 **80.6%**，这一列指标可用。
2. **"方向"列只在 82 张上做过原图放大确认**；其余 320 张按 §1.4 的"无人无动势 ⇒ 无方向"记 `-`。
3. `n7`、`n41` 是**视频笔记**，只看得到**封面**（封面内是多格拼版），"动势方向"只是封面内的方向。
4. 实况图（livePhoto）只有静帧，**2~3 秒视频本体的运动方向没看**——若用户指的是"动图里扫过去的方向"，本文答不了。
5. 置信度分布：**高 51 / 中 346 / 低 5**（"中"占多数，是因为 320 张没做放大复核，其判定又几乎都是"无方向/居中"这类不难判的结论）。

| **强形式**：同一篇里两张是"同一构图的镜像版式"（镜像成对） | **0 组**可确证（只有 4 组弱候选，增益 ≤0.026） | — | 目视怀疑的 23 组里 16 组被原图否定 |
| 全篇**没有任何**横向引导（纯居中/静物/对称） | **23 / 41** | **56.1%** | |
| 全站**真有横向引导**的图 | 33 / 402（左→右 10、右→左 23） | **8.2%** | |
| 全站**镜面对称构图** | 69 / 402 | **17.2%** | |

**诚实版结论**：
用户确实**看到过**"一张左、一张右"的篇——**至少 7 篇**能指到具体图（n5-3↔n5-6 最典型）。
但这不是他的**篇级编排手法**，而是"**同一场 shoot 会从两侧各拍一张**"的副产品；
用"镜像成对"去概括它更是不成立（那 7 篇里只有 3 组能确认为"同一主体被放到了相反一侧"，其余只是不同主体各占一侧）。
换句话说：**当用户在某一篇里注意到"一左一右"时，他注意到的是真实存在的（7/41 = 17%），但它不是每一篇都有的规律。**

### 4.2 他的篇级规律**其实是另外几条**（这才是"每篇都有策划思路"的答案）

1. **居中式 + 大留白是基本盘（最强规律）**：63.7% 的图没有横向引导，28.1% 明确"居中/正视/对称"。
   静物篇（n4 全粉 / n9 冰蓝 / n23 冰透粉 / n39 全粉 / n40 纯色背景）几乎**每张都是主体居中 + 单侧或上下大留白**——
   留白侧**逐张都不一样**（没有"留白永远在左"这种固定规则：`留白固定同一侧` 的篇 = **0/41**）。
2. **镜面对称构图 69 张（17.2%）**，是"成套感"的第二个来源，集中在三类：
   ① 产品居中静物（`n35-2` `n37-7` `n39-6` `n40-2` `n23-7/8/9/11`）；
   ② 宫格拼版（`n10-3` `n19-1` `n20-1` `n35-1/9` `n40-1` `n9-2` `n2-7`）；
   ③ 居中大字/色块版式与圆形框（`n20-18` `n26-11` `n37-8` `n38-2/9` `n19-7`）。
3. **篇内"同版式族反复用"**（客观聚类：版式签名距离 ≤0.14）：**74 / 402 张（18.4%）落在 21 篇的同机位簇里**，例如
   `n4-1/7/8/10`、`n19-3/4/5/7/10/11`、`n20-16/18`、`n23-4/5/9/11`、`n25-6/9/13`、`n29-1/4/5/6/7/8/10`、
   `n31-1/2/3/6/7`、`n36-1/5`、`n36-2/6`、`n37-7/9`、`n38-7/9`、`n39-5/8`、`n40-2/3`、`n40-4/5`；
   最严阈值（≤0.06）下只剩 `n29-7/n29-10`、`n31-1/n31-7` 两组"几乎同机位"。
   ⇒ **他的篇级做法是"一个版式/机位连着用几张，每张换道具/换材质/换文案"，而不是"每张都换构图"**。
4. **景别/主体占比的单调收束**（主体占比与张序的 Spearman |rho|≥0.5，5 篇）：
   `n9` rho=**−0.82**（0.41→0.04：开篇主体最大、最后一张最简）、`n31` rho=**+0.85**（0.14→0.29：从"百叶帘后半个脸"收到"提包+全套产品"）、
   `n22` +0.73、`n36` +0.58、`n40` +0.50。⚠️ `areaFrac` 是"前景掩膜占比"的粗代理，**这一条置信中低**，但方向一致。
5. **没有"左右交替"这种节奏**：L/R 重心在序列里换向 ≥2 次的篇只有 **1 篇（n28）**；跨篇素材复用（上一轮已证 n24↔n27 四张、n37↔n38 五张、n26↔n28 两张）在本轮方向维度上也一致——
   `n37`/`n38` 是同一批"瓶+渐变背景"素材，方向一律居中/对称。

## 五、给工作台的输入建议（`docs/design/82` 的哪一层加哪一栏）

1. **要加**：在 `docs/design/82` §四 的「**③ 画面构思（每张）**」层，给每张加一栏
   **`构图方向：左→右 / 右→左 / 居中(对称) / 无`**，并同时落两个可执行字段：
   **`主体所在侧（左/中/右）`** 与 **`留白侧（左/右/上/下/均）`**。
   理由（数字）：真正带横向方向的只有 **8.2%**（左→右 10 张 / 右→左 23 张），**17.2%** 是镜面对称，**其余 ~74% 是"居中 + 留白"或"铺满"**。
   ⇒ 这一栏的**默认值应当是"居中/无方向"**；"左→右 / 右→左"只在**有人物、有手伸入画面、或人物在行走**的镜头里才允许出现（那些镜头的方向要跟着"手往哪边伸/人往哪边看"写死）。
2. **要加（更重要）**：在「**② 母体（每篇）**」层加一栏 **`版式族（本篇反复用的 3~5 个机位/版式）`**，
   并加一条硬规则：**同一版式族至少复用 2 张**。理由：74/402 张（18.4%）属于同机位簇——**"成套感"主要来自"版式反复"，不是来自"张张不同"**。
3. **可选开关（别当默认）**：`两侧机位对拍：左机位 + 右机位`，只在"有人物/可移动主体"的篇里开——
   实测只有 **7/41 篇**这么干（n5、n8、n10、n12、n25、n33、n36）。
4. **建议不要加**"镜像成对"这一栏：客观配对 + 目视复核都不支持它是他的手法（4 组弱候选、16 组目视怀疑被否定），加了会让模型产出他不做的"工整镜像对"。
