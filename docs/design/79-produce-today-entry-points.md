## 一、今天就能用的入口（实测，可点）

**总入口**：`https://shuimg.cn/` → 首页那张「**图片生成**」卡 → 进入总页面 `https://shuimg.cn/image-creation`

总页面里**按分类列技能**（5 类共 48 条）。跟 Aura 那种"品牌广告级画面"对得上的技能在这两组里：

| 分类 | 可用技能（今天就能点） |
|---|---|
| **创意应用** | **品牌主视觉**（`image.brand_kv`）、**展厅静物主视觉**（`image.showroom_still`）、中文海报（`image.cn_poster`）、液态 Logo 海报（`image.liquid_logo`）、场景拼贴（`image.sticker_collage`） |
| **电商专区** | 单色糖果系广告（`image.mono_pastel_ad`）、巨型产品广告（`image.giant_product`）、悬浮主视觉（`image.float_kv`）、极地冰封海报（`image.ice_ad`）、礼盒场景图（`image.gift_scene`）、场景种草图（`image.scene`） |

**直链**（把 id 换掉即可）：
`https://shuimg.cn/image-creation?id=image.brand_kv`

### ⭐ 今天最该用的那条：**品牌主视觉**（`image.brand_kv`）

选它的原因很实在 —— 它的内置提示词原文就是：
> 「做一张品牌主视觉……要求：**不是一张孤立的图，而是一套能延展到其他版式的画面语言——
>  构图、材质、光线、色板与图形节奏要统一**；品牌标识与产品细节必须原样保留。」

**这句话几乎就是"签名 + 母体"的定义**，而且它是唯一一条带**自由文本框**又能承载整套方向的技能。

它的字段只有 5 格：**主题**（text）/ **品牌**（text）/ **描述**（textarea）/ 比例 / 分辨率。

### 今天"跑一篇"的填法（以「秋日限定」为例）

| 格子 | 填什么 |
|---|---|
| 主题 | `秋日限定`（**这就是母体**） |
| 品牌 | 品牌名或关键词（要出字标就填；不填就别让它编） |
| 描述 | **签名块 + 母体块 + 本张镜头句**（三段一次全粘进去，见下面的模板） |
| 比例 | `3:4` |
| 分辨率 | `2K` |

**描述里粘的三段**（照 77 号 §十一 那条实例改）：

```
[签名纪律] 画面不出现面部（只出手部/背影/局部），柔光为主，3:4 竖版，
编辑级质感，统一颗粒与饱和度；任何文字必须原样渲染，不许自己编品牌名。

[本篇方向] 概念：秋日限定。主色：暖灰大地 #94847A，辅色 #8F8E93 灰蓝、#CAB3AE 裸粉。
场景：米灰石膏台面与干枝。材质：陶土、丝绸。

[这一张] 主图：产品为绝对主角，居中构图，大量留白，柔光罩打光。
```

**出一套**：改「描述」里第三段那一句（换成 场景叙事 / 静物组合 / 细节微距 / 空镜），
**再点一次生成**；重复到够 6–9 张。每次都点一次 = 一张 = 一次计费（先报价再扣费，跟现在一样）。

**出完自己核一遍**：有没有露脸？是不是都是 3:4？色是不是都在那个色簇里？字标有没有被模型改字？

## 二、今天**给不了**你的东西（诚实清单，别以为漏找）

| 你规划里要的 | 今天 | 说明 |
|---|---|---|
| 一次给一个"母体"就自动铺开一套 | ❌ | 48 条技能全是**一次一张**，一篇要 6–9 张就点 6–9 次 |
| 勾镜头、按镜头归位的结果墙 | ❌ | 没有这个概念；出完的图进「历史」，平铺 |
| 单独调整某一张 / 重出某一张 | ❌ | 只能整张重来 |
| 看见并改这一张最终下发的提示词 | ❌ | 看不到最终原话 |
| **锁定主色（色簇）** | ❌ | ⚠️ 这条最意外：`custom_colors`（品牌主色调）**只存在于电商画布那条线**
（`src/pages/Home/ec/*` + `EcCanvas`），**图片技能子页面没有这一格**（`imageSkills.js` 的字段里也没有）。
所以今天只能**把十六进制色值写进"描述"里**，靠模型理解 —— 能用，但比"锁"弱 |
| 「小红书图文」能不能当入口 | ⚠️ 不建议 | 它确实一次出 1–9 张（`image.xhs_note`，9 积分/套），但它的提示词原文是
「**真实感优先，像手机随手拍出来的生活记录，不要做成广告海报**」—— **方向跟 Aura 正好相反**（Aura 是广告战役级） |

## 三、我要给你的那个入口（长什么样）

新增一条技能 **`image.concept_set`「概念视觉方案」**，落在 `/image-creation` 的 **创意应用** 分组，
跟「品牌主视觉」「小红书图文」并列。

**直链**：`https://shuimg.cn/image-creation?id=image.concept_set`（做出来之后）

**点进去看到的**：

```
┌─────────────────────────────┬──────────────────────────────┐
│ 左栏                        │ 右栏                          │
│                             │                              │
│ ▸ 本账号签名（只读，已就绪）  │   结果墙：按镜头归位          │
│   不露脸 · 柔光 · 3:4 · 统一调色 · 字标原样                 │
│                             │   [主图]   [场景叙事]  [静物组合]│
│ ▸ 这一篇（三格）             │   [细节微距] [空镜]   [  ]     │
│   ① 母体  ← 5 个按钮+自定义  │                              │
│   ② 钩子  一句               │   每格：改这一张 / 重出这一张   │
│   ③ 勾镜头 ← 10 个，默认全不勾│        / 看这一张的原话 / 让它动│
│                             │        / 下载                 │
│ ▸ 比例 / 清晰度 / 模型       │                              │
│   [生成这一张] 价：x 积分     │                              │
└─────────────────────────────┴──────────────────────────────┘
```

**操作节奏**：选母体 → 写一句钩子 → 勾 5 个镜头 → 点 5 次生成（每张一次报价）。
每张都自动带同一套签名与母体块；哪张不满意就「重出这一张」，只想改一格就「改这一张」。

**它复用的都是现成的**：出图走既有 `visualCreation` 管道（`/api/generate`）、
计费走既有报价确认、签名那几项挂既有的 `campaignBible` 与 `negativeConstraints/forbidden`
（见 78 号 §三-b），**不新增计费点、不新增引擎**。

**实施清单**在 77 号 §九（9 步），落地前的三处核实也在那（封面计划白名单、`FIELD_KINDS` 九种、
出处登记走 `ours`）。
