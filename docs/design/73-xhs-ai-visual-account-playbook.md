## 三、变现核查：¥8000/条 到底可不可能（用公开数据算，不猜）

### 3.1 平台机制（有出处）
* **蒲公英**（官方接单平台）**服务费 10%**（官方帮助中心条目 pgy.xiaohongshu.com/help/docs?id=2908，
  正文 JS 渲染，拿到的是搜索索引摘要：「普通模式仅提供内容合作服务，收取10%服务费」）；
* **报备制**：品牌付现金 + 达人发笔记**必须走报备**（带"合作"标识），非报备属商业违规；
* **挂牌价 ≠ 成交价**：蒲公英的报价是博主自填的挂牌价，品牌方可以不下单（这一点**没有直接出处，
  是我的机制判断**）。

### 3.2 公开报价区间（都是自媒体/平台方口径，非官方）
| 粉丝量级 | 公开口径 | 出处 |
|---|---|---|
| 1,000 粉 | **约 ¥100/篇**（「报价 = 粉丝数 × 1/10」） | B站 cv23755917 |
| 1,000 粉 | 200~800 元 | 搜狐《小红书推图文价格一般都是多少》（仅域名可核） |
| 1 万以下素人 | 200~800 元 | 同上 |

### 3.3 结论（这条很重要）
**按全部可查到的公开口径，几千粉的图文投放报价落在 ¥100~800 —— 与 ¥8000 差一个数量级。**
所以「¥8000/条 × 9 条/月」这套数字，**用"广告投放"口径解释不通**。它更可能是：

1. **视觉外包/委托创作的稿费**（品牌买它的**图**，不是买它的曝光）——
   一套 campaign 概念图 ¥1000~8000 在视觉行业里是正常价；这与它的简介里挂着
   **商务邮箱**、内容按 campaign 标准做、还贴品牌官方 IG 数据（作品集行为）**完全吻合**；
2. 或第三方平台那个位置的**「系统测算预估值」**（千瓜首页原文说明预估含"系统测算投放报价"）。

⇒ **这不是"广告号"，是"用小红书当作品集的视觉工作室"**。
两者的做法、KPI、天花板完全不同 —— 这决定了我们该怎么做（见 §六）。

### 3.4 一个必须说清的缺口
**没有任何公开来源能证实"某个 AI 视觉账号接到了哪个品牌、多少钱"。**
品牌方/agency 公开承认用 AI 视觉素材做投放的案例：**一条都没有**（只有技术博客讲商用场景）。
⇒ 这条赛道的变现数据**只能靠你自己去谈**，我不该给你一个"月入 7.2 万"的预期。

## 四、动图 / 实况图（live 图）：你问的"他们怎么做出来的"

### 4.1 实况图是什么（技术规格，有出处）
* **一张实况 = 静态封面 + 约 3 秒短视频**，靠元数据配对：
  * **iOS**：同名 `JPG` + `MOV`，EXIF 里写入**同一个 36 位 UUID**（Apple 官方：1.5 秒前 + 1.5 秒后 ≈ 3 秒）；
  * **安卓**：**JPEG/HEIC 尾部直接追加 MP4** + XMP 记录偏移（`Camera:MotionPhoto=1`、
    `Container:Directory`、`Item:Length`），文件名为 `*_MP.jpg` / `MVIMG_*`（Google 官方规范）。
* **小红书不帮你转换**：发布入口是 App 内「+ → 图片 → 右上角**实况**开关 →
  选相册里的实况素材」。⚠️ 如果把整批都勾"全部"的实况照片，**会被当成一段视频**处理
  （要在"照片/实况图"里选）。
* 平台对实况图的**时长/体积/分辨率上限、流量扶持**：**查不到**（官方无公开页面）。
* 小红书对实况的支持历史：2024-05 OPPO Reno12 首台安卓可发 → 2024-07 小红书 8.44
  "通配 LivePhoto" → vivo/荣耀/小米陆续直发 → 2025-09 OPPO 与小红书共建 4K 实况直出。

### 4.2 AI 实况图的三条现实路线（同行在用的）

| 路线 | 做法 | 成本/效率（从业者公开口径） |
|---|---|---|
| **A. 图生视频 2~3 秒 → 合成实况**（主流） | 静态图（AI 生成或自有）→ I2V 模型出 2~3 秒 H.264 小视频 → 与封面图合成实况文件 | 某商业工具自述「**90 秒一张、一个人一上午 100 张**」「单张 **¥0.2~0.3**」 |
| **B. 纯图片微动效** | 只让画面某处轻微动（"呼吸感"），本质是 A 的提示词版本 | 同上工具第二条产品线 |
| **C. 视频切片配封面** | 已有视频按 2~3 秒切片，每段配一张封面图 → 合成实况 | 同上 |

**开源工具（可直接用，star 与更新时间实测）**：

| 仓库 | Stars | 用途 |
|---|---|---|
| `PetrVys/MotionPhoto2` | 307 | HEIC/JPG + MP4 → Google/Samsung 动态照片 |
| `wszqkzqk/live-photo-conv` | 225 | 跨平台 make/extract/repair；**视频直接转实况** |
| `hacoresapling/AIGC-LivePhoto-Maker` | 11 | **最贴合"AI live 图"**：内置智谱 CogVideoX 图生视频，直出 iOS（注入 UUID）与安卓（追加+XMP）两种 |
| `Young-Spark/oppo-live-photo-maker` | 11 | 任意视频 → OPPO 相册可识别实况（另有纯前端 PageCodecs 版，零上传） |
| `969246694/video2livephoto` | 0（很新） | Windows 专用，视频→iPhone 实况，**不重编码** |

**工程约束（有出处）**：时长取 **2~3 秒**；视频优先 **H.264 而非 HEVC**（兼容性更好）；
封面帧尽量零重编码；**传回手机必须走不压缩通道**（AirDrop / 爱思助手"导入实况照片"）——
**微信、QQ 会剥掉元数据，传过去就散了**。

**翻车场景（从业者明确警告）**：画面里有大量细小文字（证书/表格/说明书）、或依赖 Logo/纹理/数量细节时，
AI 动效容易把字**变形**——必须逐张抽检。

### 4.3 我们怎么实现（我的建议）
**我们站内已经有全部上游零件**：出静图（48 条图片 skill）→ 图生视频（站内视频链路）。
缺的只是**最后那一步"合成实况文件"**（JPG+MOV 写 UUID / JPG 尾追 MP4 写 XMP）。
这一步是**纯本地确定性工作**（不是模型能力），完全可以在服务端做，成本≈0。
⇒ 我建议把它做成站内的一个导出选项（"导出为实况图"），而不是让你去装开源 CLI。
**这条要不要做、什么时候做，等你拍板**（我不擅自加功能）。

## 五、你问的四件事：直答（AI 标识 / 人脸筛查 / 发布包 / 检测）

### 5.1 「发布包」是什么意思（我上一版没解释，是我的疏漏）
**发布包 = 一条笔记的"待发布物料"打成一个包**，内容是：
`① 图片（按顺序，封面第一张） ② 标题（给 3 个候选） ③ 正文（含话题标签） ④ 首评（自己抢一楼）
⑤ 一个说明文件（这组图出自哪个 skill / 什么提示词 / 是否标 AI）`。
用途：**因为发布必须人工**（小红书没有开放发布 API，自动发帖＝平台明令封禁的"AI 托管账号"），
所以平台侧能做的是"把物料准备好、你复制粘贴就能发"。
站内已经有 `image.xhs_note`（小红书图文链路）+ `xhs_image_set_2k`（1 封面 + 8 图，9 积分/套）——
**发布包就是把它的产出补上标题/正文/话题/首评那一层**。

### 5.2 AI 标识：「没必要，学他们」这句我要把事实摆全
**事实（都有出处）**：
* 小红书 **2026-02-12/13**《关于加强自主标识AI生成合成内容的公告》：要求**主动标识**；
  **未标识 → 平台"通过降低推荐权重"限制分发**；且「平台将**自动通过检测系统为其添加显眼标识**」；
  总口径是"**主动标识为主，被动标识为辅**"。
* 小红书 **2026-04-27**《AI治理规则公告》：把 **AI违规运营 / AI造假 / AI侵权 / AI低质** 四类列为违规，
  处置梯度到**封号**；其中「**套用模板批量生产同质化内容**」明确属于「AI低质」。
  → 同一份公告还把「**传授利用AI洗稿、规避审核的做号方法**」列入违规运营。
* 《人工智能生成合成内容标识办法》（**2025-09-01 施行**）第十条：
  「**用户使用网络信息内容传播服务发布生成合成内容的，应当主动声明并使用服务提供者提供的标识功能
  进行标识**」，并禁止恶意删除/篡改/伪造/隐匿标识。
* **对平台侧（我们）**：同一办法要求**服务提供者**加显式 + 隐式标识 —— 这是**我们的义务**，不是你的选择。

**「是不是某些模型可以产出不被平台识别到 AI 的图片？」**
这个问题我**不会给你规避方法**，原因不是道德洁癖，而是三件很实际的事：
1. **这是平台明文打击的行为**（上面第 2 条，"规避审核的做号方法"本身在违规清单里）；
2. **收益极低**：平台是"未标 → 自动检测补标 + 降权"，也就是说**不标不会让内容"看起来更像真人"，
   只会同时吃到"降权"和"被补标"两个结果**；
3. **成本很高**：一旦被判 AI 造假/低质，处置是**限制分发到封号**，账号即资产归零。

**学他们怎么做（这是对的做法）**：他们发的图**不触发警告**，最可能的解释不是"模型能骗过检测"，
而是——他们的内容**本来就不是"批量同质模板"**：每条一个独立创意（车盖上的阿玛尼甜品、
电梯里的亮片礼服）、构图与品牌语言都是定制的、而且**不露脸**。
平台要打的是"**套模板批量生产**"，不是"用了 AI 工具"。**把内容做成这样，才是他们的护城河。**

### 5.3 人脸筛查：**我们平台现在没有这个逻辑**（你问得对）
你说得没错——我上一版把"人脸筛查"写进流水线，那是**我提议要加的风控**，不是现有功能。
站内 48 条图片 skill **没有任何一条**带人脸判定逻辑（我刚查过：没有 face/人脸检测的判定代码）。
⇒ 所以"没必要"这个判断成立：**在它存在之前，谈不上要不要**。
我的建议是**先不做**（理由：AI 生成的脸本来就是虚拟的，真正的风险是"撞真人"，
而撞真人的概率取决于提示词里有没有写具体人名/明星，那靠**提示词规范**而不是图像比对来防）。
如果你希望有一条底线，最省的做法是在 `image.portrait` 这类页面的提示词模板里**明确禁止写真人姓名**，
而不是上一个人脸模型。**这条也等你拍板。**

### 6.2 出图成本（决定你能不能天天更）
站内模型每张成本：**mdkj ¥0.026 / gpt-image ¥0.038 / nano-banana ¥0.06 /
Seedream 2.5 ¥0.0715~0.1235 / Gemini3 ¥0.12~0.15 / Midjourney ¥0.25~0.39**。

真正的成本是**选题与选片的人力**，不是生成。

### 6.3 建议的 0→1 四步（每步独立可交付）
1. **定位**：`AI 视觉 · 品牌概念图`。简介照它的骨架 + **留商务邮箱**（这是"接委托"的唯一入口）。
2. **内容配方（8 栏目轮换，专治"批量同质化"判定）**：
   ①「如果 XX 出甜品/香水」概念体（它的爆款钩子）②品牌静物棚拍 ③节日/季节限定
   ④**中国品牌**（国产美妆/咖啡/茶饮/白酒 —— **它全是国外品牌，这是空白**）
   ⑤电商带货视觉（**我们自己最强**）⑥"提示词公开"型（涨粉最快：图 + 过程）
   ⑦前后对比/翻车修复（最不像批量号）⑧品牌官方内容复刻 + 数据点评（它那条 IG 截图就是这类）。
3. **生产流水线**：选题 → 出图（2~3 个模型并出选片）→ 手检（文字/logo/结构）→
   成组（1 封面 + 8 图）→ **发布包**（图 + 标题 3 选 1 + 正文 + 话题 + 首评）→ **人工发布** →
   数据回填。
4. **节奏**：**每周 3~4 条**，不要日更（平台对"批量同质"最敏感；同质化的号粉丝不精准、品牌方不投）。

## 七、这个模式的问题 + 我们能做得更好的地方

### 它的四个硬问题
1. **变现口径要重算**（§三）：¥8000 不是广告费而是**稿费**的话，"月接 9 条"意味着
   **每月 9 个定制 campaign** —— 交付压力与广告完全不同，也不好复制。
2. **粉丝量与商业价值脱钩**：4,608 粉的账号能接品牌委托，是因为**卖的是图不是曝光**；
   这也意味着**"涨粉"不是它的 KPI**，照抄"涨粉"这套会跑偏。
3. **版权与商标风险**：拿一线品牌的 logo/包装做图，**只能当作品集，不能商用交付**；
   真要变现必须换成客户自己的品牌。肖像权同理（判例口径：AI 脸"公众能识别出原型即侵权"）。
4. **赛道拥挤且被规则压着**：见 §5.2 —— 批量同质化是明文违规，模板化那部分没有护城河。

### 我们能做得更好的四条（按我认为的价值排序）
1. **把账号当"获客入口"而不是"广告位"**：广告天花板是有数的，而"内容 → 私域 → **shuimg.cn**"
   的天花板是产品用户。**它只有 4,608 粉却在卖服务，正好说明这个赛道的钱不在曝光。**
2. **做"中国品牌"这个空白**：国货美妆/咖啡/茶饮/白酒的概念图几乎没人做，
   而**品牌方就在国内、决策更快、预算更愿意给**。
3. **把"AI 视觉外包"产品化**（把自己的流水线卖给别人，而不是只自己用号）——
   这比自己做号可复制性好得多，也是我们平台现成能力最直接的变现路径。
4. **合规当差异化**：主动标 AI、公开提示词、保留创作过程、不露脸、商单走报备 ——
   平台鼓励"把 AI 当创意工具"的用法。**能长期活下来的号才有复利。**
