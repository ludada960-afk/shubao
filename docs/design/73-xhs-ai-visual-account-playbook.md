## 二、我们平台的自查：能不能做？——**能，而且底座比它厚**

### 已有能力（`src/skills/imageSkills.js` 共 **48** 条图片 skill，逐条对照）
| 它那几条的内容形态 | 我们现成的 skill | 差距 |
|---|---|---|
| 品牌产品静物（兰蔻/Valentino 那种） | `image.showroom_still`（棚拍静物）、`image.float_kv`（悬浮主视觉）、`image.ice_ad`（暗场戏剧光）、`image.gift_scene`（台面场景静物） | 差"按品牌语言定制"这一步（提示词层即可补） |
| 概念创意海报（阿玛尼甜品） | `image.cn_poster`、`image.liquid_logo`、`image.giant_product`、`image.mono_pastel_ad` | 差"品牌植入式概念"的配方 |
| 场景叙事（电梯晚宴） | `image.scene`、`image.portrait`（人像）、`image.sticker_collage` | 差"不露脸的产品叙事"配方 |
| 小红书整套交付（1 封面 + 8 图） | **`image.xhs_note`**（已有小红书图文链路）+ **`xhs_image_set_2k` SKU（9 积分/套）** | **零差距**——平台本来就卖这个 |
| 品牌字样要清晰可读 | gpt-image 系（`ec_image_2k/4k`）文字渲染最强；`text_consistency` 的思路视频侧已有 | 文字**准确率**要靠模型选型 + 复检 |

### 模型底座（站内已在售，成本是"每张几分钱"）
nano-banana flash/pro（1k/2k/4k，成本 **¥0.06/张**）、gpt-image（2k/4k，¥0.038）、
Seedream 2.5 sunburst/flare（¥0.0715~0.1235）、Gemini3（¥0.12~0.15）、**Midjourney（¥0.25~0.39）**、
mdkj（¥0.026）。⇒ **出图成本 ¥0.03~0.39/张**，做这种账号一天 10 张的原料成本 **不到 4 元**。

### 能力边界（老实说，缺什么）
1. **缺"品牌广告级静物"的专属 skill + 配方**：现在要靠用户自己写提示词，不稳定。（可补，见 §三）
2. **缺"批量生成 → 选片 → 发布物料"的工作流**：我们有批量出图与小红书套图，但没有"账号日历 + 选片 + 导出发布包"这一层。
3. **发布环节我们不做也**不能**做自动化**：小红书没有开放发布 API；用工具自动发帖正是平台**明令永久封禁**的"AI 托管账号"（2026-03-10 公告，已封 80 万号）⇒ **发布必须人工**（或半自动：生成"发布包"= 图 + 标题 + 正文 + 话题）。
4. **合规能力缺口（这是产品机会）**：《AI 生成合成内容标识办法》要求**服务提供者**
   （= 我们平台的导出物）加**显式 + 隐式标识**（含元数据）。**我们现在没有做**——
   这是上线"AI 内容账号"之前必须先补的一环（见 §四）。

## 三、0→1 落地方案（我的建议，分四步，每步都能独立交付）

### 步骤 1：账号定位（照 Aura，但选一个我们能赢的窄口）
· **定位**：`AI 视觉 · 品牌概念图`，一句话简介照它的骨架：
  「品牌美学｜AI 视觉｜电商创意 / 用 AI 把品牌做成广告级画面」；
· **内容配方（8 条栏目轮换，避免"批量同质化"判定）**：
  ①「如果 XX 出甜品/咖啡/香水」概念体（Aura 爆款同款钩子）
  ②品牌产品静物（无缝背景 + 钩子标题）
  ③节日/季节限定（它那两条秋日粉调）
  ④中国品牌（国产美妆/咖啡/白酒）——**竞争空白，Aura 全是国外品牌**
  ⑤电商带货视觉（我们自己最强：白底/详情/A+）
  ⑥"提示词公开"型（涨粉最快的一类：图 + 过程）
  ⑦前后对比/翻车修复（真实性最强，最不像 AI 批量号）
  ⑧品牌官方内容复刻 + 数据点评（Aura 那条 IG 截图就是这一类）
· **更新节奏**：每周 3~4 条（比"日更"更安全、更省人力；平台对"批量同质"最敏感）。

### 步骤 2：生产流水线（用我们平台，一天能出 10 张）
`选题（栏目表）→ 出图（我们平台现有 skill，1~3 模型并出选片）→ 合规检查（AI 标识 + 人脸筛查）
→ 发布包（图 + 标题 3 选 1 + 正文 + 话题 + 首评）→ 人工发布 → 数据回填（收藏/涨粉/商单咨询）`
· 出图用哪个 model：**品牌字样清晰**选 gpt-image（2k）；**氛围质感**选 Midjourney 或 Seedream 2.5；
  **便宜量跑量**选 nano-banana 4k（¥0.06/张，10 积分/张面值）。
· 我给这一步能补的产品能力（**缺什么做什么**）：见 §五「平台赋能」。

### 步骤 3：合规（不做这步会被限流到封号）
1. **每条笔记手动勾选"AI 生成"标识**（平台规则：不主动标识→平台识别后**直接限流**）；
2. **我们平台导出时必须带隐式标识**（元数据）+ 显式角标（法规要求的"服务提供者义务"）；
3. **不发布拟真人脸**（学 Aura：只用产品/手/背影/无脸人像），或人脸模型不能撞真人；
4. **商单必须走蒲公英报备**并标"广告"；
5. **不铺矩阵、不自动发帖**（那是封号红线）。

### 步骤 4：变现（三层结构，不要只押广告）
① **商单投放**（腰部前）：前期 1k~1 万粉阶段报价 ¥150~800/条；
② **视觉外包**（Aura 那种"品牌概念图"真正的钱在这里：一套 campaign 图 ¥1000~8000，**这才是你听到的 ¥8000 的可能口径**）；
③ **自有产品引流**：账号 → 私域 → 导流到 **shuimg.cn**（你自己的平台！这条的天花板远高于广告，详见 §四）。

## 四、这个模式的问题 + 我们怎么做得更好（我的判断，含风险）

### 它模式的四个硬问题
1. **天花板低且被平台拿捏**：普通号商单上限约 7~8 条/月（从业者口径），且报价 ≈ 粉丝 ×5~20%；
   「¥8000×9」要么是预估值，要么是外包价 —— **不要按"月入 7.2 万"去做财务预期**。
2. **"AI 低质"红线**：小红书 2026-04-27《AI 治理规则》原文把「**利用模型批量生成同质化内容**」
   列为违规，处置梯度到**封号**；2026-03-10 起已封 **80 万 AI 托管号**。⇒ **批量发图=自杀**。
3. **肖像权最高危**（判例：AI 脸"公众能识别出原型即侵权"，"技术自动生成"不构成免责）；
   **品牌商标**同样有风险：拿一线品牌的 logo/包装做商单图**不能商用**（Aura 这种图只能算作品集/自嗨，
   真要变现必须换成**客户自己的品牌**）。
4. **同质化内卷**：这类号已经很多，模板化以后粉丝不精准、品牌方不投。

### 我们能做得更好的四条（按我觉得的价值排序）
1. **把账号当"平台获客入口"而不是"广告位"**：广告天花板 7~8 条/月，而"内容 → 私域 → shuimg.cn 注册"
   的天花板是产品用户。Aura 只有 4608 粉却像在卖服务，说明**这个赛道的钱本来就不在曝光**。
2. **做"中国品牌"这个空白**：Aura 全是一线国外美妆（Armani/Valentino/Lancôme/Urban Decay），
   国货美妆、咖啡、茶饮、白酒的"概念图"几乎没人做，而**品牌方就在国内、决策更快、投放更便宜**。
3. **产品化"AI 视觉外包"**：把 §三步骤 2 的流水线做成站内能力 → 卖给别人（不只是自己用号）。
   这是**把账号的变现模式变成产品**，比自己做号可复制性好得多。
4. **合规本身就是差异化**：主动标 AI、公开提示词、保留创作过程、不露脸、报备商单 ——
   平台对这种号是鼓励的（"AI 作为创意工具"），而同行都在踩线。**能长期活下来的号才有复利。**
