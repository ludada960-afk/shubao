## 一、心智变了：一次任务是「一篇」

以前：选主题 + 选手法 → 出 **1 张**图（想要"一篇"得自己一张张点）。
现在：**勾 N 种手法 → 一次出 N 张 → 归为一篇**，历史里**一篇一张卡**、可一键还原当时的勾选。

## 二、每一步怎么用（按界面顺序）

### 1. `主题意象`（必填，单选）
20 条母体，每条自带**实测色板**（对竞品 41 张封面做 k-means 量出的 5 个色簇：灰调大地 / 海蓝灰雾 /
柔雾浅粉 / 暖砂裸粉 / 深棕暗红）。**一篇只选一个**。
**依据**：他"一篇看着像一套"首先来自**同一个色板**——母体决定色调，这是"每篇不一样、但一眼是同一个账号"的机制。

### 2. `本篇手法清单`（可勾选，勾几种 = 出几张）
10 种手法：概念静物 / 场景叙事 / 材质静物 / 平铺集合 / 局部极特写 / 超现实拼贴 / 拼版页 / 杂志版式 /
户外自然光 / 空镜。**逐张生成、每张只带自己那一种手法**；某张失败只重试/只算成功的那几张（按张计费）。
**依据**：实测他单篇 **4~18 张、均值 10.3**，且**篇内刻意不重复**。第一次建议勾 **5~6 种**。

### 3. `版式族`（每篇一档）
现在只给**两种**：`宫格` / `底片条`。规则：**同一篇里同族至少复用 2 张**（判据在 `skillRun.pieceLayoutFamilyHolds`，
拼版层据此拒绝只有 1 张的篇）。
**依据**：实测拼版 **60/402（14.9%）、分布 36/41 篇**；而真正撑"成套感"的是**篇内"同版式族反复用" 74 张 / 21 篇**
（不是左右交替——那条只 9/41 篇站得住）。
⚠️ 两种做法上的硬约束：**先出单图、再本地拼**（确定性渲染，不调模型、不计费）；
**绝不让模型一次画一整张九宫格**（分格线会画歪、格内内容互相渗透）。
（他还有"宝丽来画中画"与"品牌信息图版式"两种语法，属于下一阶段。）

### 4. `人物形态`（每张一档，默认"空镜"）
`画面里不出现任何人物（空镜或纯静物）` / `只有手或手臂` / `躯干与腿部（不露头）` / `下半脸` /
`戴墨镜` / `背影或侧脸`。唯一硬约束：**不出现正脸、不直视镜头**。
**依据**：实测**完全没有头 346/402（86.1%）**，但人物局部很常见（躯干腿 74 / 手 66 / 下半脸 17 / 墨镜 13 /
遮脸 8 / 背影 8）；**正面脸只有 1 张**。旧的"不出现面部"会把那 34.8% 的"有人在场但不露脸"一起禁掉。

### 5. `构图方向`（每张一档，默认"居中/无方向"）
`画面不做方向引导（主体居中、左右留白平衡）` / `左→右` / `右→左` / `居中对称`。
⚠️ **人物形态选"空镜"时这一栏会被锁定**（禁用 + 就地说明），并且**下发前再夹一次**——
从历史还原/「做同款」带进来的旧值也会被夹回默认档，不会偷偷发出去。
**依据**：实测**只有 33 张（8.2%）真有横向引导，63.7% 没有方向**，居中+大留白是基本盘；
镜面对称 69 张（17.2%）。**"镜像成对"实测不成立**（23 组目视怀疑里 16 组被原图否定）⇒ 我们**没做**这个档。

### 6. `补充 / 参考图 / 比例 / 分辨率`
`补充` 是你自己要说的话（可选）；`参考图` 最多 3 张；`比例` 默认 **3:4**（本账号签名，实测他封面全是竖版）；
`分辨率` 默认 2K。

### 7. 出片之后
- **历史按篇分组**：一篇一张卡；过期的是**灰卡 + 已过期**（不会凭空消失）；
- 每张可 **下载** / **存到我的资产** / **回到工作台**（带上素材与配置，不自动生成）；
- **拼版**：宫格 / 底片条在**生成结果区**可以拼（免费、可下载、可存资产）。
  ⚠️ 如实说明：**刷新后的历史条目里暂时还没有拼版入口**（只在刚生成的结果区）。
- **做成动图**：✅ **已接线**（2026-09-27 批 DC-4）—— 做法与验收边界见本文第 **8** 节。

### 8. `做成动图`（结果区，**每张一颗**，要花钱）
刚出的那几张图，**每张下面**都有一颗「**做成动图 · 15 积分**」：
1. 点它 → 先弹一次**计费确认**（写清这次扣多少）；
2. 确认后：服务端按**这张图**去上游做一次图生视频（我们买的是**最短的 5 秒档**），
   拿到成片后**在本机裁到 2~3 秒**，再把这条短片交回结果区；
3. 做完在这一张下面直接 **`<video>` 预览 + 「下载这张动图」**（文件名 = `概念视觉方案.mp4`，
   下到本地一眼认得出）；下载后**直接传小红书**（发布时选「视频」即可）。
4. 失败/没做完会**写在这一张下面**（不是转瞬即逝的提示），并写明**没有扣积分**。
   ⚠️ 只有一种失败**不会**这么说：**"这一单已经建好了、但这一会儿读不到进度"**（上游比预期慢）。
   那会儿钱**已经按最短路花了**、任务还在跑，所以这里只如实说"进度暂时查不到（不会重复扣费）"，
   并在原地给一颗「**再看一眼**」—— 点它就拿这条任务号再查一次，成片取回来就在这张图下面下载。
   （**不会**再说"不扣积分"：那是把花了钱说成没花钱；也**不会**把你推去「任务记录」：
   那个入口挂的是另一个权限。同一张图也**不会**出现第二颗「做成动图」：再点一次会变成第二条任务。）

**进度去哪儿查**：查的是**这一档自己的口**（`/api/concept/live-photo?jobId=`，与上面那条价目同一条 GET）。
⚠️ 这一处 2026-09-28 从"查既有的 `/api/video/jobs/:id`"**改过来了**，原因是**两处权限不是同一把锁**：
概念视觉方案归 `ecommerce_image`，而视频任务那几个口挂的是 `video_generation`。只开了电商生图的账号
点这颗按钮，会**钱已按最短路花掉、上游也真出了片，他却永远看不到也拿不到**（「任务记录」同样是视频口，
一样进不去）。交付承诺不能挂在用户可能没有的权限上 ⇒ 状态留在这一档自己的口上
（任务本身仍是同一条视频任务，在「任务记录」里也照样看得到；服务端仍按**属主 + 是不是这一档的任务**两道核）。

**凭什么是这个价**：这一档的成本是我们自己的最短档 —— **Seedance Fast 5 秒 ≈ ¥0.91/条**
（与线上已在出片的 `seedance_fast` 同一条通道）；面价 **¥3.90/次**（14900 units，
过高端档 70% 毛利地板）。裁到 2~3 秒是**本机 ffmpeg**的活，不额外花钱。
⚠️ 「做成动图」与小红书图文页那颗「让它动」**不是同一条路**：后者是纯本机微动效（免费），
前者**真的走一次上游图生视频**（所以收费）—— 这是用户原话点出来的：
「即便是在服务端做，**你也要收费呀**……而你确定你的方案没有成本吗，**你这个不是用到图生视频吗**」。

**这一条现在验到哪一步（如实说）**：
- ✅ 打桩验过的（一次真实上游调用都没发）：建单与计费链路（一次点击 = **一条任务 = 一次上游调用 = 一笔冻结**）、
  同一次点击重复触发**不重复扣费**、上游失败/裁切失败**都退钱且不结算**、裁切纯函数（目标 2~3 秒且不超原片）、
  本机真裁一条（H.264 / 2.5 秒 / 无音轨 / 体积更小）、界面链路（按钮带价 / 点前确认 / 轮询 / 下载文件名 /
  失败就近说明）、状态查询的两道核（别人的任务号查不到 + 产品判据，2026-09-28 批 CY-2）。
  门禁：`test/concept-set-live-photo-0927.test.mjs`；端到端：`scripts/media-workbench-e2e.mjs` 的㉒
  （场景里同时钉住"状态只打这一档自己的口、一次都没绕去视频任务口"）。
- ⏳ **只有你真机点一次才能验的**（我不许替你花钱跑）：① 上游真给你出片（那条通道 5 秒档实测约 **2~3 分钟**，
  台账里的历史记录是 156 秒）；② 出来的片子**好不好看**（动得自不自然、像不像这张图动了一下）；
  ③ 裁出来的 2~3 秒在手机/小红书里播放与观感；④ 上游那条通道**当前余额/渠道是否还活着**
  （台账是快照，不是事实 —— 详见 `server/videoCatalog.mjs` 的判据纠错）。
  真跑之前请先确认中转余额 ≥ ¥0.91×并发（否则建单会被上游以 `insufficient_user_quota` 拒，**不扣我们的钱**）。

## 三、明天第一次怎么跑（建议 5~8 张，几分钟）

1. 进「概念视觉方案」子页面 → 选一个你喜欢的母体（例如 `秋日限定 · 灰调大地`）；
2. 手法勾 **5 种**：概念静物 / 场景叙事 / 材质静物 / 局部极特写 / 空镜；
3. `版式族` 选 **宫格**；
4. `人物形态`：2 张`空镜`、2 张`只有手或手臂`、1 张`背影或侧脸`（照实测分布配）；
5. `构图方向` 全部留默认（居中/无方向，空镜那两张会自动锁住）；
6. 生成 → **对着他的作品比四件事**：① 色调是不是同一个色板；② 是不是"有人在场但不露脸"；
   ③ 版式族是不是在一篇里出现了两次以上；④ 居中 + 大留白的比例像不像；
7. 想在结果上叠宫格/底片条，就在结果区点拼版。

2. **拼版的历史入口**：刷新后的历史条目里没有拼版按钮（只在生成结果区）。
3. **跨图一致性锚定**（同一模特/同一场景连拍，如他 n33 四张、n5 七张）：下一阶段。
4. **品牌信息图版式**（一张图 = 一个版式 + 多个小场景 + 文案）：本质是平面设计模板，下一阶段。
5. **素材池「一材两篇」界面**（池子 / 多篇复用；实测他有 12 组跨篇完全相同的图）：下一阶段。
