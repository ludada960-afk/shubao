# 81 · 运营执行手册：今天做什么 → 每周做什么 → 我并行做什么

> 用户 2026-09-25：「你现在再告诉我，**我该怎么执行这个账号的运营策略呢，具体我现在该做什么**」
> 这一篇不给分析，只给动作。**所有动作都用站内已有的能力，不依赖任何还没做的开发。**

---

## 第 0 步（10 分钟）：先准备一张"无标产品图"

**为什么**：`image.scene` 的「上传商品图」是必填的，而我们走**无品牌线**，
所以这张图上**不能有任何品牌标识**。

**怎么做**（最省事的）：
拿一个**素色的东西**——哑光陶瓷杯 / 玻璃瓶 / 陶罐 / 亚克力方块——放在**白墙或白桌**前，
用手机拍一张，光线尽量均匀（窗边散射光最好，别用闪光灯）。拍完就是"无标产品图"。
**不用修图、不用抠底**，站里会把它放进场景。

> 这一张图就是你的"视觉主体"，后面每一套都从它出发。以后可以多备几个不同材质的。

## 第 1 步（今天，1～2 小时）：跑通第 1 套

### 去哪

`https://shuimg.cn/` → 首页「**图片生成**」卡 → 总页面里找 **电商专区 → 场景种草图**
直链：`https://shuimg.cn/image-creation?id=image.scene`

### 怎么填

| 格子 | 填什么 |
|---|---|
| 上传商品图 | 第 0 步那张**无标产品图** |
| 修图指令 | 下面三段**整块粘进去**（这是第一段，见下表的替换规则） |
| 比例 | `3:4` |
| 分辨率 | `2K` |

**第一张（主图）—— 整块复制到「修图指令」：**

```
[签名纪律] 高端编辑级静物，画面不出现面部（只出手部/背影/局部），柔光罩打光，3:4 竖版，
统一颗粒与饱和度；画面内不出现任何品牌标识与包装文字；不要生活照的随意感。

[本篇方向] 概念：秋日限定。主色：暖灰大地 #94847A，辅色 #8F8E93 灰蓝、#CAB3AE 裸粉。
场景：米灰石膏台面与干枝。材质：陶土、丝绸。

[这一张] 主图：哑光陶土罐居中为绝对主角，大量留白，柔和顶光。
```

**出第 2～5 张时，只改最后 `[这一张]` 那一行**，前面两段一个字不动（那是签名与母体，整套共用）：

| 张 | `[这一张]` 换成 |
|---|---|
| 1 主图 | 哑光陶土罐居中为绝对主角，大量留白，柔和顶光。 |
| 2 场景叙事 | 陶罐放在米灰台面上，一只手（不露脸）从画面侧边轻轻扶住它，干枝在背景虚化。 |
| 3 静物组合 | 陶罐与陶土小碟、几枝干花错落组合，高低有别，构成雕塑感。 |
| 4 细节微距 | 极近特写陶罐表面的陶土颗粒与手作痕迹，浅景深。 |
| 5 空镜 | 没有任何产品：只有米灰台面、干枝与一片柔光投影，作为呼吸页。 |

### 每一步的成本

**按钮上会显示本次报价**（先报价 → 你确认 → 才扣费），所以你看得见再决定。
5 张就是点 5 次、算 5 张的钱。**不满意的那张先别删，留在历史里**。

### 出完之后（这一步最重要）

把 5 张导出来看一遍，然后诚实回答三个问题，**告诉我**：

1. **哪几张"对味"**（像那种高级审美账号的图），哪几张一看就是 AI 味/廉价感？
2. **色是不是真的收到那个色簇里了**（暖灰大地 #94847A 那种低饱和暖灰）？还是飘走了？
3. **有没有漏出品牌标识或乱码文字**？有没有露脸？

> 这三个答案决定工作台该长什么样 —— **我不猜，我等你的结果**。
> 这也是我一直建议"先手工跑一篇再建工作台"的全部理由。

## 第 2 步（本周）：定签名，然后把它固定下来

签名是**账号级、设一次、以后长期不变**的那一层，目的是让人不看标题就知道是你。七条：

| # | 签名 | 取值 | 状态 |
|---|---|---|---|
| 1 | 人物纪律 | 几乎不露脸，人物只出手部 / 背影 / 局部 | 需你点头 |
| 2 | 画幅 | 统一 3:4 竖版 | 需你点头 |
| 3 | 光位 | 柔光为主，戏剧光只用于暗色母体 | 需你点头 |
| 4 | 调色 | 统一质感 / 颗粒 / 饱和度纪律 | 需你点头 |
| 5 | 无品牌 | 画面内不出现任何品牌标识与包装文字 | 已定（80 号） |
| 6 | 标题书写 | 「"……」」引用式短句，不写产品参数 | 需你点头 |
| 7 | 色簇 | 只用实测 5 个色簇（见第 3 步） | 需你点头 |

**今天过渡期**：这七条就是上面 `[签名纪律]` 那一段文字，每次粘贴一次。
**等做了新技能之后**：它变成账号级设置，**你只需要每篇填"母体 + 钩子 + 勾镜头"三样**。

## 第 4 步（本周）：节奏、选题来源、复盘

**节奏**：**每周 3～4 篇**稳定发，不要断更式日更（从业者口径："稳定大于数量，
不要一天狂发 5～6 篇，容易被判定机器批量操作"）。每篇 = 1 张封面 + 6～9 张内页。

**栏目**：先开 2 个，带固定句式，让人认得出。建议：
- **「季节母体」**（母体表第 1～8 行那种）—— 启动成本最低，
- **「情绪命题」**（第 9～12、17～20 行那种）—— 靠文字功底，做起来之后再上。

**选题来源（四类，都别自己瞎想）**：
1. **对标账号超出它自己均值 2 倍的"入池选题"** —— 翻最近 30 篇算平均，把高于均值 2 倍的记下来
   （**不是抄最火那篇**）；
2. **货架差评区 + 追评 + 问大家** —— 2026 年最被强调的**原创**来源（"高赞笔记拆解已经没有信息差了"）；
3. **平台官方灵感 / 活动**（"命题作文"）+ 搜索下拉词；
4. **周复盘反推**。

**复盘（每周 30 分钟）**：挑数据最好的 2～3 篇，看**比例**不看绝对值（收藏率 / 评论率 / 分享率），
然后更新母体表的"已用"次数与新的母体候选。

## 第 5 步（发布前，每次都做，不能省）

- **勾选 AI 生成标注** —— 这是**法规**不是建议（《人工智能生成合成内容标识办法》2025-09-01 施行，
  图片必须在适当位置加显著标识；发布者要主动声明、不得删除或篡改）。
- **文字自己再过一遍**（平台要求 AI 产出必须人工二次改写，直接复制输出会被判低质）。
- **自查**：有没有露脸？有没有品牌标识？色簇对不对？字有没有被模型写错？
- 如果是商业合作：**走蒲公英报备 + 标注"广告"**。

## 我并行做什么（你不用等）

| 我做的 | 依赖你的什么 | 什么时候 |
|---|---|---|
| **补"冲突告知"**：提示词与 skill 冲突时显式提示（画布线已有"绝不静默"，图片线还没有） | 无 | 等并行会话收尾 |
| **图片线补硬约束层**（让 `/api/generate` 认负面词） | 无 | 同上 |
| **`image.concept_set`「概念视觉方案」**：账号级签名 + 每篇三格（母体 / 钩子 / 勾镜头）+ 结果墙按镜头归位 + **声明 `previewStep: true` 自动拿到三步预览（可看可改最终方案）** | **你跑完第 1 套的反馈** | 拿到反馈后 |
| 母体库做成产品里的那张表（带"已用次数"与去重建议） | 签名定稿 | 随新技能 |

**为什么新技能要等你的反馈**：工作台的字段应该由**真实出图结果**倒推，
不是我现在猜一个 —— 否则就是先固化一套可能不对的流程，**而这正是会做出"大同小异"的原因**。

## 一句话的执行顺序

**今天**：拍一张无标产品图 → 用 `image.scene` 跑 5 张（粘贴上面那三段）→ 把"哪几张对味"告诉我。
**本周**：定签名七条 → 用母体表挑下周 3～4 个母体 → 开始每周 3～4 篇的节奏。
**之后**：我按你的反馈把「概念视觉方案」做出来，你就不用每次粘那三段了。
