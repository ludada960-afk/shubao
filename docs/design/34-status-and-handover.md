## 六、协作纪律（这个 worktree 是 5–6 条线共用，踩过的坑都在这里）

1. **提交一律 pathspec**：`git commit -m "..." -- <你的文件>`；提交前 `git diff --cached --name-only` 核对；提交后**看完整输出**（并发会撞 index 锁，可能静默失败）。
2. **严禁** `git add -A` / `git commit -a`；**严禁 `git stash`**（曾把别人整批改动抹掉）；不要 `checkout/reset/restore` 别人的文件。
3. 需要「改前/改后」对照时，用**文件级备份**或**从 HEAD 读一份到临时文件**，不要动 git 快照。
4. 报「主干坏了」之前**先重跑一次**——并发写入会造成瞬时中间态（已有一次误报）。
5. **不许为了变绿而放宽/删除断言**；规范被取代时改断言必须**引用决策编号**。
