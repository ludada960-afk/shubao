## 执行顺序（按「客观坏掉」优先）
**P0（功能坏 / 用户可见不该看的）**
1. 乱码 ×2（画面比例面板 / 视频模型面板）—— 注释泄漏成正文
2. 顶栏 LOGO 图 404 / 不显示
3. 「包含模块」死按钮 —— 点击无效，且没进生成参数
4. 开发说明文字泄漏给用户（多处）
5. 左下角无意义悬浮按钮
6. 子页面左右贴边、区域间无间隙

**P1（视觉语言 / 抄竞品）**
7. 子页面顶栏三格（左返回 / 中名称 / 右积分账户）+ 去 LOGO + 只留一行可选栏
8. 图片侧两卡恢复左右对称歪；视频侧首尾帧照抄；智能成片不歪
9. 视频侧「一个大框包住上传+输入」照抄图片侧
10. 选中态去黑底，改 liuyingai 交互语言
11. 首页两张模式卡 = flova 扇形张开
12. skill 精选区照抄 flova
13. 模型下拉 = 打钩 + 紧凑
14. 「智能成片 / 全能参考」命名统一
15. 顶部模式卡标题白底 + 背景色
16. skill 分类切换区 + 「更多 skill」按钮
