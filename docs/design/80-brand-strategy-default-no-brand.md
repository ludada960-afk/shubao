## 二、风险：用户的直觉是对的，但理由要换一个

⚠️ **以下不是法律意见**，只是把要评估的风险类别列清楚，具体定性要问律师。

用别人的品牌做内容，风险有四类（前两类是你担心的"侵权"）：

1. **商标**：关键在是否构成"商标性使用"（是否用于识别商品来源、是否暗示与品牌的关联或背书）。
2. **著作权 / 产品图与包装设计**：包装设计、图案、摄影素材本身可能有著作权。
3. **不正当竞争 / 混淆**：让受众误以为你与该品牌有合作关系。
4. **肖像权**：出现模特脸时（Aura 几乎不露脸，这条它天然避开了）。

**但还有一条更容易被忽略、而且更"确定"的：**
5. **平台侧——未报备的商业内容**。研究结论里明确：**所有商业合作笔记必须走蒲公英报备**
   （私下置换不报备，后续无法投流且有处罚风险）；而《互联网广告管理办法》第九条第三款要求
   通过"知识介绍、体验分享、消费测评"等形式推销并**附加购物链接**的应显著标明"广告"，
   且专业解读指出该款**未穷尽列举**（不挂链接也可能被认定为广告）。
   ⇒ **无授权用品牌 + 看起来像商业内容** = 侵权风险 **叠加** 未报备广告风险。

**而"接商单"那一侧的风险结构完全不同**：品牌方会给**授权物料 + brief + 审核**，
你是在授权范围内使用，且走平台报备 —— 那才是合规路径。
最后 1/3 那 11/13 条带官方 campaign 话题的内容，形态上更像**合作投放**，不是自作主张用品牌。

### 所以正确的结论是

**不是"早期风险高、后期风险低"，而是：**
- **没有授权就用品牌 → 风险是恒定的**（不随时间变好）；
- **有授权的商单 → 风险可控**（但要报备、要标注、要过品牌审核）；
- **完全不出现品牌 → 风险最低，而且数据上更划算**（收藏掉 62% 那条就是证据）。

**你的方向是对的：早期应该做无品牌的内容。** 只是理由不是"早期才有侵权风险"，
而是"**无品牌内容的收藏表现明显更好，且没有授权风险**"。

## 三、方案怎么改：**默认无品牌层 + 商单可插拔**

这是对 77 / 78 号的一处**结构性修改**：把"品牌"从默认字段里拿掉。

| 层 | 默认（内容线） | 商单模式（另开） |
|---|---|---|
| 签名 | 不露脸 / 柔光 / 3:4 / 统一调色 / 引用式短标题 | 同左 **+ 品牌方 VI 约束** |
| 母体 | 季节 / 自然 / 情绪命题（**与品牌无关**，本来就不需要品牌） | 同左，但母体要**贴合品牌 brief** |
| 视觉主体 | **无标产品 / 材质道具 / 场景**（见下） | 品牌方提供的**官方物料**（有授权） |
| 字标 | **不出**（整条"字标海报"镜头默认禁用） | 用品牌方给的**官方字标**，且"文字原样、不许自己编" |
| 出处 | 自己拍/站内生成的无标素材 | 品牌 brief + 授权物料 |
| 合规 | AI 标识（图必须带显著标识） | AI 标识 **+ 蒲公英报备 + 标注"广告" + 品牌审核** |

### "无品牌"了那画面拍什么？—— 这是要一起定的关键问题

Aura 那股"高级感"有很大一部分来自**品牌物料的质感**（兰蔻粉水那种棚拍、YSL 的字标）。
去掉品牌之后，视觉主体要换，可选的做法（按可用度排）：

1. **无标产品**：素瓶、无 logo 包装、哑光罐、玻璃器皿 —— 形状与材质在，标识不在。
   （站内已有的「展厅静物主视觉」「悬浮主视觉」「单色糖果系广告」本来就是按这个路子做的）
2. **材质与道具为主角**：陶土 / 丝绸 / 亚克力 / 干枝 / 水果 / 石材 —— **这正好是母体的载体**，
   母体（秋/海/落日）本来就该由材质与场景来表达，不需要产品。
3. **纯场景/空镜**：把"空镜"这条镜头从"当呼吸页用"提升为**主力**。
4. **自产品牌**：如果你要长期经营，**你自己的品牌（薯包）就是唯一你有权用的品牌**。
   这条可以放到后期当"自有品牌"线。
