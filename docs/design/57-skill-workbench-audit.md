# 全局 skill 工作台核查（2026-09-19）

> 起因：用户批注 #1-2「他们这里是有切换按钮的，你为什么切换按钮点了是没有反应的**呢？**
> 这个问题我之前已经提过了呀，你为什么不去解决呢？**而且全局可能都存在类似的情况，
> 你全部都应该重新去衡量，去抄完善呀**」，以及 #2-1「你应该**每个skill工作台都去深度点击**，
> 看看他们各个按钮下面是什么反馈啊」。

## 结论（先给结论）

**92 条技能全部点过一遍，共点 831 个控件，真正「点了什么都没变」的只有 2 个 ——
而那 2 个是上传卡片（弹系统文件框，DOM 本来就不会变）。**

也就是说：skill 工作台里**没有成片的、系统性的死按钮**。

## ⚠️ 这份报告的第一版是错的，先说清楚怎么错的

第一版报出「约 30 条技能有死按钮」，还列了 6 组待复核候选（运镜档位 / 风格档位 /
比例 / 历史页签 / 图文数字档 / 清晨）。**这 6 组我一条条手工点过，全部是假阳性**
（点「推近」is-selected 确实会移过去；点「参考/自定义风格」确实会换出字段；「历史」页签确实切页）。

### 真根因：我按**下标**点，不是按元素点

COLLECT 收集控件时记的是它在节点列表里的下标，CLICK 再按同一套选择器取第 N 个。
但**每点一次（还带一次复原）页面就会重渲染**，节点集合随之变化 —— 同一个下标下一次
就指到**别的元素**上去了。点错了东西，当然「什么都没变」。

改成给每个控件打一个稳定标记（data-audit-id）再按标记点之后，
发现数从「约 30 条技能」直接掉到「1 条技能 / 2 个控件」。

⚠️ **教训：跨进程的「标识」必须是内容本身（或稳定标记），不能是位置。**
   位置在「页面会重渲染」这个前提下根本不成立。

### 沿途还踩了三个坑（都记下来，免得下一个人再踩）

1. **假绿**：探针里的索引插值写错 + 评估助手对数字返回值会抛异常 → 点击全失败、控件数报 0，
   表现成「35 个技能全都验过了，一个死按钮都没有」。**是脚本里的自证计数器把它戳穿的**
   （「共点 0 个控件」）。现在：一个都没点到就 process.exit(2) 响亮失败。
2. **签名撑爆**：把整页所有 className 拼成字符串传回来（几百 KB），CDP 返回被截断、JSON.parse 失败。
   改成**在页面里摘要成两个数**再返回。**跨进程传的「签名」必须定长，不能是原始内容。**
3. **过度过滤**：为了排除「弹文件框」的控件，顺手加了 n.closest('label') —— 结果几乎所有控件
   都在某个 label 里，控件数从 10 掉到 1。**过度过滤比漏判更危险：它会让人以为「全都验过了」。**

## 工具还剩的两类已知假阳性（都不是 bug）

| 类别 | 例子 | 为什么假 |
|---|---|---|
| 弹**原生文件对话框** | 上传卡片 | 系统对话框不进 DOM。这次最后剩下的那 2 个就是它 |
| 需要**真实用户手势** | 视频的「全屏」 | 全屏 API 拒绝不可信事件（eval 里的 click 不算）。手工点也是 false，
|  |  | **但这是 API 的门槛，不是 bug** —— 真人点击时这个工具证伪不了 |

（「放大」那颗按钮弹的是 **portal**，挂在 .media-workbench 外面；签名一开始只按工作台取，
把它误判成死按钮。签名改成看整个 document 之后就对了。）

## 怎么跑的

.tmp/audit-skills.mjs：把声明源里 **92 条技能**（50 图片 + 42 视频）逐条打开子页面，
在 .media-workbench 里收集全部可点控件（button / role=tab / role=checkbox / select），
**逐个点一遍**，用「点击前后的 DOM 签名」判断有没有反馈。签名 = aria 状态 + 正文长度与哈希
+ 控件数 + 全文档 class 长度与哈希（**全部在页面里算成定长的数**再返回）。

**零成本**：本机后端(3001)未启动，/api 全失败；并且显式排除所有计费按钮
（.media-workbench-submit / -paid / -parse，以及文案含 生成/解析/购买/订阅/积分 的）。

## 复现

node .tmp/audit-skills.mjs —— 需要 dev server 在 5231、CDP 代理在 3456、后端 3001 **关着**。
它会打印每条技能的控件数与无反馈清单，末尾一行是总数；**点不到任何控件时会 exit 2 报错**。
