# 45 · 封面出图清单（17 张）

> 数据源：`src/skills/imageSkills.js`（7 条图片 Skill）、`src/skills/videoSkills.js`（10 条视频 Skill）、
> `src/skills/coverTemplates.js`（3 个模板族 + 5 个色相 + 5 条铁律 + `buildCoverPrompt()`）。
> 声明改了，照同一张表重出即可；**清单必须与声明一一对应**（门禁：每个 Skill 都要有封面，不许出现空卡）。

## 统一规格

- 尺寸 **1600×1200（4:3）**；列表里会缩到约 274×205，缩图后主体仍要认得出
- 每个 Skill **一张**封面；三个模板族：`case-3up` 案例三拼 / `hero-single` 主体单图 / `poster-style` 海报满幅
- 五个色相：`warm` 暖调（电商）· `soft` 柔调（人像）· `cool` 冷调（白底/修图）· `accent` 高饱和（社媒）· `neutral` 中性（自由创作）

### 五条铁律（每张都要满足）

1. 统一 4:3（1600×1200），四角不得出现水印、logo、二维码
2. 标题最多 8 个汉字，副标题最多 16 个；标题字号明显大于副标题
3. 同一套封面字体气质一致（标题无衬线粗体，副标题同族常规字重）
4. 留白不少于画面 18%，保证缩到 274×205 仍认得出主体
5. 画面里不出现模型名、价格、积分或促销文案（那些由界面渲染，不进封面）

## 逐张提示词

> 下面是每条 Skill 的提示词主体。**通用前缀**（每张都加）：
> 「商业级棚拍质感，柔和棚光 + 轻微景深，画面干净、有呼吸感，缩到 274×205 依然辨识度强；
> 不要水印/logo/二维码/价格/积分/模型名；不要拼贴边框；不要超过两种字体气质；留白不少于 18%。」

1. **自由创作**（`hero-single`/中性）：一张风格鲜明的 AI 生成插画或摄影作品，整幅铺满，左上留白给标题「自由创作」。黑白灰为主，只留一个点缀色。
2. **海报设计**（`poster-style`/暖调）：一张文化活动的商业海报成品，满幅主视觉，底部压半透明标题条，写「海报设计」，副标题「版式与文字层级一起给」。米杏陶土暖白。
3. **社媒封面**（`poster-style`/高饱和）：一张公众号/视频号封面成品，主视觉满幅，底部标题条写「社媒封面」，副标题「一眼看懂主题」。品牌紫为主点缀。
4. **电商套图**（`case-3up`/暖调）：同一款商品的三种电商成品图（白底、场景、卖点），右侧三图错落叠压，左侧标题区写「电商套图」，副标题「白底+场景+卖点成套」。
5. **白底商品图**（`hero-single`/冷调）：一件商品的白底主图，多角度呈现细节，整幅铺满，左上留白写「白底商品图」。雾蓝灰绿冷白。
6. **模特试穿**（`case-3up`/柔调）：同一位模特穿着商品的三张不同姿势照片，右侧错落，左侧写「模特试穿」，副标题「姿势与场景可选」。奶油雾粉。
7. **小红书图文**（`case-3up`/柔调）：一组小红书风种草图（封面 + 两张内页），右侧错落，左侧写「小红书图文」，副标题「真实感优先」。
8. **智能成片**（`case-3up`/高饱和）：一段商品短片的三个关键帧（开场、特写、收束），右侧错落，左侧写「智能成片」，副标题「一句话起步」。
9. **首尾帧**（`case-3up`/冷调）：同一镜头首帧与尾帧的对比画面，右侧错落，左侧写「首尾帧」，副标题「锁定起点与终点」。
10. **爆款复刻**（`case-3up`/暖调）：参考片节奏与替换后成片的对照画面，右侧错落，左侧写「爆款复刻」，副标题「保住节奏换内容」。
11. **图生视频**（`hero-single`/暖调）：一件商品静图与它动起来后的画面并置，整幅铺满，左上留白写「图生视频」。
12. **商品动态展示**（`hero-single`/暖调）：商品旋转、光影扫过的动态瞬间，整幅铺满，左上写「商品动态」。
13. **内容替换**（`case-3up`/柔调）：同一段动作里人物被替换前后的对照，右侧错落，左侧写「内容替换」，副标题「一键换人」。
14. **模特动态**（`hero-single`/柔调）：模特转身迈步、衣摆飘动的瞬间，整幅铺满，左上写「模特动态」。
15. **运镜控制**（`case-3up`/高饱和）：同一场景下推、移、环绕三种运镜的画面，右侧错落，左侧写「运镜控制」，副标题「指定镜头怎么走」。
16. **延长续写**（`case-3up`/冷调）：同一镜头前后两段连续画面的衔接，右侧错落，左侧写「延长续写」。

## 出图之后

1. 文件按 Skill id 归档：`cover-<skillId>.png`（例：`cover-image.poster.png`）；
2. 填进对应 Skill 声明的 `cases[0].cover`（或二期后台上传）；
3. **视频案例先放占位视频**（≤6 秒、静音、标 `placeholder: true`），你自己生成后逐条替换，**不用改代码**；
4. 替换完重跑 `npm run precommit` —— 封面契约门禁会校验「每个 Skill 都有封面计划」。
