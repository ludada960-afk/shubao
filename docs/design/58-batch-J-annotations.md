## ★ 最重要的一条：图片侧的「预览」该怎么做（用户给了明确路径）

用户原话（image.png 批注 1）：「你可以来看一下他们这个视频创作的这个skill页面。他这里有一个**教学示例**，
这个教学示例里面的这个视频它也是可以下载的……如果说你没办法在线解析或者在线解析的效果没有那么好的话，
那你也可以去下载之后去解析他的视频内容，你好好看一下，它里面有一个叫**代为撰写**的功能。
这个功能它实际上就是**我们图片生成那边的板块里面的那个预览的功能**。
只是图片的话，他在生成的配置做好之后**进行预览，然后再去生成**，这样的流程会更合理一些。
然后视频这边的情况，它其实是在生成之前就必须要做好这个视频脚本的创作，所以他才会把这个**代为撰写**
放在这个**提示词的输入框**这个位置。相当于它点击生成按钮是直接生成的，但是它在生成之前，
它需要对你的内容进行一个AI的精细化调教。而图片生成和视频生成他们的调教的流程是在不同的位置的。
**但他们的内在逻辑其实是一样的。**所以图片生成那边他们的预览应该怎么做？
你可以去参考他这个视频创作这边的**代为撰写**是怎么做的。本质上就是图片生成那边的预览的功能。
你照抄他的思路去做就对了，**整个UI和设计你也要跟他一样去做**。
然后视频生成这边的skill页面，你也要**全面的去抄**他们视频制作页面里面的**所有的子页面**，
包括布局风格 / 设计理念 / 整体 UI 交互，**不能再漏掉任何的点**。
而且他视频制作这边的子页面**绝大部分是有教学示例的**，你要**结合教学示例做深度匹配**，
按他的讲解 + 工作台里真实有的按钮和功能去做规划和设计。**我们的目的就是要跟他抄得一样。**」

## 执行顺序（按 影响面 × 用户强调程度）

**A 组 · 全局骨架**（#2-2 说这条要整个去改）
1. 总页面顶部去掉 LOGO + 板块切换条，内容顶上；右上留积分+账号（#2-1 / #3-1 / #3-2）
2. 全局背景重做：顶栏 + 内容 = 一个整体区块，不是三块拼接（#2-2）
3. 左导航：按钮+文字成一体 + 底部渐变进度条（hover 充能/回落 + 文字变色），定成全站设计语言（#2-3）；
   「生成过程」按钮移进左导航下方（#2-4）；背景过渡做顺（#12-2）

**B 组 · 卡片与 skill 区**
4. 首页模式卡照 k-fashionshop：选中再抬高一点点（#5-1 / #6-1）
5. 热门 skill 行：左图右文 / hover 遮罩+试一试 / 预览窗 / **两行（上5下3）** / 毛玻璃（#3-3）
6. 「更多 skill」移到分类页签右边（#4-3）
7. 案例区：复用原有的「左文案 + 右效果图」，搬进预览区，不重做（#4-1 / #4-2）

**C 组 · 面板**
8. 生图模型下拉：紧凑、第一个模型补副标题（#5-2）
9. 画面规格面板：删描述与副标题、尺寸卡照视频侧重做、规格补全（#7 / #8 / #9）
10. 视频模型：**找回原有模型清单**（#10-1）—— 先查证「原来那版」到底有哪些
11. 视频创作台照抄图片侧（读代码抄数值）（#11 / #12）

**D 组 · 预览流程（最大的一件）**
12. 看竞品视频 skill 的**教学示例**，学「代为撰写」；翻译成图片侧的「预览」；
    视频侧 skill 的所有子页面要全面对齐教学示例里的讲解（#1 的长文）
