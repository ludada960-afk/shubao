# 78 · 内容体系与艺术指导 —— 从「做一个工作台」到「长期经营一个视觉账号」

> 起因：用户 2026-09-25 的追问。核心三句（逐字）：
> 「你刚刚说了那么多，其实我都没有太明白你的逻辑，就是你能不能**更简单的把你想明白的事情跟我传达清楚**？」
> 「我们怎么做到像他那样**每天生成的内容都是有一套独特的审美语言**，然后有独特的设计方案，独特的这种创意套路，
>  因为我感觉如果我们**把方案写的太死的话，会导致每次生成出来的内容都是大同小异的**吧。」
> 「他们生成的内容其实都挺没有什么逻辑的……但是他们的**创意方向我觉得是特别的天马行空的**。
>  你自己认为他们的这些天马行空的设计创意是怎么来的呢？是不是就纯靠AI就可以想象出来这些设计创意呢？」
> 以及一条明确要求：「**你不要纯靠自己去深度思考，你还要去做深度调研**……你也可以通过像github吧，像各种社媒呀……」
>
> 调研过程与来源见 `docs/research/2026-09-25-art-direction-research-digest.md`（四路并行调研，逐条带 URL）。

## 〇、一页版结论（先看这个）

1. **你真正要的是"怎么长期经营一个像他那样的账号"，不是"一个子页面"。** 子页面只是这条链里
   **出图那一步**的工具。我上一版把这两件事混在一起讲，所以你没听明白 —— 这一版分开：
   **内容体系（主菜，不用写代码）** 与 **工具（配菜，可以晚做、可以先手工）**。
2. **他们不重样的原因，不是"AI 会想创意"，而是两层分离**：
   **账号级永远不变的"签名"** + **每篇必须换掉的"母体"**。
   所以"方案写太死会不会雷同"这个问题本身问错了地方 —— **雷同的根源不是方案写死，是母体不换**（§三）。
3. **创意来源有机制、可批量生产，不是靠灵感。** 41 条标题拆出来：**只有 8 条出现品牌名，
   32 条出现"概念母体"词**（季节/自然/情绪命题）。他们的做法是
   **把产品并置到一个公共意象母体上，标题只说母体、不说产品**（§二）。
4. **所以不需要你每次给我新提示词。** 每篇你只要给三样：**一个母体 + 一句钩子 + 勾几个镜头**，
   提示词由三层模板拼出来（§六、§八）。母体库是一张**可枚举的表**，不是每天现想。
5. **"先去找成熟方案查漏补缺"这个方向对了一半**：出图技法确实有成熟做法可抄（§四），
   但**"每天一套、套内还要有变化"这一层，市场上是空的** —— 没有产品把"一个可版本化的方向对象"
   和"每张必须有差异"解耦开。这块要我们自己补，而它正好是我们可以占的位（§四末、§六）。

## 二、一手证据：把 41 条标题拆开，创意到底从哪来

用本仓已有的 `.tmp/xhs/aura-all/notes.json`（41 条，批 BF 那批扒下来的）做机械统计，
脚本 `.tmp/xhs-aura-titles.mjs`，输出 `.tmp/xhs-aura-titles.log`：

| 观察 | 数字 |
|---|---|
| 标题里出现**品牌名** | **8 / 41**（YSL、PRADA、Loewe、VALENTINO、阿玛尼） |
| 标题里出现**"概念母体"词**（季节/自然/情绪命题） | **32 / 41** |
| 标题形态是「**"……」**」引用式短句 | **40 / 41** |
| 疑问句标题 | 4 / 41 |

**三类母体（从 41 条里数出来的）**：

- **季节与自然**：秋（4 条）、夏（10+ 条）、海（4 条）、雨（2 条）、落日/海岸/橘子/浆果/巧克力/玫瑰。
  例：《"被巧克力吻过的秋天🍫"》《"夏日碎片，是橘子味的"》《"找不到答案时，去看海"》。
- **情绪命题 / 价值观短句**：爱（6 条）、欲望、权力、"自己"（2 条）、时髦、浪漫、答案。
  例：《"爱不是重复，是不断看见"》《"欲望无需绕行，爱也一样"》《"你本身，就值得庆祝"》。
- **少数品牌直给**：只有 8 条把品牌写进标题。

### 机制（这条是这份文档的核心）

> **产品不说产品，说它像什么、或者让你成为谁。**
> 产品（香水/口红/护肤）被**翻译成一个公共意象母体**，视觉按那个母体执行，标题只说母体。

这在创意学里有名字：**Koestler 的 bisociation（双联想）** —— 把两个原本无关的"思维母体"
并置成一个新的意义矩阵；而且 Koestler 明确区分了三种领域，**艺术恰恰是"两个母体保持并置
（held in juxtaposition）"的那一种**（笑话是替换、科学是融合）。这正是为什么你会觉得
"他们的创意**没有什么逻辑**，但审美**明显被把控过**" —— 那两个观感其实是同一个机制的两面：

- **"没有逻辑"** = 产品与母体之间**故意保持间接**（间接性本身就是钩子，直接了就是广告腔）；
- **"审美被把控"** = 不论母体怎么换，**执行纪律不变**（不露脸、柔光、同一套调色、短句标题）。

### 由此推出的关键结论（直接回答你的担心）

**创意不在"方案"里，创意在"母体"里。**
方案（调色/光位/构图纪律）写死**不会**导致大同小异 —— 它写死才保证了一套图看起来是一套。
**母体不换才会导致大同小异。** 我上一版把 9 个方案字段当成"每篇都要填"，那确实会做出
千篇一律的东西；但错的是**"每篇都要重新填方案"这件事**，不是"方案要写死"。

## 三、两层分离：稳定层（签名）vs 变量层（母体）

### 稳定层 —— 我们该固化的"签名"（设一次，长期不变）

依据：本仓前几轮实测收敛的 Aura 特征（RTK 批 AX/BF）+
**Ehrenberg-Bass Institute 的 distinctive assets**（成文概念："devices, aside from the brand name,
that help identify a brand"，可以是颜色、图形、形状等任何识别装置，**要长期不变**）。

| 签名 | 取值 | 依据 |
|---|---|---|
| 人物纪律 | **几乎不露脸**，人物只出手部/背影/局部 | 本仓实测 |
| 画幅 | 统一 **3:4 竖版**（封面另按平台） | 本仓实测 |
| 光位 | 柔光为主，戏剧光只用于暗场母体 | 本仓实测 |
| 调色 | 一套统一的质感/颗粒/饱和度纪律（博主本人说"需要自己后期"） | 本仓实测 + 本人自述 |
| 字标纪律 | 品牌字样**清晰可读、文字原样、不许自己编** | 本仓实测 |
| 标题书写签名 | 「**"……」**」引用式短钩子，不写产品参数 | §二 统计（40/41） |
| 色簇 | 5 个实测色簇（灰调大地 / 海蓝灰雾 / 柔雾浅粉 / 暖砂裸粉 / 深棕暗红） | 批 BF 实测 41 张封面聚类 |

**为什么签名要"少而刚性"**：Ehrenberg-Bass 对行业的纠偏是 **differentiation（要新）** 与
**distinctiveness（要被认出）** 是**两个不同的轴**；大规模物料生产应该走 distinctiveness。
反例很有名：Tropicana 换包装移除了"带吸管的大橙子 + 强烈橙色"这两个识别装置，首季销量跌 20%
（约 3300 万美元），原因不是情感，是购物者"**找不到**"了。⇒ **识别装置越少越刚性越好。**

### 变量层 —— 每篇必须换的（创意就在这里）

母体 → 由母体**决定**的主色簇 → 材质/道具/场景 → 镜头清单 → 钩子句。

⚠️ 注意这里有一条**漂亮的巧合，它把整套东西扣起来了**：母体**自己决定色调** ——
海→海蓝灰雾，巧克力/秋→灰调大地，落日/南法→暖砂裸粉，粉/玫瑰→柔雾浅粉，晚宴/权力→深棕暗红。
我们批 BF 实测出来的 5 个色簇，**基本就是这个映射表**。所以"换母体"这一步自动把颜色也换掉了，
不需要额外设计"这次换什么颜色"。

## 三-b、签名在代码里已经有落点（**不是从零发明**，本条是 2026-09-25 补查出来的）

用户追问"签名这个规则是做在哪里"，于是把仓库翻了一遍。结论：**签名要的东西，服务端已经有一份实现，
叫 `campaignBible`**；我们缺的不是机制，是"**把它从每次算、改成账号级存一次**"。

### 已有实现（**生产在跑的**）

| 位置 | 内容 |
|---|---|
| `server/ecommerceEngine/campaignBible.mjs` | `compileCampaignBible(direction, overrides, styleReferenceProfile)` → 返回 `schemaVersion: 2` 的**艺术指导对象**，字段就是签名要的那些：`palette` / `lighting` / `composition` / `cameraLanguage` / `backgroundLanguage` / `typographyIntent` + `typographySystem` / `consistencyLocks` / `visualKeywords` / `editableBrief` |
| 同上（色彩优先级） | `customColors`（`custom_colors`）**优先于**设计方向的 palette；且一旦给了自定义色，会把它写成一条 **canonical consistency lock**（`palette: …`）并把旧的调色锁剔除 —— 这就是"锁定品牌色一路带到出图请求"那条门禁守的东西 |
| `server/ecommerceEngine/typographyPolicy.mjs` | `compileTypographySystem()` —— 排版/字体单独一套策略，已接进 bible |
| **反面约束（已端到端跑通）** | 面板 `src/pages/Home/ec/GenerationConstraintsPanel.jsx`「避免出现的元素」→ `genSettings.negativePrompt` → 服务端 `negativeConstraints` → `server/ecommerceEngine/promptCompiler.mjs` 里 `compileAssetRequest()` 输出成请求里的 **`forbidden`** 字段 |

⇒ 所以"不露脸 / 无文字 / 无水印"这类**反面纪律**，和"色簇 / 柔光 / 构图 / 字体"这类**正面纪律**，
**都已有承接字段**。签名不需要新造数据模型。

### 真正缺的两件事（这才是要做的）

1. **账号级持久化**：现在 bible 是**每次生成时**从"设计方向 + 覆盖项 + 风格参考档案"**算出来**的，
   没有"设一次、以后每篇都继承"的存放位置。签名 = 把这份 bible 变成一个**账号级对象**，
   每篇生成时自动带上，而不是每篇重新生成/重新填。
2. **母体库**：母体表（含"已用次数"）—— 它**不进**出图请求，只决定"这一篇往 bible 的
   `palette`/`lighting`/`visualKeywords` 里填什么"。

### 一条**不在出图链路上**的签名项

**标题的书写签名**（「"……」」引用式短句）与出图无关，它属于**文案与发布环节**，
落点是发布包里的标题模板 + 人工润色（见 §七 合规那段："AI 产出必须人工二次改写"）。
不要试图把它塞进提示词。

### 阶段 0（手工阶段）它落在哪

**一份签名块文本 + 一张发布前自检清单**，都是文档，零开发：
出图时把签名块粘在提示词最前面（正面纪律），反面纪律填进「避免出现的元素」那一格（已有面板），
出完对着清单核一遍（不露脸？3:4？色簇对？字标原样？）。**这一阶段不需要任何代码改动。**

## 四、市场调研结论：行业怎么做，空白在哪


（完整来源见 `docs/research/2026-09-25-art-direction-research-digest.md`）

### 4.1 你的直觉是对的：这在广告业叫"艺术指导体系"

- 行业的标准链路（有文献字段表可抄）：**client brief → creative brief → insight → big idea / concept platform
  → key visual（KV/主视觉）→ 延展/adaptation**。
- **creative brief 的标准字段**可直接当我们的输入 schema：Background / Target audience / Key insight /
  Objectives / **Single message**（唯一要说的一件事）/ **Tone of voice** / **Mandatories**（强制元素）/
  Deliverables / Timeline。brief 必须同时具备 **directional（约束）** 与 **inspirational（感觉）** 两层 ——
  **这就是"稳定层 / 变量层"分离的上游来源**。
- **KV（key visual）的定义就是"被跨媒介重复的那张图"**，记协的表述是
  "the **singular, iconographic image** that is the foundation upon which a movie's marketing campaign is built"。
  ⇒ 我们每篇要做的是**一个 KV + 一套延展**，不是"9 张平等的图"。
- 洞察来源在广告公司是专门职能（account planning），纪律是 **"planning truly begins when research ends"**
  —— 洞察不是数据摘要，是从数据里提炼出关于人的判断。

### 4.2 产品侧：只有三种"方向"承载形式，而且全行业都只有一个旋钮

| 承载形式 | 代表 | 说明 |
|---|---|---|
| 内建枚举预设 | Firefly style presets（约 150 个 + `strength`）、Ideogram curated styles、Krea 1000+ | 固定枚举，**不能自定义**（除非训私有模型） |
| 参考图 / 参考码 | Midjourney `--sref` / Moodboards、Recraft V4 Styles（1–10 张参考）、Ideogram 自定义（≤3 张） | 可复用，但**不可编辑、不可版本化** |
| 私有训练资产 | Firefly Custom Model（asset ID）、Krea 自训、LoRA | 最稳，但重、贵、不可移植 |

**品牌规则作为数据**做得最完整的是 **Adobe GenStudio**（上传品牌指南 → AI 抽取 brand voice /
image guidelines / channel guidelines / logos / colors → 生成侧有 **Content check（Brand validation）门禁**）；
**Canva** 是 Brand Kit（资产 + 指南）+ **Brand Controls**（强制只能用 kit 内的颜色字体）。
⇒ **"方向可下发 / 约束可强制 / 结果可校验"这个三段式值得抄。**

### 4.3 空白（= 我们能占的位）

1. **没有"跨天/跨批次的项目级方向对象"** —— 有的只是一次性 set（Recraft）或发布标签（GenStudio）。
2. **风格资产没有版本 / 回滚 / A-B** —— MJ moodboard 最接近，但官方原文写明
   "**As your moodboard updates, it will generate new codes**"，方向一改 code 就变，
   旧版本只能翻历史 prompt 找。
3. **"方向稳定性"与"单图差异度"没有解耦** —— 所有产品都只有一维强度旋钮
   （`strength` / `--sw` / `stylize`），**没有任何产品提供"保持方向的前提下，第 N 张必须有 X 类差异"**。
   **这一条正是你担心的那个问题的行业级答案：连大厂都没解决。**
4. **视觉一致性没有自动验收** —— Content check 检的是品牌文本与合规，不是"这套图是否成组"。
5. **没有产品以"日更一套"为默认工作循环**；而 **MJ 明确对"探索方向"收 GPU 时间**
   （Style Creator："Each set of preview images uses your GPU time"）—— 也就是说
   "每天先试 5–10 轮方向再定"在它的计费模型里是**被惩罚**的行为。

### 4.4 一致性工程的五条硬教训（可直接用，都有出处）

1. **必须每张重新锚定，不能只靠上一张链式传递。** 实测原话：长系列"style decays because nothing
   carries it after beat 1"，结果"**beat 4 is four reinterpretations from beat 1**"。
   ⇒ 每一张都要带完整的方向块，不是"接上一张继续"。
2. **把风格从文本搬到更强的载体**：文本（天生漂）→ 参考图（钉住实例）→ 训练权重（最难撼动）→
   项目记忆。有参考图就用参考图。
3. **长提示词会被稀释**：主体必须前置，**一次只改一个地方**（"One instruction carrying two changes
   will usually cost you more retries than two separate passes"）。
4. **风格块 + 固定注入顺序**才是可维护的形态（官方也说 blocks 赢在可维护性，不是赢在 JSON）。
5. **变化要显式枚举，并且必须配上限**：MJ `{}` 排列、A1111 X/Y/Z + Prompt S/R、Dynamic Prompts
   `{a|b|c}`、ComfyUI Impact Pack 通配 —— **所有成熟工具都配了"最大生成数"上限**，防"意外产出上千张"。

## 五、创意从哪来（可批量生产的部分）

创意 = **母体库（这一篇长什么样）× 选题来源（这一篇讲什么）**。两者**正交**，所以组合数极大，
天然不重样。

### 5.1 母体库（要建成一张表，像技能库那样）

可枚举的公共意象家族：**季节 / 天气 / 地理 / 材质 / 情绪命题 / 文学电影艺术史引用 / 生活场景 /
感官（味觉嗅觉触觉）**。

每条母体登记：`母体名 · 一句话立意 · 派生色簇 · 常见材质道具 · 适合的产品类型 · 已用次数 · 最后使用日期`。

**"已用次数"是关键字段** —— 它是防重复的机制（研究结论：把防重复做成计数器，
"相邻两期的视角/人群是否真的换了"、"该栏目数据是否跌破自身篇均基线"都可以量化）。

### 5.2 选题来源（四类，都可操作）

1. **对标账号的"入池选题"** —— 不是抄它最火的那篇，而是找**超出它自己平均水平 2 倍以上**的选题
   （做法：翻最近 30 篇算平均点赞，把高于均值 2 倍的记下来）。这是"这个选题在它的账号里已经被
   平台验证过"的信号。
2. **货架差评区 + 追评 + 问大家** —— 2026 年最被强调的**原创**来源，方法论是冲突营销
   （发现冲突 / 解决冲突 / 制造冲突）。底层判断很重要：**"高赞笔记拆解已经没信息差了"**
   （竞品、服务商、达人、AI 都在拆同样的笔记），而**差评区给的是"一个还没被解决的问题"**。
3. **平台官方灵感/活动**（"命题作文"）+ 搜索下拉词 + 长尾词。
4. **周复盘反推** —— 看**比例**（收藏率/评论率/分享率）与搜索收录率，不是绝对点赞。

### 5.3 给自己"上强度"的算子（有出处的具名方法）

- **SCAMPER 七算子**（Bob Eberle 1971，受 Osborn 启发）：替换 / 组合 / 调整 / 修改放大缩小 /
  转用 / 剔除 / 反转。可以当成"在同一个母体上做七种受控扰动"。
- **形态分析（General Morphological Analysis）**：把问题拆成 N 个正交维度、每维列举取值，
  **笛卡尔积就是全部合法执行**。这就是"母体 × 产品 × 镜头 × 材质"那张组合表。
  （⚠️ 把这两个组合成"变量矩阵 + 算子扰动"是**本文的构造**，不是行业命名框架 —— 别对外说成有出处的标准。）

## 六、修正后的产品形态（我上一版错在哪）

**错**：把 9 个方案字段当成"每篇都要填" → 每篇都在填同一份方案 → 必然大同小异。
**改**：把方案**拆成两层**，一层设一次，一层每篇换。

| 层 | 内容 | 频率 |
|---|---|---|
| **账号级（设一次）** | 签名规范（不露脸纪律、画幅、调色、字标纪律）+ 母体库 + 默认镜头清单 + 默认模型/清晰度 | 长期不变 |
| **每篇级（3 个输入）** | **① 选一个母体（或自定义）② 一句钩子 ③ 勾几个镜头** | 每篇 |

**提示词 = 三层拼装**：`签名块（账号级，每张都带）` + `母体块（本篇，每张都带）` + `镜头句（这一张）`。
每条都有出处支撑：签名块对应 style bible / look sheet（60–120 词、不含动作与镜头、**每张重新注入**）；
母体块对应 creative brief 的 Single message + Tone of voice；镜头句对应 KV→延展。

**额外要做的两件事（都是市场空白，也是我们相对 MJ 的结构性优势）**：

- **母体去重建议**：母体的"已用次数"计数器 + 新母体推荐（防重复的机制化）。
- **成组自检**：出完一套后判"这套图像不像一套"（色簇一致性 + 镜头是否互相重复 + 是否出现面部）。
  全行业这块是空的（GenStudio 的 Content check 只检品牌文本，不检"是否成组"）。
- **方向探索不额外扣费**：MJ 对探索收 GPU 时间；我们是积分制，可以把"试方向"做成不扣费，
  这是结构性差异（不是话术）。

### 实施分阶段（**阶段 0 不写代码**）

- **阶段 0（现在）**：**手工跑通 3 篇**。用站内现有能力（图片技能 + 参考图通道 + 手工调色）验证
  "母体 → 一套图"能不能达到他的水准。**跑通了再决定工作台要什么** —— 这是避免"先建工作台再发现
  内容体系不对"的唯一办法。
- **阶段 1**：把跑通的流程固化成**母体库 + 三层提示词模板**（先做成文档 + 一个小脚本，不碰线上）。
- **阶段 2**：工作台（账号规范 + 每篇 3 输入 + 结果墙按镜头归位 + 单独调整 —— 即 77 号 §六 那四条路径）。
- **阶段 3**：成组自检 + 母体去重 + 发布包（图 + 标题 3 选 1 + 正文 + 话题 + 首评）。

## 七、长期运营计划（账号侧）

- **节奏**：**每周 3–4 篇稳定 > 断更式日更**（从业者口径："稳定大于数量，不要一天狂发 5–6 篇，
  容易被判定机器批量操作"）。每篇 = **1 个 KV（封面）+ 6–9 张延展**。
- **栏目化**：固定 2–3 个栏目，带**固定句式**（可抄的成熟形态是"带序号的固定句式 + 固定节奏 +
  合集沉淀"，"第 N 天"结构让作者不必每期重想开场，且每篇都是主页入口）。
- **复盘**：单篇（24–48h）→ 周（固定 30 分钟：拆最好 2–3 篇 + 算比例 + 更新母体库）→
  月（内容维度看哪类母体持续好 → 加大产出；沉淀封面模板与标题公式）。
- **商业化**：商单链路是 **达人筛选 → 出 Brief → 初稿审核 → 蒲公英报备发布 → 冷跑 24h → 数据归档**；
  ⚠️ **所有商业合作笔记必须走蒲公英报备**（私下置换不报备，后续无法投流且有处罚风险）。
  报价锚点建议**不要按粉丝量线性估**（从业者那两套公式互相矛盾：粉丝量×0.1–0.3 与 粉丝量 5–8%，
  都是经验值）—— 视觉类账号的交付其实是"物料件数 × 授权范围 × 独家期"，按粉丝量算会低估交付成本。
- **合规红线（硬，不是建议）**：
  - **《人工智能生成合成内容标识办法》**（国信办等四部门，**2025-09-01 施行**）：
    第四条第（三）项要求**图片在适当位置添加显著的提示标识**；第五条要求文件元数据里加隐式标识；
    第十条要求**发布者主动声明**且**不得删除、篡改、伪造、隐匿**标识。
    配套强制国标 **GB 45438-2025** 同日实施。
  - 商单合规锚点是"**可识别性**"：《广告法》第十四条 + 《互联网广告管理办法》第九条第三款
    （通过**知识介绍、体验分享、消费测评**等形式推销并**附加购物链接**的，应显著标明"广告"）。
  - 平台的真正打击对象是"**流水线低质 + 未标注 + AI 托管**"，不是 AI 本身；
    且平台要求 **AI 产出必须人工二次改写润色，不能直接复制输出**。
  - ⇒ 对"日更 AI 出图"这个模型的直接含义：**必须让每条内容带上"有人工增量"的证据**
    （自有母体来源、自有签名、人工改写痕迹），否则会被归进"模板化低质"那一档。
    **这恰好也是内容体系要做的第一件事**（母体库是自有的、签名是自有的）——
    合规要求和差异化要求在这里是同一个动作。

## 八、提示词体系：三层 + 一条完整实例

三层（完整实例见 77 号 §十一，那里已经拼成逐字可用的原话）：

```
① 签名块（账号级，每张都带，长期不变）
   Shot discipline: no visible face (hands/back only), soft studio light, 3:4 vertical,
     premium editorial grade, consistent grain and saturation across the whole set.
   Brand fidelity: any wordmark renders exactly as provided; never invent a brand name.

② 母体块（本篇，每张都带）
   Concept: {母体}      e.g. Autumn limited edition
   Palette: {该母体派生的色簇}   e.g. warm grey earth #94847A + #8F8E93 + #CAB3AE
   World: {场景世界观}  e.g. warm grey plaster surface with dried branches
   Materials: {材质}    e.g. terracotta, silk

③ 镜头句（这一张）
   Shot {n}/{N} — {镜头模板句}
```

**关键纪律（各有出处，别漏）**：
- **每张都重新注入 ①②**，不做"接上一张"（§4.4-1）。
- **主体前置**、**一次只改一处**（§4.4-3）。
- 有参考图就用参考图承载风格（比文字稳，§4.4-2）。
- 负面词永远是块的一部分（面部/水印/塑料感/过饱和）。
- 变化用**显式枚举**并**配上限**（§4.4-5），不要靠"随手多写点形容词"。

## 九、要你拍板的四件事

1. **先手工跑 3 篇**验证"母体 → 一套图"再定工作台 —— 同意吗？（这是 §六 阶段 0，不写代码、不扣费要你确认）
2. **签名规范取哪几条**？（§三 那张表：不露脸 / 3:4 / 柔光 / 统一调色 / 字标原样 / 引用式短标题）
   —— 这是"你的审美语言"，定了以后长期不变，所以得你点头。
3. **栏目先开哪 2–3 个**？（建议：季节母体 / 情绪命题 / 品牌复刻三条之一二）
4. **第一个月是不是先做"季节母体"这一条**（因为 5 个实测色簇里 4 个都是季节可覆盖的，
   启动成本最低；情绪命题那类要靠文字功底，后面再上）。
