## 4. 为什么有 144 个值 / 204 处**没有**配 token（技术说明，非推诿）

带 **alpha < 1** 的值不能只按 RGB 配色 —— 它的**实际呈现色**取决于背后的底色。
例如 `rgba(124,58,237,0.1)` 配到 `--sb-brand-50`（纯色 #F5F3FF）会算出 ΔE 110，
但**在白底上二者视觉几乎相同** —— 这是**比较方法失真**，不是颜色真的差。

**建议**：对这 144 个值（204 处），改用「**合成到实际底色后再算 ΔE**」的口径。
需要你确认是否采用（会显著改变 §1 的分布）。

> 受影响最大的是 **`rgba(255,255,255,α)` 共 61 处**（§0-B）——
> 它在白底上几乎不可见、在暗底上是主要视觉元素，**同一个值两种观感**，
> 用纯 RGB 比较必然失真。这类值本质上是「**玻璃面上的相对明度**」，不是一个绝对色。

## 6. 我不建议做的事（先说清，避免返工）

1. **不建议**把暖棕描边硬压到 `--sb-border-*`：ΔE 21.6 全部来自**色相**（暖棕→暖黑），
   迁完全是冷色，会与页面整体的暖调打架。
2. **不建议**把玻璃白硬压到任何现有 token：ΔE 93+，纯属两个不同角色。
3. **不建议**在没有"合成底色再算 ΔE"的口径前迁移那 144 个 alpha 值（204 处）。
