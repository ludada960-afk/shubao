## 1. 已确认的**结构性差距**（逐条都是实测，不是感觉）

### 差距 A：知渔的工作台**锁在视口内**，我们原来不是 —— 已修（批 O-③④）
知渔：`main` = `flex h-[calc(100vh-56px)] min-h-0 overflow-y-auto p-4`，两栏各自内部滚动。
我们（修前）：页面整体滚动 ⇒ 主 CTA 落到视口外 32px，`elementFromPoint` 返回 null（点不到）。
**已修**：`.media-creation[data-surface="subpage"]` 锁高 + 左右内边距 136px → **24px**（与顶栏同线）；
e2e 新增场景 ㉑（4 条断言）+ 变异测试证明会红。

### 差距 B：**字段数量与粒度对不上**（我们 50 条里 18 条字段数不同）
实测（`.tmp/laoyu2/image-field-diff.json`）：SAME **12** / DIFF **18** / 未映射 **20**。

### 差距 C：知渔的**公共档位**（我们缺或不一致）
- **比例 7 档**（带副说明）：`1:1方图 / 2:3竖版长图 / 3:2横版摄影 / 3:4竖版海报 / 4:3横版主图 / 9:16手机竖屏 / 16:9手机横屏`
- **分辨率 2~3 档**：`2K高清 / 4K超清`（有的含 `1K标准`）
- **图片复刻的比例是 13 档**：`自适应 / 1:1 / 3:2 / 2:3 / 16:9 / 9:16 / 5:4 / 4:5 / 4:3 / 3:4 / 21:9 / 9:21 / 2:1 / 1:2`
- **模型选择**：App 类页面普遍有「模型选择 / 智能图片image」这一档（我们**没有**）

### 差距 D：**分组结构**不同（以商品套图为例）
- 知渔：`基础信息`【上传图片 0/6 + 目标市场 9 + 目标平台 5 + 文案语言 14】→
  `产品卖点与设计风格` → `套图结构配置`（**「上传图片」在「基础信息」组里面**）
- 我们：上传图片 / 基础信息 / 产品卖点与设计风格 / 套图结构配置（**「上传图片」被拆成独立一组**）
