## §0 一句话结论
他们的「高级感」不来自渐变或阴影，而来自**三件事**：
① 中性到近乎无色的底（白 + `#F5F7FA`），颜色只出现在**图标**与**悬停反馈**上；
② 悬停时**只**让图标磁贴变成品牌渐变（`#0076F5 → #7D28CC`，135deg），卡本体只做一次极轻的底色变化；
③ 卡底一条 **4px** 的渐变进度条，靠 **width 0 → 100%**（不是 transform）在 **700ms** 内从左往右充满。
我们现在的做法与它相反的正是第 ① 条：**按钮/卡片大面积铺品牌紫**，所以「整个页面看起来一大堆紫色」。

## §1 技术亮点 12 卡（要照抄的那一组）

容器：`grid`，`gap: 1px`，父级 `background: #E4E7EC` + `border: 1px solid #E4E7EC` + `border-radius: 24px` + `overflow: hidden`
→ **卡与卡之间不是留白，是 1px 缝隙里露出的分隔线色**。整体 `box-shadow: rgba(10,25,41,.04) 0 1px 2px`。
断点 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`；实测视口 1600 下一行 **3 个**，卡 **425.33 × 218**。

### 卡片默认态（逐项实测）
| 属性 | 值 |
|---|---|
| background | `rgb(255,255,255)` ｜ background-image `none` |
| color | `rgb(10,26,41)` |
| border | `0px`（实际无边框）| border-radius `0`（圆角在父 grid 上）|
| box-shadow | `none` | padding `32px` |
| font-size / weight | `16px` / `400` |
| transition | `0.5s cubic-bezier(0.4, 0, 0.2, 1)`（property = all）|

卡内元素默认态：
- 图标容器 `56×56`，`background: rgb(245,247,250)`，`border: 1px solid rgb(228,231,236)`，`border-radius: 16px`，`box-shadow: rgba(10,25,41,.04) 0 1px 2px`
- 图标 `svg` **28×28**，`color: rgb(0,118,245)`（**默认就是蓝色，不是黑/灰**）
- 序号 `30px / 700 / rgb(228,231,236)`（极浅灰，当水印用）
- 标题 `20px / 700 / rgb(10,26,41)`；描述 `16px / 500 / rgb(75,88,104)`
- 右下角装饰光晕：`256×256` 圆，`rgba(0,118,245,.06)`，`blur(80px)`，`right:-80px; bottom:-80px`

### 悬停态（逐项实测）
**卡本体只有一项变化**：`background-color` → `rgb(245,247,250)`。
宽高 / padding / border / border-radius / box-shadow / 字号 / 字重**全部不变**。

| 元素 | 默认 | 悬停 |
|---|---|---|
| 光晕 | `rgba(0,118,245,.06)` | `rgba(0,118,245,.1)`（transition 0.7s）|
| 图标容器 background-image | `none` | **`linear-gradient(135deg, rgb(0,118,245), rgb(125,40,204))`** |
| 图标容器 border-color | `rgb(228,231,236)` | `rgba(0,0,0,0)` |
| 图标容器 transform | `none` | `matrix(1.05,0,0,1.05,0,0)` = **scale(1.05)**（56 → 58.8）|
| 图标 svg color | `rgb(0,118,245)` | **`rgb(255,255,255)`** |
| 序号 | `rgb(228,231,236)` | `rgba(0,118,245,.15)` |
| 标题 | `rgb(10,26,41)` | **`rgb(0,118,245)`** |
| 描述 | `rgb(75,88,104)` | `rgba(10,26,41,.9)` |

**全站唯一一处渐变**：`linear-gradient(135deg, #0076F5, #7D28CC)` —— 只用在 56×56 的图标磁贴上，
**不是**卡片背景、**不是**按钮背景。

### 进度条（用户描述的那一条）
- **真实 DOM 元素，不是伪元素**（全卡及各后代 `::before/::after` 的 `content` 均为 `none`，逐项验证过）。
- 卡的第 3 个子 div：`absolute bottom-0 left-0 w-0 h-1`
- 高 **4px**；默认宽 **0**，悬停宽 **425.33px**（= 卡满宽）；`bottom: 0; left: 0`；圆角 `0`
- 背景 `linear-gradient(to right, #0076F5, #7D28CC)`
- **`transform: none`，没有 scaleX** —— 实现方式就是 **width 0 → 100%**
- `transition: all 0.7s cubic-bezier(0.4, 0, 0.2, 1)`
- 方向与左边缘：x 恒为 **631.5**（钉死不动）；进入时右边缘 631.5 → 1002.5 推进（**左→右充满**），
  离开时 width 收缩、左边缘不动（**右→左收回**）—— 与用户描述**一致**。

### 实测时序（真实鼠标，满宽 425.33px）
| 采样 | 进入宽度 | 占比 | 离开宽度 | 占比 |
|---|---|---|---|---|
| 0ms | 0 | 0.0% | 425.33 | 100.0% |
| 50ms | 5.25 | 1.2% | 420.06 | 98.8% |
| 100ms | 24.97 | 5.9% | 400.34 | 94.1% |
| 200ms | 139.66 | 32.8% | 258.05 | 60.7% |
| 400ms | 370.95 | 87.2% | 54.36 | 12.8% |

⚠️ **与用户描述不符的一处，如实记录**：用户说「这个速度会非常的快」，但 computed 与实测**都是 0.7s**，
没有找到任何短于 700ms 的覆盖。感知上的「快」可能来自缓动集中在中后段（前 100ms 只走 5.9%）。
**我们没有为了迎合描述去把时长改短** —— 照抄就该照抄实测值。

## §2 我们能直接抄的 / 不能抄的

### 建议照抄（属于「设计语言」，与业务无关）
1. **默认态无色**：按钮/卡默认是白底 + 一个**有颜色的小图标**，而不是大面积品牌色块。
2. **悬停只让一小块变渐变**：渐变只出现在图标磁贴（56×56）上，卡本体只做一次极轻的底色变化。
3. **1px 缝隙分隔**：卡与卡之间用父级底色透出的 1px 线，不用 border、不用大留白。
4. **底部 4px 进度条**：`width 0 → 100%` + `700ms cubic-bezier(0.4,0,0.2,1)`，左→右充满、右→左收回。
5. **序号/水印字号 30px 极浅灰**：信息层级靠字重与颜色深浅，不靠加框。

### 不能照抄（与我们既有约束冲突）
1. **他们的紫色 `#7D28CC` 与我们的 `--sb-brand-600` `#7C3AED` 不是同一个值**：
   我们是 D1 裁定的品牌色，改它是品牌决策，不是 UI 决策 —— 渐变可以照抄**形状**（135deg 两色），
   但端点要用我们自己的 `--sb-brand-*` 档位，否则全站会出现两套紫。
2. **他们整站是「白 + 冷灰」的冷色调**；我们首页是暖米底（`--sb-surface-page: #F5EFE4`）。
   直接套他们的白会把首页的暖色语言打断 —— 用户批注 #11-④ 要的是**分级**（首页/总页面/子页面各有自己的语言），
   不是把三级都刷成白的。见下条。
3. **他们的卡片没有 hover 位移**（只有底色变化）。我们既有的 `translateY(-4px)` 已经是站内语言，
   抄的时候保留位移、把颜色部分换成他们这套即可。
